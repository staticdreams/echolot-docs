Echolot is a native Mac app for sending, testing and building APIs. It speaks HTTP/1.1, HTTP/2 and HTTP/3, GraphQL,
gRPC, WebSocket, Server-Sent Events, Socket.IO, MQTT and MCP, and shows exactly what went over the wire: the raw
bytes, every redirect, and the time each step took.

What it does:

- **Keeps your work in plain files.** A workspace is a folder of readable TOML files, one per request, that you can
  keep in Git. Secret values stay in the macOS Keychain, never in the files.
- **Tests and runs.** Add checks to any request, run a folder or the whole workspace in the Runner, and run the same
  workspace in CI with the `echolot` command-line tool.
- **Designs and mocks.** Write OpenAPI specs visually or as text, and serve any spec as a local mock server.
- **Automates.** Chain requests, conditions and loops into flows on a canvas, and run them by hand, on a schedule or
  from a webhook.
- **Works with AI.** The built-in Assistant sends, tests and fixes requests with the model you choose. External AI
  agents can use your workspace through Echolot's own MCP server. Anything that changes data asks you first.
- **Reads huge responses.** Bodies stream to disk, so a 500 MB JSON response opens at once.

Echolot needs macOS 15 or later on a Mac with Apple silicon. It has no account and no sign-in.
