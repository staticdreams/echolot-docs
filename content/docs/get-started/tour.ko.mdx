## 투어 시작 [#start-the-tour]

Echolot은 새로 설치한 뒤 첫 작업 공간 윈도우가 열릴 때 투어를 한 번 제안합니다. 카드에 **Echolot에 오신 것을 환영합니다**라고 표시되고 **둘러보기**와
**나중에** 버튼이 있습니다. **나중에**는 기억되며 Echolot은 다시 묻지 않습니다. 투어가 생기기 전부터 사용하던 설치본에는 투어를 제안하지 않습니다.

투어를 다시 보려면 아무 작업 공간 윈도우에서 **도움말 › 투어 보기**를 선택합니다.

## 투어 진행 [#move-through-it]

각 카드에는 **8단계 중 1단계**와 현재 위치를 나타내는 점이 표시됩니다. 다음과 같이 사용합니다.

| 동작 | 방법 |
| --- | --- |
| 다음으로 | **다음**을 클릭하거나 <kbd>↩</kbd>를 누릅니다. |
| 이전으로 | **뒤로**를 클릭합니다. |
| 종료 | 닫기 버튼을 클릭하거나 <kbd>esc</kbd>를 누릅니다. |

밝게 표시된 컨트롤은 계속 작동하므로 직접 써 볼 수 있습니다. 어두워진 나머지 윈도우를 클릭해도 투어가 끝날 때까지 아무 일도 일어나지 않습니다. 투어가 끝나면
윈도우는 이전에 보던 페이지와 모듈로 돌아갑니다. **동작 줄이기**가 켜져 있으면 조명이 미끄러지듯 이동하는 대신 페이드로 바뀝니다.

## 단계 [#the-steps]

1. **모듈 다섯 개, 작업 공간 하나.** 모듈 전환기: 요청, MCP 서버, 명세, 모의 서버, 플로이며 <kbd>⌘</kbd><kbd>1</kbd>부터 <kbd>⌘</kbd><kbd>5</kbd>까지입니다.
   [윈도우](/docs/get-started/the-window)를 참고하십시오.
2. <strong>요청.</strong> 요청 목록: 모든 요청은 작업 공간 폴더 안의 일반 파일이며 Git에 바로 쓸 수 있습니다. <strong>+</strong>는 요청과 폴더를 추가하거나 Postman, Insomnia,
   OpenAPI, cURL에서 가져옵니다.
3. **테스트와 실행.** 목록 위의 두 행. [스크립트와 테스트](/docs/requests/scripts-and-tests)와 [실행](/docs/requests/runner)을 참고하십시오.
4. **환경.** 페이지 헤더의 환경 메뉴. [환경](/docs/workspaces/environments)을 참고하십시오.
5. **무엇이든 찾기.** 검색 필드, <kbd>⌘</kbd><kbd>K</kbd>: 요청, 환경, 동작, 지난 응답의 본문.
6. **플로.** 윈도우가 플로로 전환되고 해당 탭이 밝아집니다. [플로](/docs/flows)를 참고하십시오.
7. **어시스턴트에게 묻기.** 페이지 헤더의 마술봉, <kbd>⌘</kbd><kbd>J</kbd>, 그리고 예시 질문 세 개. 하나를 클릭하면 투어가 끝나고 질문이 어시스턴트에
   보낼 준비가 된 채로 남습니다. [어시스턴트](/docs/ai/assistant)를 참고하십시오.
8. **Echo를 소개합니다.** 페이지 헤더 가운데의 상태 화면. 이 Mac에서 Echo가 꺼져 있으면 카드가 켜기를 제안합니다. [Echo](/docs/ai/echo)를 참고하십시오.

마지막 카드 **준비가 끝났습니다**에는 알아 두면 좋은 키 다섯 개가 나옵니다. <kbd>⌘</kbd><kbd>K</kbd>는 모든 것을 검색하고, <kbd>⌘</kbd><kbd>N</kbd>은
새 요청을 만들고, <kbd>⌘</kbd><kbd>R</kbd>은 열려 있는 요청을 보내고, <kbd>⌘</kbd><kbd>J</kbd>는 어시스턴트를 표시하거나 가리고,
<kbd>⌘</kbd><kbd>1</kbd>–<kbd>5</kbd>는 모듈을 전환합니다. 투어를 다시 찾는 방법도 안내합니다. 모든 키는
[키보드 단축키](/docs/reference/keyboard-shortcuts)에 있습니다.
