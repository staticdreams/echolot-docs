Echolot 为“快捷指令”App 添加了两个操作：**运行请求**和**运行文件夹**。它们会像[运行器](/docs/requests/runner)那样发送已存储的请求并执行其检查，再把结果交给下一个操作。可用它们在每天早上检查 API，用键盘快捷键触发，或对 Siri 说一声。运行期间 Echolot 不会跳到前台。

<Shot id="mac-shortcuts-action" alt="“快捷指令”App：Echolot 的“运行文件夹”操作设为运行 Alpenglow 工作区的 Catalog 文件夹，后面接着一个以其“通过”值为条件的“如果”操作" />

## 操作 [#the-actions]

在“快捷指令”App 中搜索 Echolot，即可在**请求**下找到它们。

### 运行请求 [#run-request]

发送工作区中一个已存储的请求并执行其检查，然后返回结果。在编辑器中显示为**在 *工作区* 中运行 *请求***。

| 参数 | 选择什么 |
| --- | --- |
| **工作区** | Echolot 中已打开的工作区，或你最近使用的工作区之一。 |
| **请求** | 该工作区中一个已存储的请求。每个请求都显示其方法和路径。 |
| **环境** | 可选。工作区中显示的环境名称，或它的 slug。留空时使用工作区在窗口中所用的环境，或上次所用的环境。 |

### 运行文件夹 [#run-folder]

按顺序运行文件夹中的每个请求及其检查，并返回结果。在编辑器中显示为**在 *工作区* 中运行 *文件夹***。

| 参数 | 选择什么 |
| --- | --- |
| **工作区** | Echolot 中已打开的工作区，或你最近使用的工作区之一。 |
| <strong>文件夹</strong> | 该工作区的一个文件夹，或选择<strong>整个工作区（*名称*）</strong>运行每个请求。 |
| **环境** | 可选，与“运行请求”相同。 |

请求会带着脚本和检查运行，响应会记入工作区的[历史记录](/docs/workspaces/history)，与从工作区窗口发送时一样。工作区不必处于打开状态。

<Edition only="appstore">
  这些操作在 App Store 版本中的工作方式相同。未打开的工作区，通过你打开它时授予 Echolot 的访问权限来访问。
</Edition>

## 结果 [#the-outcome]

两个操作都会返回一个**运行结果**交给下一个操作，并在快捷指令结束时显示其摘要。

| 属性 | 内容 |
| --- | --- |
| **通过** | 是否每个请求都没有出错，且每项检查都通过（跳过的检查不计入）。 |
| **请求** | 运行了多少个请求。 |
| **失败的请求** | 有多少个失败。 |
| **状态** | 单个请求的状态码。 |
| **时长（毫秒）** | 单个请求所用的时间，以毫秒计。 |
| **摘要** | 一行文字，例如单个请求时为 `GET List products: 200 in 182 ms, 3 of 3 checks passed`，文件夹则为 `2 of 9 requests failed`。 |
| **失败率** | 每个失败的请求一行：它的名称，以及错误或未通过的检查。 |

## 受保护的环境 [#protected-environments]

当环境[受保护](/docs/workspaces/protected-environments)时，在发送任何内容之前，快捷指令会先询问，并显示环境和将要发送的内容。拒绝则结束该操作，不发送任何内容。

## Siri [#siri]

Echolot 的操作无需设置快捷指令即可用于 Siri：对“运行请求”，说“在 Echolot 中运行请求”或“用 Echolot 发送请求”；对“运行文件夹”，说“在 Echolot 中运行文件夹”或“在 Echolot 中运行文件夹里的请求”。

## 示例：每天早上检查商店 [#example-check-the-shop-every-morning]

使用 Alpenglow 示例工作区，它针对[演示 API](/docs/tutorials/demo-api)运行：

<Steps>
<Step>
在“快捷指令”App 中新建一个快捷指令并添加**运行文件夹**。选择 Alpenglow 工作区和 **Catalog** 文件夹。
</Step>
<Step>
添加**如果**，以**运行结果**的**通过**为输入，条件选择**为假**。
</Step>
<Step>
在“如果”内添加**显示通知**，内容为该结果的**摘要**；要列出每个失败的请求，则用**失败率**。
</Step>
<Step>
在**自动化**中创建一个个人自动化，让它每天早上运行这个快捷指令。
</Step>
</Steps>
