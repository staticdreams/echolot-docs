작업 공간은 각각 별도의 윈도우에서 열립니다. 윈도우는 두 부분으로 이루어져 있습니다. 왼쪽의 **사이드바**와 오른쪽의 **콘텐츠 패널**이며, 콘텐츠 패널은
페이지 헤더 아래에 한 번에 한 페이지를 표시합니다.

## 환영 윈도우 [#the-welcome-window]

열려 있는 작업 공간 윈도우가 없으면 Echolot은 환영 윈도우를 표시합니다. **새로운 작업 공간…**, **작업 공간 열기…**, **예제 열기**와 최근 작업 공간이
있습니다. 이름 아래에는 버전이 표시되고 **새로운 기능** 링크가 있습니다. Finder에서 연 작업 공간(`.echolot` 폴더를 더블 클릭)은 바로 작업 공간
윈도우로 열립니다.

## 사이드바 [#the-sidebar]

위에서 아래로 다음과 같습니다.

- 윈도우 버튼 옆의 **홈**과 **검색**. **홈**(<kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd>)은 작업 공간의 개요입니다. 요청, 폴더, 환경, 변수, 검사의 개수,
  최근 요청, 최근 응답, 테스트 현황, 환경을 보여 주며, 맨 위의 **Sonar** 카드는 지난 1시간, 하루, 일주일 또는 한 달 동안의 모든 전송을 응답에 걸린 시간별로
  표시합니다. [홈과 Sonar](/docs/get-started/home)를 참고하십시오. **검색**은 [명령 팔레트](#the-command-palette)(<kbd>⌘</kbd><kbd>K</kbd>)를 엽니다.
- **모듈 전환기**는 사이드바에 무엇을 나열할지 고릅니다. 각 모듈에는 자체 페이지가 있습니다.
- **모듈의 목록.**
- 아래쪽의 **작업 공간 전환기.**

<kbd>⌘</kbd><kbd>B</kbd>(**보기 › 사이드바 가리기**)는 사이드바를 가리거나 다시 표시합니다. 오른쪽 가장자리를 드래그하면 너비를 조절할 수 있습니다.

### 모듈 [#modules]

| 모듈 | 단축키 | 사이드바에 표시되는 항목 | 자세히 보기 |
| --- | --- | --- | --- |
| **요청** | <kbd>⌘</kbd><kbd>1</kbd> | **테스트**와 **실행**(현황 포함), 그다음 폴더와 요청 | [요청](/docs/requests) |
| **MCP 서버** | <kbd>⌘</kbd><kbd>2</kbd> | 작업 공간의 MCP 서버 | [MCP 서버](/docs/mcp-servers) |
| **명세** | <kbd>⌘</kbd><kbd>3</kbd> | OpenAPI 문서와 `.proto` 파일 | [명세](/docs/specs) |
| **모의 서버** | <kbd>⌘</kbd><kbd>4</kbd> | 모의 서버 | [모의 서버](/docs/mocks) |
| **플로** | <kbd>⌘</kbd><kbd>5</kbd> | 플로 | [플로](/docs/flows) |

모듈로 전환하면 마지막에 보던 화면으로 돌아갑니다. 목록의 행을 클릭하면 모듈 페이지에서 열립니다.

### 요청 트리 [#the-requests-tree]

요청 모듈에서 **요청** 옆의 **+** 버튼은 모든 종류의 요청(HTTP, GraphQL, WebSocket, Socket.IO, MQTT, gRPC 또는 MCP 호출)과 폴더를 추가하고,
가져오기와 내보내기도 합니다. 폴더와 요청 행에는 각자의 메뉴(오른쪽 클릭)가 있으며 **새로운 요청**, **새로운 폴더**, **폴더 설정…**, **이름 변경**, **복제**,
<strong>위로 이동</strong>, <strong>아래로 이동</strong>, <strong>Finder에서 보기</strong>, <strong>휴지통으로 이동…</strong>이 들어 있습니다.

- 행을 드래그하여 순서를 바꾸거나 폴더로 옮깁니다. 놓일 자리에 틈이 열리며, 닫힌 폴더 위에 잠시 두면 폴더가 열립니다.
- <kbd>⌘</kbd> 또는 <kbd>⇧</kbd>로 여러 행을 선택하고 오른쪽 클릭하면 **항목 N개 실행**, **요청 N개 편집…**, **항목 N개를 포함한 새로운 폴더**,
  <strong>항목 N개를 다음으로 이동</strong>, <strong>항목 N개를 휴지통으로 이동…</strong>을 사용할 수 있습니다.
- cURL 명령, 컬렉션 또는 명세를 사이드바에 붙여넣으면 [가져오기](/docs/get-started/importing)가 되고, 파일을 윈도우에 드롭해도 됩니다.
- **편집 › 복제**(<kbd>⌘</kbd><kbd>D</kbd>)와 **편집 › 이름 변경**은 선택한 행에 적용됩니다.
- 요청 옆의 점은 아직 기록되지 않은 변경 사항이 있다는 뜻입니다.
- 요청 옆의 경고 표시는 마지막 전송이 실패했다는 뜻입니다. 응답이 없거나, 상태가 400 이상이거나, gRPC 상태가 OK가 아닌 경우입니다. 포인터를 올리면 무엇이
  잘못되었는지 읽을 수 있으며, 이후 성공하면 사라집니다.

묻지 않고 삭제되는 것은 없으며, 삭제된 항목은 휴지통으로 이동합니다. 자세한 내용은 [폴더](/docs/workspaces/folders)에 있습니다.

### 작업 공간 전환기 [#the-workspace-switcher]

작업 공간 이름 아래에 저장 상태가 표시됩니다. **모두 저장됨**, **저장 중…**, **저장할 수 없음** 중 하나입니다. 클릭하면 최근 작업 공간,
**새로운 작업 공간…**, **작업 공간 열기…**, **작업 공간 설정…**, **Finder에서 보기**가 나타납니다. **파일 › 작업 공간 전환…**(<kbd>⌘</kbd><kbd>P</kbd>)은
대신 최근 작업 공간을 플로팅 패널에 나열하며, 입력하여 필터링하고 <kbd>Return</kbd>으로 엽니다.

## 페이지 헤더 [#the-page-header]

콘텐츠 패널 맨 위의 띠에는 페이지 이름이 표시됩니다. 요청에서는 요청의 폴더와 이름이 표시됩니다. 오른쪽에는 윈도우의 버튼이 있습니다.

| 버튼 | 동작 |
| --- | --- |
| **새로운 기능**(반짝이 아이콘) | 업데이트 후 새 릴리스 노트와 함께 나타납니다. |
| **기록** | 모든 응답과 보낸 주체(사용자, 실행, 에이전트)를 보여 줍니다(<kbd>⌘</kbd><kbd>Y</kbd>). [기록](/docs/workspaces/history)을 참고하십시오. |
| **에이전트** | 외부 AI 에이전트가 Echolot의 MCP 서버를 통해 이 작업 공간을 사용하도록 허용합니다. [에이전트](/docs/ai/agents)를 참고하십시오. |
| <strong>환경</strong> | 활성 환경을 고르거나 <strong>환경 없음</strong>을 선택합니다. <strong>환경 관리…</strong>는 환경 페이지를 엽니다. 보호된 환경에는 방패 아이콘이 표시됩니다. [환경](/docs/workspaces/environments)을 참고하십시오. |
| **레이아웃** | 요청에서: 나란히 또는 위아래로. [패널](#the-request-page)을 참고하십시오. |
| **편집기** | 명세에서: 시각적 편집기 또는 텍스트 편집기. |
| **어시스턴트**(마술봉) | 어시스턴트를 엽니다(<kbd>⌘</kbd><kbd>J</kbd>). |

헤더는 제목 막대를 대신합니다. 드래그하면 윈도우를 이동하고, 더블 클릭하면 **시스템 설정 › 데스크탑 및 Dock**에서 제목 막대에 지정한 동작(기본값은 확대/축소)을
실행합니다.

## 페이지 [#pages]

모듈 페이지 외에 **보기** 메뉴에서 다음 페이지를 열 수 있습니다.

| 페이지 | 단축키 |
| --- | --- |
| **홈** | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd> |
| **테스트**: 모든 요청의 검사 | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>T</kbd> |
| **실행**: 폴더 또는 작업 공간 실행 | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>R</kbd> |
| **환경** | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>E</kbd> |
| **기록** | <kbd>⌘</kbd><kbd>Y</kbd> |

**보기 › 변수 보기**(<kbd>⌥</kbd><kbd>⌘</kbd><kbd>V</kbd>)는 변수 패널을 엽니다. 작업 공간 전체, 폴더, 환경의 모든 변수가 표시되고 사용 중인 값에 표시가
붙으며 비밀 값은 가려집니다. 콘텐츠 옆에 열로 고정하거나 떠 있게 둘 수 있습니다.

**도움말 › 이 페이지에 대한 도움말**은 현재 페이지에 대한 이 문서의 페이지를 엽니다.

## 요청 페이지 [#the-request-page]

요청 페이지에는 두 개의 패널이 있습니다. 요청 편집기와 응답입니다.

- 맨 위에 걸쳐 있는 <strong>요청 헤더</strong>: 메서드, 주소, <strong>보내기</strong>(<kbd>⌘</kbd><kbd>R</kbd> 또는 <kbd>⌘</kbd><kbd>↩</kbd>). 보호된 환경이 활성일 때는 <strong>보내기</strong>가
  <strong>*환경*에 보내기…</strong>로 바뀌며 먼저 확인을 묻습니다. 세션(WebSocket, Socket.IO, MQTT)에는 대신 <strong>연결</strong>과 <strong>연결 해제</strong>가 있습니다.
- **편집기의 탭**은 요청 종류에 따라 다릅니다. HTTP 요청에는 **문서**, **헤더**, **매개변수**, **본문**, **인증**, **변수**, **테스트**, **스크립트**,
  **설정**이 있습니다. [요청](/docs/requests)을 참고하십시오.
- **응답의 탭**: **본문**, **테스트**, **헤더**, **쿠키**, **원본**, **16진수**, **통신**이 있으며, 스크립트가 실행되었을 때는 **콘솔**, 스트림에는 **이벤트**,
  세션에는 **메시지**, GraphQL에는 **스키마**가 추가됩니다. [응답](/docs/requests/responses)을 참고하십시오.

### 패널 레이아웃 [#pane-layouts]

패널은 **나란히** 또는 **위아래로**(응답이 아래) 배치됩니다. 페이지 헤더의 **레이아웃** 버튼이나 **보기 › 패널**에서 고릅니다. 요청 종류마다 자체 레이아웃과
구분선 위치를 이 Mac에서만 유지합니다. 예를 들어 HTTP 요청은 나란히 두고 WebSocket 요청은 위아래로 둘 수 있습니다. 구분선을 드래그하여 크기를 조절하며,
**보기 › 패널 › 패널 크기 재설정**은 모든 종류를 원래대로 되돌립니다. 윈도우가 나란히 배치하기에 너무 좁으면 공간이 생길 때까지 패널이 위아래로 쌓입니다.

| 항목 | 단축키 |
| --- | --- |
| **보내기** | <kbd>⌘</kbd><kbd>R</kbd> |
| **취소** | <kbd>⌘</kbd><kbd>.</kbd> |
| **cURL로 복사** | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>C</kbd> |
| **코드 생성…** | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>G</kbd> |
| **교환을 HAR로 내보내기…** | |
| **본문에서 찾기** | <kbd>⌘</kbd><kbd>F</kbd> |
| **명령 팔레트…** | <kbd>⌘</kbd><kbd>K</kbd> |

**보기 › 코드 확대**(<kbd>⌘</kbd><kbd>+</kbd>), **코드 축소**(<kbd>⌘</kbd><kbd>-</kbd>), **실제 코드 크기**(<kbd>⌘</kbd><kbd>0</kbd>)는 응답 본문,
트리, 코드 편집기의 크기를 바꿉니다. **보기 › 긴 줄 자동 줄 바꿈**은 긴 줄을 줄 바꿈합니다.

## 명령 팔레트 [#the-command-palette]

<kbd>⌘</kbd><kbd>K</kbd>나 사이드바의 **검색**은 작업 공간 전체를 검색하는 창을 엽니다. 몇 글자를 입력하고 결과에서 <kbd>Return</kbd>을 누릅니다.

- **요청**: 폴더와 주소와 함께 표시됩니다.
- **동작**: 모든 페이지로 **이동**, **새로운 요청**과 다른 종류, **새로운 폴더**, **새로운 명세**, **가져오기…**, **작업 공간 내보내기…**,
  **작업 공간 설정…**, **변수 보기**, **작업 공간 실행**, 요청에서는 **보내기**, **cURL로 복사**, **코드 생성…**, **레이아웃 전환**, **패널 크기 재설정**.
- **환경**: **사용 *환경***을 선택하면 해당 환경으로 전환합니다.
- **응답**: 세 글자부터는 기록에 있는 응답도 검색합니다.

## 어시스턴트 패널 [#the-assistant-panel]

<kbd>⌘</kbd><kbd>J</kbd>(**보기 › 어시스턴트 보기**)나 페이지 헤더 끝의 마술봉은 모든 페이지의 오른쪽에 어시스턴트를 엽니다. 어시스턴트는 Echolot에 내장된
AI 에이전트로, 요청을 보내고, 검사를 작성하고, 플로, 명세, 모의 서버를 만들 수 있으며, 무언가를 변경하기 전에 먼저 묻습니다. **설정 › 어시스턴트**에서 모델을
설정합니다. [어시스턴트](/docs/ai/assistant)를 참고하십시오.

## Echo [#echo]

Echo는 페이지 헤더 가운데에 있는 작은 상태 화면입니다. 전송과 소요 시간, 오류, 실행, 플로, 모의 서버, 에이전트, 활성 환경 등 지금 일어나는 일을 알려 주며,
가끔 농담도 합니다. 클릭하면 세션 보고서가 나옵니다. 기본적으로 꺼져 있으며, **설정 › 일반 › Echo**에서 **페이지 헤더에 Echo의 상태 화면 표시**를 켭니다.
[Echo](/docs/ai/echo)를 참고하십시오.

## 설정 [#settings]

**Echolot › 설정…**(<kbd>⌘</kbd><kbd>,</kbd>)에는 **일반**, **네트워크**, **저장 공간**, **어시스턴트**, **에이전트**, **개인정보 보호**, **정보** 패널과
설정을 이름으로 찾는 검색 필드가 있습니다. [설정](/docs/settings)을 참고하십시오. 작업 공간이나 폴더 하나에만 적용되는 설정은 **작업 공간 설정…**
(**인증**, **변수**, **스크립트**, **에이전트**, **프록시**, **인증서**)과 **폴더 설정…**(**인증**, **변수**, **스크립트**, **문서**)에 있습니다.

모든 키보드 단축키는 [키보드 단축키](/docs/reference/keyboard-shortcuts)에 나와 있습니다.
