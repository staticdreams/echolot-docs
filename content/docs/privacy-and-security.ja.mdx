Echolotにはアカウントもクラウドもありません。リクエストはあなたのMac上のファイルに、シークレットはキーチェーンに残り、あなた自身やワークスペースに関する情報は、あなたが送信するか何かをオンにしない限り、Macの外には出ません。このページには、Echolotが行うことだけを挙げています。

## ファイル [#your-files]

- **ワークスペース**は、保存した場所にあるプレーンなTOMLファイルのフォルダです。Echolotがアップロードすることはありません。
- **Echolot自身のデータ**（保存されたレスポンスのボディ、履歴、クラッシュレポート、アシスタントの会話）は、このMacの`~/Library/Application Support/Echolot`にあります。**設定 › 情報 › レスポンスと履歴 › Finderに表示**で開けます。App Store版は、独自のコンテナに保存します。[エディション](/docs/get-started/editions)を参照してください。
- ペインのレイアウトや、信頼したスクリプトとサーバなどの**個人的な選択**は、このMac上のアプリの設定に保存され、ワークスペースには入りません。

## シークレットはキーチェーンに残る [#secrets-stay-in-the-keychain]

シークレットの値は、ワークスペースのファイルに入ることがないので、ワークスペースをGitにコミットできます。

- **シークレット変数**は、キーチェーンにのみ保存されます。ファイルには変数の名前が書かれ、値はキーチェーンにあります。[シークレット](/docs/workspaces/secrets)を参照してください。
- **読み込み**では、認証や認証情報のヘッダーで見つかったパスワード、トークン、キーがシークレット変数に移され、読み込みのレポートにはその名前が表示され、値は表示されません。[読み込み](/docs/get-started/importing)を参照してください。
- **書き出し**では、シークレットの値は書き込まれません。シークレット変数は名前だけが書き出され、書き出しのレポートには、リクエストに平文で入力された認証情報の件数が表示されます。
- トークンをシークレット変数に保存する**レスポンスのキャプチャ**は、キーチェーンにのみ書き込みます。
- アシスタントの**モデルのキー**、**MCPのサインイントークン**、**プロキシのパスワード**もキーチェーンにあります。プロキシのパスワードや証明書のパスフレーズをプレーンテキストで入力すると、**キーチェーンに移動**が付いた警告が表示されます。
- コマンドラインツールは、同じキーチェーンの項目を読み取ります。アプリとecholot.devのツールは、確認なしでそれらを共有します。Mac App Store版とソースからビルドしたものでは1回確認されることがあります。**常に許可**を選んでください。

## 認証情報はそのサーバにとどまる [#credentials-stay-with-their-server]

リダイレクトが別のオリジン（別のスキーム、ホスト、ポート）に向かうとき、Echolotは、従う前に認証情報を取り除きます。`Authorization`、`Cookie`、一般的なAPIキーのヘッダー、APIキー認証のヘッダー、シークレットを含むすべてのヘッダー、Digest、AWS、クライアント証明書の設定です。あるサーバのために設定したシークレットが、リダイレクトによって別のサーバに渡ることはありません。

## ディスク上のレスポンスのボディ [#response-bodies-on-disk]

レスポンスはディスクにストリーミングされ、すべての送信は、このMacの履歴に保持されます。どれだけ、どのように保存するかは、**設定 › ストレージ**で決めます。

| 設定 | 意味 |
| --- | --- |
| **レスポンスのボディをディスク上で暗号化** | ボディ、通信のキャプチャ、整形済みのコピーが、ログインキーチェーンの鍵で暗号化されるので、その鍵がなければEcholotのストレージフォルダ内でレスポンスのどの部分も読めません。保存済みのボディはバックグラウンドで暗号化され、オフにすると復号されます。 |
| **レスポンスのボディを保持する上限** | このサイズを超えると、最近使われていないボディから削除されます。タブで開いているボディは常に保持されます。 |
| **リクエストごとの履歴** | 各リクエストが保持するレスポンスの数。 |

暗号化がオンの間、履歴の検索では、リクエストを名前、アドレス、ヘッダーで見つけられますが、ボディの内容では見つけられません。履歴の検索インデックスは暗号化されないため、ボディのテキストは保持されず、暗号化をオンにすると、それまであったボディのテキストは削除されます。ワークスペースには影響しません。[ストレージと暗号化](/docs/workspaces/storage-and-encryption)を参照してください。

## 保護された環境 [#protected-environments]

環境を保護された環境（たとえばProduction）に設定すると、それがアクティブな間にあなたが開始するすべての送信が、先に確認されます。リクエストの<strong>送信</strong>（<strong>Productionに送信…</strong>と表示されます）、接続、ランナーの実行、フローの手動実行、クイック送信とショートカットのアクション、MCPの呼び出しとチェック、<strong>トークンを取得</strong>、スキーマの取得、gRPCリフレクションが対象です。確認では、環境の名前と、送信される内容が表示され、シークレットはマスクされます。

**キャンセル**がデフォルトのボタンなので、<kbd>Return</kbd>で保護された環境に誤って送信されることはなく、<kbd>Esc</kbd>でもキャンセルされます。**環境を切り替えるまで確認しない**を選ぶと、そのウインドウの環境が変わるまで確認されなくなります。これが保存されることはありません。エージェントは常に確認されます。[保護された環境](/docs/workspaces/protected-environments)を参照してください。

## スクリプトとローカルのプログラム [#scripts-and-local-programs]

- **スクリプト**（リクエスト前スクリプトとテストスクリプト）は、Echolot内のサンドボックスで実行されます。スクリプトがリクエストを送信できるのはEcholotを通じてだけで、ルールはあなた自身の送信と同じです。
- スクリプトは、<strong>このMacで</strong>信頼したときにだけ実行されます。Echolotで書いたスクリプトは信頼されています。ほかから届いたスクリプト（読み込み、`git pull`、Echolotの外での編集）は、<strong>スクリプトを確認…</strong>を選んで信頼するまで、送信を止めます。信頼はスクリプトの内容に対して、ワークスペースの外に保存されるので、ワークスペースが自分のスクリプトを信頼することはできません。
- **ローカルのプログラムとして動くMCPサーバ**は、MCPサーバページでコマンドを承認（**信頼して確認**）した後にだけ起動します。コマンド、その引数、環境が変更されると、再び確認されます。

## アシスタントとモデルプロバイダ [#the-assistant-and-model-providers]

アシスタントと、オンにした場合のEchoのAIコメントは、**設定 › アシスタント**で選んだモデルプロバイダを使います。

- モデルのキーはこのMacのキーチェーンに残り、プロバイダ自身のアドレスにだけ送られます。
- **プロバイダへの最初のメッセージは、何かが送信される前に確認されます。** プロバイダごとに1回です（互換サーバの場合はホストごと）。確認では、何が送られるかが示されます。アシスタントの場合は、あなたのメッセージ、アシスタントが読み取るワークスペースのデータ、ツールの結果です。シークレットの値は決して送られません。
- EchoのAIコメントは、何が起きたかについての短い事実だけを送ります（リクエストの種類、ステータスコード、所要時間）。名前、アドレス、ヘッダー、ボディ、変数、シークレットは決して送りません。
- Appleのオンデバイスモデルと、このMac上のサーバ（Ollamaなど）は確認しません。何もMacの外に出ないためです。
- **設定 › アシスタント › データの受け取りを許可**には、許可したプロバイダが、それぞれ**許可を取り消す**とともに一覧表示されます。取り消したプロバイダは、次回また確認されます。
- アシスタントは、データを変更するときや新しいホストに接続するときにあなたに確認し、外部エージェントと同じツールとルールで動作します。

[アシスタント](/docs/ai/assistant)を参照してください。

## 外部のAIエージェント [#external-ai-agents]

Claude Code、Cursor、CodexなどのエージェントがEcholotのMCPサーバを通じてワークスペースを使えるのは、あなたが許可した場合だけです。

- **デフォルトではオフ。** **設定 › エージェント › 開いているワークスペースの使用をエージェントに許可**でオンになり、各ワークスペースは**ワークスペース設定 › エージェント**でエージェントをオフにできます。
- **このMacのみ。** サーバは、標準入出力か、トークン付きの`127.0.0.1`で待ち受けます。ネットワークからは何も届きません。
- **あなたが承認する。** デフォルトでは、読み取りと安全な送信は実行されます。データを変更する可能性のある送信、新しいホスト、ワークスペースへの変更は、あなたに確認されます（**拒否**、**1回だけ許可**、**このセッションでは許可**）。保護された環境と新しいホストは、常に確認されます。
- **シークレットがエージェントに渡ることはない。** エージェントはシークレットを名前で参照します。エージェントに返されるものはすべて、エラーも含めて、そのまま、JSON、パーセントエンコード、Base64のいずれの形でも、シークレットの値が取り除かれます。エージェントが読む履歴では認証情報がマスクされ、誰も保存していない `access_token` など、レスポンスのボディの認証情報フィールドも同様にマスクされます。
- **提供されないもの。** エージェントのポリシー、プロキシ、証明書、認証、スクリプトの保存は、エージェントが使えるツールではありません。エージェントはスクリプトを提案できます。あなたはその理由と変更内容を確認し、**保存して信頼**だけがそれを書き込んで信頼します。
- **すべての呼び出しが記録される。** 履歴には、各リクエストを誰が送信したかが、エージェントは名前付きで表示されます。ウインドウの**エージェント**には、最近の呼び出しが一覧表示されます。

[エージェント](/docs/ai/agents)と[AIエージェントにワークスペースを安全に使わせる](/docs/tutorials/agents-safely)を参照してください。

## 使用状況データとクラッシュレポート [#usage-data-and-crash-reports]

どちらも**設定 › プライバシー**にあります。使用状況データはデフォルトでオフ、このMacに保存されるクラッシュレポートはオンです。

- **匿名の使用状況データを共有。** オンにすると、Echolotは、どの機能が使われているか（リクエストの送信、実行、MCPのチェック）を、リクエストの種類やステータスコードといった小さな事実とともに開発者に伝え、エラーをスタックトレースとともに報告します。URL、ヘッダー、ボディ、変数、シークレット、レスポンスは決して送りません。送信先は、Echolotが使っている分析サービスのPostHogです。
- **クラッシュレポートを収集。** デフォルトでオンです。macOSは、次回の起動時にクラッシュとハングのレポートをEcholotに渡し、Echolotはそれをこのmac上に保存します。バグ報告に添付できるようにするためです。レポートにはスタックトレースしか含まれず、どこにも送信されません。**Finderに表示**で開けます。

## Echolotが自分で行う接続 [#connections-echolot-makes-on-its-own]

あなたが送信するリクエストのほかに、Echolotがネットワークに接続するのは、次の場合だけです。

| 内容 | タイミング | 送信するもの |
| --- | --- | --- |
| <strong>アップデートの確認</strong>（ダイレクトダウンロード版） | <strong>アップデートを自動的に確認</strong>がオンのときは1日1回、または<strong>アップデートを確認…</strong>を選んだとき | GitHubにリリースの一覧を問い合わせます。GitHubには、アプリのバージョンとあなたのIPアドレスが見えます。 |
| **ベータ版の状態**（ダイレクトダウンロード版のベータビルド） | 起動時と1日1回 | GitHub Pagesから、署名された小さなファイルを、Cookieや保存された認証情報なしで取得します。ベータビルドを早く終了させたり、延長したりすることがあります。 |
| レスポンスツリーの**画像プレビュー** | JSONまたはXMLのツリーで、画像のアドレスにポインタを置いたときだけ | その画像を、ブラウザと同じように、Cookieや保存された認証情報なしで、最大10 MBまで取得します。履歴には記録されず、スクリプトは実行されません。 |
| **使用状況データ** | オンにしたときだけ | 上記を参照してください。 |
| **モデルプロバイダ** | アシスタントまたはEchoのAIコメントを使い、許可した後だけ | 上記を参照してください。 |

App Store版は、アップデートやベータ版の確認を行いません。アップデートはApp Storeが処理します。
