---
title: Keyboard shortcuts
description: Every keyboard shortcut in Echolot, from the menus and from the pages, grouped by where you use it.
---

Every action in the menus has its shortcut beside it. This page gathers them, with the keys that work on a page or in
a list. <kbd>⌘</kbd> is Command, <kbd>⌥</kbd> Option, <kbd>⇧</kbd> Shift, <kbd>⌃</kbd> Control.

## Workspaces and files

| Action | Keys | Menu |
| --- | --- | --- |
| New Request | <kbd>⌘</kbd><kbd>N</kbd> | File |
| New Folder | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>N</kbd> | File (while the sidebar shows Requests) |
| New Workspace… | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>N</kbd> | File |
| Open Workspace… | <kbd>⌘</kbd><kbd>O</kbd> | File |
| Switch Workspace… | <kbd>⌘</kbd><kbd>P</kbd> | File |
| Close Tab | <kbd>⌘</kbd><kbd>W</kbd> | File |
| Close Window | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd> | File |
| Import… | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>I</kbd> | File |
| Export Workspace… | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>E</kbd> | File |
| Duplicate | <kbd>⌘</kbd><kbd>D</kbd> | Edit |
| Undo, Redo | <kbd>⌘</kbd><kbd>Z</kbd>, <kbd>⇧</kbd><kbd>⌘</kbd><kbd>Z</kbd> | Edit |
| Settings | <kbd>⌘</kbd><kbd>,</kbd> | Echolot |

<kbd>⌘</kbd><kbd>W</kbd> closes the tab on screen, never the workspace window; <kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd>
closes the window. In other windows, such as Settings, <kbd>⌘</kbd><kbd>W</kbd> closes the window.

The **New GraphQL Request**, **New WebSocket Request**, **New Socket.IO Request**, **New MQTT Request** and **New gRPC
Request** items in the File menu, **Export Folder…** and **Rename** have no shortcut.

## Requests and responses

| Action | Keys | Menu |
| --- | --- | --- |
| Send | <kbd>⌘</kbd><kbd>R</kbd> or <kbd>⌘</kbd><kbd>↩</kbd> | Request |
| Cancel | <kbd>⌘</kbd><kbd>.</kbd> | Request |
| Copy as cURL | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>C</kbd> | Request |
| Generate Code… | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>G</kbd> | Request |
| Find in Body | <kbd>⌘</kbd><kbd>F</kbd> | Request |
| Next match, previous match | <kbd>⌘</kbd><kbd>G</kbd>, <kbd>⇧</kbd><kbd>⌘</kbd><kbd>G</kbd> | (in the find bar) |

While a [protected environment](/docs/workspaces/protected-environments) is active, the item reads **Send to
&lt;Environment&gt;…** and asks first. **Cancel** is the default button there, so <kbd>↩</kbd> never sends by accident.

**Export Exchange as HAR…** in the Request menu has no shortcut.

## The sidebar

| Action | Keys |
| --- | --- |
| Move the selection | <kbd>↑</kbd>, <kbd>↓</kbd> |
| Open a folder | <kbd>→</kbd> |
| Close a folder, or go to the folder above | <kbd>←</kbd> |
| Rename the selection | <kbd>↩</kbd> |
| Stop renaming | <kbd>Esc</kbd> |
| Move a request to the Trash | <kbd>⌫</kbd> (asks first) |

<kbd>⌫</kbd> only works on one request. No key deletes a folder or several items: use **Move to Trash…** (or **Move N Items
to Trash…**) in the context menu, which asks first. On the MCP Servers page, <kbd>⌫</kbd> offers to delete the selected server.

## Flows

| Action | Keys |
| --- | --- |
| Run, or **Run in &lt;Environment&gt;…** | <kbd>⌘</kbd><kbd>R</kbd> |
| Stop the run | <kbd>⌘</kbd><kbd>.</kbd> |
| Add a block | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>B</kbd> |
| Duplicate the selected blocks | <kbd>⌘</kbd><kbd>D</kbd> |
| Fit: show the whole flow | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>0</kbd> |
| Copy, cut, paste blocks (with the links between them) | <kbd>⌘</kbd><kbd>C</kbd>, <kbd>⌘</kbd><kbd>X</kbd>, <kbd>⌘</kbd><kbd>V</kbd> |
| Delete the selection | <kbd>⌫</kbd> |

| Draw a selection box | <kbd>⇧</kbd> or <kbd>⌘</kbd> and drag on the canvas |

A plain drag on empty canvas pans. See [flows](/docs/flows).

## Quick Send

| Action | Keys |
| --- | --- |
| Open Quick Send from any app | <kbd>⌃</kbd><kbd>⌥</kbd><kbd>Space</kbd> |

Quick Send is off until you turn it on in **Settings › General**, where you can also record another shortcut. See
[Quick Send](/docs/mac/quick-send).

## Settings and help

| Action | Keys | Where |
| --- | --- | --- |
| Search the settings | <kbd>⌘</kbd><kbd>F</kbd> | Settings |
| Echolot Documentation | <kbd>⌘</kbd><kbd>?</kbd> | Help menu |

**Help for This Page** opens the docs page about the page in the front window.

## Sheets and dialogs

<kbd>↩</kbd> chooses the default button and <kbd>Esc</kbd> cancels. A dialog that deletes something has no key for its
red button, so you always click it.
