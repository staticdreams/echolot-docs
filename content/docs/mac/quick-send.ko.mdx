빠른 보내기는 어디에 있든 저장된 요청 하나를 보냅니다. 아무 앱에서나 단축키를 누르고 요청 이름의 몇 글자를 입력한 다음 <kbd>↩</kbd>를
누르면, 상태, 시간, 크기가 작은 패널에 표시됩니다. 사용하던 앱은 계속 맨 앞에 있습니다.

## 켜기 [#turn-it-on]

빠른 보내기는 켜기 전에는 꺼져 있습니다.

1. **설정 › 일반**을 엽니다.
2. **빠른 보내기** 아래에서 **메뉴 막대에 빠른 보내기 표시**를 켭니다.

메뉴 막대에 종이비행기가 나타나고, 단축키가 모든 앱에서 동작하기 시작합니다.

### 단축키 변경 [#change-the-shortcut]

다른 단축키를 고르지 않으면 <kbd>⌃</kbd><kbd>⌥</kbd><kbd>Space</kbd>입니다. 바꾸려면 **단축키** 옆의 단축키를 클릭하고 새 키를
누르세요. <kbd>Esc</kbd>를 누르면 기존 단축키가 유지되고, **재설정**을 누르면 <kbd>⌃</kbd><kbd>⌥</kbd><kbd>Space</kbd>로
돌아갑니다.

모든 앱에서 동작하는 단축키에는 <kbd>⌘</kbd>, <kbd>⌃</kbd>, <kbd>⌥</kbd> 중 하나 또는 기능 키가 필요합니다. 그래야 글자를 입력할 때
단축키가 작동하지 않습니다. 단축키가 등록되어 있는 동안에는 다른 앱이 그 키를 받지 못합니다. 이미 다른 앱이 그 키를 사용 중이면
설정에 단축키를 등록할 수 없다고 표시되므로, 다른 단축키를 고르세요.

<Callout title="입력 소스">
  시스템 설정 › 키보드 › 키보드 단축키에서 켜 두었다면, macOS는 <kbd>⌃</kbd><kbd>⌥</kbd><kbd>Space</kbd>로 다음 입력 소스로
  전환할 수 있습니다. 이 단축키를 사용 중이라면 빠른 보내기에는 다른 단축키를 고르세요.
</Callout>

## 요청 보내기 [#send-a-request]

1. 단축키를 누르거나 메뉴 막대의 종이비행기를 클릭합니다.
2. <strong>저장된 요청 보내기…</strong>에 입력해서 목록을 좁힙니다. 각 행에는 요청의 메서드와 이름, 그리고 작업 공간과 폴더가 표시됩니다.
3. <kbd>↑</kbd>와 <kbd>↓</kbd>로 요청을 고르고 <kbd>↩</kbd>를 누르거나, 요청을 클릭합니다.

패널 아래쪽에는 결과가 표시됩니다. 상태 코드, 사유(또는 요청 이름), 시간, 크기가 나타나거나, 보내기에 실패한 이유가 나타납니다.
**Echolot에서 열기**를 누르면 해당 작업 공간 윈도우에서 요청이 열리며, 작업 공간이 열려 있지 않으면 먼저 작업 공간을 엽니다.

패널은 <kbd>Esc</kbd>를 누르거나 다른 곳을 클릭하면 닫힙니다.

## 표시되는 요청 [#which-requests-it-offers]

패널에는 Echolot에서 열려 있는 작업 공간의 저장된 요청이 먼저 나오고, 그다음에 최근 작업 공간(마지막으로 연 10개)의 요청이 나옵니다.
순서는 각 작업 공간의 사이드바 순서를 따릅니다. 요청을 보내기 위해 작업 공간이 열려 있을 필요는 없습니다.

빠른 보내기로 보낸 요청은 해당 윈도우에서 보낸 것과 똑같이 나갑니다.

- 작업 공간이 윈도우에서 사용하는 환경, 또는 마지막으로 사용한 환경으로 보냅니다.
- 요청의 스크립트와 검사가 함께 실행됩니다.
- 요청의 [기록](/docs/workspaces/history)에 남으므로, 요청을 열면 응답을 바로 볼 수 있습니다.

<Edition only="appstore">
  빠른 보내기는 App Store 에디션에서도 같게 동작합니다. 열려 있지 않은 작업 공간은 <strong>파일 › 작업 공간 열기…</strong>로 열 때
  Echolot에 허용한 접근 권한을 통해 사용합니다.
</Edition>

## 보호된 환경 [#protected-environments]

요청의 환경이 [보호된 환경](/docs/workspaces/protected-environments)이면 패널이 먼저 확인을 요청합니다.
**환경(으)로 보내시겠습니까?** 라는 질문과 함께, 보내려는 메서드와 주소가 비밀 값을 가린 채 표시됩니다. **취소**가 기본
버튼이므로 <kbd>↩</kbd>를 눌러도 보내지 않습니다. 계속하려면 **보내기**(WebSocket, Socket.IO, MQTT 요청은 **연결**)를 클릭하세요.
작업 공간의 열려 있는 윈도우에서 해당 환경에 대해 다시 묻지 않도록 선택했다면 빠른 보내기도 묻지 않습니다.
