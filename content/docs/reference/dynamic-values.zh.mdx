动态值是 `{{ }}` 中的一个函数：`{{$uuid}}`、`{{$base64('heidi:alpenglow')}}`、`{{$responseJSONPath('auth/sign-in', '$.access_token')}}`。Echolot 会在发送请求时计算它。动态值可用于变量能用的任何地方：URL、标头、正文、认证字段、消息和设置。关于如何在 App 中选取和编辑它们，参见[动态值](/docs/requests/dynamic-values)。

## 书写方式 [#writing-them]

- 动态值以 `$` 开头：`{{$timestamp}}`。没有参数时，括号可以省略。
- 参数放在括号中，用逗号分隔：加引号的文本（`'…'` 或 `"…"`）、数字、不加引号的变量名，或其他动态值。
- 文本参数本身可以包含标记：`{{$base64('{{email}}:{{password}}')}}`。引号内的 `}}` 不会结束该标记。
- 无法解析的内容会保持你写的样子并被报告，因此多余的 `{{` 绝不会破坏请求。

```text
{{$sha256('{{body}}', 'base64')}}
{{$date('yyyy-MM-dd', -86400, 'Europe/Zurich')}}
{{$hmacSha256(apiSecret, $timestamp)}}
```

## 响应 [#responses]

这些值读取另一个已存储请求的最新响应，该请求用其路径指定（`folder/request`，如 `auth/sign-in`）。每个值都接受一个可选的最后参数，说明是否先发送那个请求：

| 最后一个参数 | 含义 |
| --- | --- |
| `'if-missing'`（默认） | 当它还没有响应时先发送。 |
| `'fresh'` | 每次都先发送；在一次运行中只发送一次。 |
| `'latest'` | 从不发送；使用最新的响应。 |

| 值 | 参数 | 返回什么 |
| --- | --- | --- |
| `$responseJSONPath` | 请求、JSONPath | 响应正文中用 JSONPath 选出的值。`{{$responseJSONPath('auth/sign-in', '$.access_token')}}` |
| `$responseKeyPath` | 请求、键路径 | 用 `data.items.0.id` 这样的键路径选出的值。`{{$responseKeyPath('orders/list-orders', 'items.0.id')}}` |
| `$responseJq` | 请求、jq 过滤器 | jq 过滤器对正文的处理结果；有多个结果时每行一个。`{{$responseJq('catalog/list-products', '.items[0].sku')}}` |
| `$responseXPath` | 请求、XPath | XML 响应中的值。`{{$responseXPath('echo/xml', '/catalog/product[1]/@sku')}}` |
| `$responseRegex` | 请求、模式 | 正文中正则表达式的第一个匹配：如果有分组，则为第一个分组。`{{$responseRegex('echo/html', '<title>(\\w+)</title>')}}` |
| `$responseHeader` | 请求、标头 | 一个响应标头。`{{$responseHeader('orders/create-order', 'Location')}}` |
| `$responseCookie` | 请求、Cookie | 响应所设置的某个 Cookie 的值。`{{$responseCookie('echo/set-cookie', 'flavour')}}` |
| `$responseStatus` | 请求 | 状态码。`{{$responseStatus('auth/sign-in')}}` |
| `$responseBody` | 请求 | 整个正文，作为文本。`{{$responseBody('auth/who-am-i')}}` |
| `$responseBodyLength` | 请求 | 正文的大小，以字节计。`{{$responseBodyLength('catalog/export')}}` |
| `$response` | 请求、查询 | 以上任一项，由查询的形式决定：JSONPath（`$.token`）、XPath（`/a/b`，或 `xpath:…`）、`regex:…`、`jq:…`、`keypath:…`、`header:Name` 或 `cookie:Name`。`{{$response('auth/sign-in', 'header:Content-Type')}}` |

例如，**Who am I** 可以直接从 **Sign in** 取得令牌，必要时先发送它：

```text
Authorization: Bearer {{$responseJSONPath('auth/sign-in', '$.access_token')}}
```

如果请求循环读取彼此的响应，会被拒绝，并指出构成循环的请求。[响应捕获](/docs/requests/captures)是在请求之间传递值的另一种方式。

## 请求 [#requests]

这些值读取一个请求在发送时的样子，即已解析的结果。第一个参数是已存储请求的路径，或者为空（`''`）表示正在发送的请求。

| 值 | 参数 | 返回什么 |
| --- | --- | --- |
| `$requestURL` | 请求 | 它的 URL，已解析。`{{$requestURL('')}}` |
| `$requestMethod` | 请求 | 它的方法。`{{$requestMethod('')}}` |
| `$requestHeader` | 请求、标头 | 一个标头，已解析，包括其认证添加的内容。`{{$requestHeader('', 'Content-Type')}}` |
| `$requestQuery` | 请求、参数 | 其 URL 的一个查询参数，已解码。`{{$requestQuery('', 'page')}}` |
| `$requestBody` | 请求 | 它的正文，已解析，作为文本。`{{$requestBody('')}}` |
| `$requestJSONPath` | 请求、JSONPath | 其 JSON 正文中的值。`{{$requestJSONPath('orders/create-order', '$.lines[0].sku')}}` |
| `$requestJq` | 请求、jq 过滤器 | jq 过滤器对其 JSON 正文的处理结果。`{{$requestJq('', '.lines[0].quantity')}}` |
| `$requestVariable` | 请求、变量 | 该请求所看到的某个变量。`{{$requestVariable('auth/sign-in', 'email')}}` |

常见的用法是用请求发送的内容给请求签名：

```text
X-Signature: {{$hmacSha256(apiSecret, $requestBody(''))}}
```

## 哈希和签名 [#hashes-and-signatures]

每个哈希接受文本，以及可选的输出格式：`'hex'`（默认）、`'base64'` 或 `'base64url'`。每个 HMAC 接受密钥、消息，以及可选的输出格式。

| 值 | 参数 | 返回什么 |
| --- | --- | --- |
| `$md5` | 文本、输出 | 文本的 MD5。`{{$md5('alpenglow')}}` |
| `$sha1` | 文本、输出 | SHA-1。`{{$sha1('alpenglow')}}` |
| `$sha224` | 文本、输出 | SHA-224。 |
| `$sha256` | 文本、输出 | SHA-256。`{{$sha256($requestBody(''), 'base64')}}` |
| `$sha384` | 文本、输出 | SHA-384。 |
| `$sha512` | 文本、输出 | SHA-512。 |
| `$hmacMd5` | 密钥、消息、输出 | 以密钥计算的消息的 HMAC-MD5。 |
| `$hmacSha1` | 密钥、消息、输出 | HMAC-SHA1。 |
| `$hmacSha224` | 密钥、消息、输出 | HMAC-SHA224。 |
| `$hmacSha256` | 密钥、消息、输出 | HMAC-SHA256。`{{$hmacSha256(apiSecret, $timestamp)}}` |
| `$hmacSha384` | 密钥、消息、输出 | HMAC-SHA384。 |
| `$hmacSha512` | 密钥、消息、输出 | HMAC-SHA512。 |

## 时间 [#time]

这些值都取发送请求的那一刻；给出偏移时，按偏移移动。

| 值 | 参数 | 返回什么 |
| --- | --- | --- |
| `$timestamp` | 偏移（可选） | 以秒计的 Unix 时间：`1793525000`。`{{$timestamp(60)}}` 是一分钟后。 |
| `$timestampMs` | 偏移（可选） | 以毫秒计的 Unix 时间：`1793525000123`。 |
| `$isoTimestamp` | 偏移（可选） | UTC 的 ISO 8601 格式，含毫秒：`2026-11-01T09:30:00.123Z`。`{{$isoTimestamp('-90s')}}` 是 90 秒前。 |
| `$httpDate` | 无 | HTTP 日期，用于 `Date` 或 `If-Modified-Since`：`Sun, 01 Nov 2026 09:30:00 GMT`。 |
| `$date` | 格式、偏移秒数（可选）、时区（可选） | 按 Unicode 日期模式格式化的时间，按偏移量平移，位于指定时区（未指定则为 UTC）。`{{$date('yyyy-MM-dd')}}`、`{{$date('yyyy-MM-dd HH:mm', 3600, 'Europe/Zurich')}}` |

`$timestamp`、`$timestampMs` 和 `$isoTimestamp` 的偏移是秒数，或者带单位的数字：`ms`、`s`、`m`、`h`、`d` 或 `w`。`-` 表示往过去移动，
`+`（或不写）表示往将来移动：`'-90s'`、`'2h'`、`'-1d'`、`'1w'`。请用引号把它写成文本；单纯的秒数可以不加引号，比如 `{{$timestamp(-3600)}}`。
无效的偏移会失败，并给出应该怎么写的提示。

## 随机 [#random]

每次发送都会生成新值，`$sameUUID` 除外。

| 值 | 参数 | 返回什么 |
| --- | --- | --- |
| `$uuid` | 无 | 一个小写的随机 UUID。也可用 `$guid` 和 `$randomUUID`。`{{$uuid}}` |
| `$sameUUID` | 名称 | 只生成一次的随机 UUID，在同一名称请求它的地方都给出同一个值：每次运行一次（每次迭代各自一个），运行之外每个窗口一次，在命令行中则每条命令一次。`{{$sameUUID('order')}}` |
| `$randomInt` | 最小值、最大值 | 两者之间的整数，包含两端。只给一个参数时它是最大值，从 0 起；不给参数则为 0 到 1000。`{{$randomInt(1, 5)}}` |
| `$randomString` | 长度、字符（可选） | 随机字符，未指定时为 16 个（最多 4096 个）：字母和数字，或指定的字符。`{{$randomString(8, 'ABCDEF0123456789')}}` |
| `$randomHex` | 字节数 | 十六进制的随机字节，未指定时为 16 个（最多 2048 个）；数字个数是字节数的两倍。`{{$randomHex(8)}}` |

Alpenglow 的 **Create order** 发送 `Idempotency-Key: {{$uuid}}`，因此它下的每一笔订单都是新的。如果一次运行中有多个请求必须发送同一个键，比如一个请求及其重试，
或者一个创建请求和随后的更新请求，请给它们 `{{$sameUUID('order')}}`：每次运行得到一个新键，所有指定 `order` 的请求都发送这个键。

## 示例数据 [#fake-data]

为请求正文、测试数据和[模拟路由](/docs/mocks/routes#bodies-with-fake-data)生成的虚构值：姓名、地址、公司、价格、日期、乱数假文等，每次发送都不同。这些名称就是 Postman 的动态变量，因此使用它们的集合在这里会发送真实的值。在 `{{` 列表中，它们位于**示例数据**下，按分组排列。

参数都是可选的；数字范围为 -10^15 到 10^15。模拟服务器的正文还可以使用[随机](#random)和[时间](#time)中的 `$uuid`（即 `$randomUUID`）、`$randomInt`、`$randomString`、`$randomHex`、`$timestamp`、`$timestampMs` 和 `$isoTimestamp`，时间值可带偏移。在“终端”中，[`echolot fake`](/docs/cli/fake) 用它们填充模板。

| `$lowercase` | 文本 | 小写的文本。`{{$lowercase(email)}}` |
| `$uppercase` | 文本 | 大写的文本。`{{$uppercase(productId)}}` |
| `$trim` | 文本 | 去掉两端空格和换行的文本。`{{$trim($responseBody('auth/who-am-i'))}}` |

## 文件和系统 [#files-and-the-system]

| 值 | 参数 | 返回什么 |
| --- | --- | --- |
| `$file` | 路径 | 文件的内容：相对于工作区的路径，或绝对路径。`{{$file('fixtures/order.json')}}` |
| `$env` | 名称 | Echolot 进程的环境变量。`{{$env('HOME')}}` |

## 动态值和智能体 [#dynamic-values-and-agents]

当 AI 智能体发送请求时（通过 Echolot 的 MCP 服务器或助手），`$env` 不返回任何内容，`$file` 只读取工作区内的文件。机密值绝不会到达智能体。参见[智能体](/docs/ai/agents)。
