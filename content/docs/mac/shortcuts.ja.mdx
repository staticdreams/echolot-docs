Echolotは、ショートカットアプリに**リクエストを実行**と**フォルダを実行**の2つのアクションを追加します。
どちらも、[ランナー](/docs/requests/runner)と同じように、保存済みのリクエストをチェックとともに送信し、結果を次のアクションに渡します。
毎朝のAPIの確認、キーボードショートカットからの確認、Siriへの依頼などに使えます。実行中も、Echolotは前面に出てきません。

## アクション [#the-actions]

ショートカットアプリでEcholotを検索し、**リクエスト**の下から見つけます。

### リクエストを実行 [#run-request]

ワークスペースの保存済みのリクエストを1件、チェックとともに送信し、結果を返します。
エディタでは<strong>「*ワークスペース*」の「*リクエスト*」を実行</strong>と表示されます。

| パラメータ | 選択する内容 |
| --- | --- |
| **ワークスペース** | Echolotで開いているワークスペース、または最近使ったワークスペース。 |
| **リクエスト** | そのワークスペースの保存済みのリクエスト。メソッドとパスが表示されます。 |
| **環境** | 省略可能。ワークスペースに表示される環境の名前、またはそのスラッグ。空の場合は、ワークスペースがそのウインドウで使っている環境、または最後に使った環境。 |

### フォルダを実行 [#run-folder]

フォルダ内のすべてのリクエストを、チェックとともに順番に実行し、結果を返します。
エディタでは<strong>「*ワークスペース*」の「*フォルダ*」を実行</strong>と表示されます。

| パラメータ | 選択する内容 |
| --- | --- |
| **ワークスペース** | Echolotで開いているワークスペース、または最近使ったワークスペース。 |
| **フォルダ** | そのワークスペースのフォルダ、またはすべてのリクエストを対象にする**ワークスペース全体（*名前*）**。 |
| **環境** | 省略可能。「リクエストを実行」と同じです。 |

リクエストはスクリプトとチェックとともに実行され、レスポンスは、ワークスペースのウインドウから送信した場合と同じように、ワークスペースの[履歴](/docs/workspaces/history)に記録されます。
ワークスペースを開いておく必要はありません。

<Edition only="appstore">
  アクションは、App Storeエディションでも同じように動作します。開いていないワークスペースには、ワークスペースを開いたときにEcholotに与えたアクセス権を通じてアクセスします。
</Edition>

## 実行結果 [#the-outcome]

どちらのアクションも、次のアクションに渡す**実行結果**を返し、ショートカットの終了時にその概要を表示します。

| プロパティ | 内容 |
| --- | --- |
| **成功** | すべてのリクエストがエラーなく実行され、すべてのチェックが成功したかどうか（スキップされたチェックは失敗として数えません）。 |
| **リクエスト** | 実行されたリクエストの数。 |
| **失敗したリクエスト** | 失敗したリクエストの数。 |
| **ステータス** | ステータスコード（リクエスト1件の場合）。 |
| **所要時間（ms）** | ミリ秒単位の時間（リクエスト1件の場合）。 |
| **概要** | 1行の文。リクエスト1件なら`GET List products: 200 in 182 ms, 3 of 3 checks passed`、フォルダなら`2 of 9 requests failed`のようになります。 |
| **失敗** | 失敗したリクエストごとに1行。リクエストの名前と、エラーまたは失敗したチェック。 |

## 保護された環境 [#protected-environments]

環境が[保護されている](/docs/workspaces/protected-environments)場合、ショートカットは何かを送信する前に、環境と送信される内容を示して確認します。
拒否すると、何も送信せずにアクションが終了します。

## Siri [#siri]

Echolotのアクションは、ショートカットを設定しなくてもSiriで使えます。
「Echolotでリクエストを実行」や「Echolotでリクエストを送信」と言うと「リクエストを実行」が、「Echolotでフォルダを実行」や「Echolotでフォルダのリクエストを実行」と言うと「フォルダを実行」が動作します。

## 例：毎朝ショップを確認する [#example-check-the-shop-every-morning]

[デモAPI](/docs/tutorials/demo-api)に対して動作するAlpenglowの例のワークスペースを使います。

<Steps>
<Step>
ショートカットアプリで新規ショートカットを作成し、**フォルダを実行**を追加します。Alpenglowワークスペースと**Catalog**フォルダを選択します。
</Step>
<Step>
**条件分岐**を追加し、入力に**実行結果**の**成功**、条件に**偽である**を指定します。
</Step>
<Step>
条件分岐の中に**通知を表示**を追加し、実行結果の**概要**を指定します。失敗したリクエストをすべて表示するには**失敗**を指定します。
</Step>
<Step>
**オートメーション**で、このショートカットを毎朝実行するパーソナルオートメーションを作成します。
</Step>
</Steps>
