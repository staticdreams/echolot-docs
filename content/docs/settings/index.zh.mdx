Echolot 的设置针对这台 Mac 上的 App：它的外观、代理、保留多少内容、AI 提供商，以及是否允许智能体接入。属于某个工作区的设置（它的认证、变量、代理、证书和智能体规则）位于边栏底部工作区菜单中的
**工作区设置…** 里，并随工作区一起流转；见[工作区](/docs/workspaces)。

用 **Echolot › 设置…** 或 <kbd>⌘</kbd><kbd>,</kbd> 打开设置。各窗格列在左侧。它们上方的搜索字段（<kbd>⌘</kbd><kbd>F</kbd>）只保留含有匹配设置的窗格；按 <kbd>↩</kbd> 打开第一个。
设置会打开到你上次使用的窗格。

## 通用 [#general]

语言、外观，以及代码和响应的显示方式。

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| **语言** | Echolot 使用的语言：**系统** 遵循系统设置 › 通用 › 语言与地区，也可以选择 Echolot 的某种语言（它们以各自的名称列出）。新的选择在重新启动后生效，设置下方会出现 **重新启动 Echolot**。Echolot 有多种语言时才显示这一部分。 | 系统 |
| **外观** | **系统**、**浅色**、**深色** 或 **海洋**，适用于每个 Echolot 窗口，不论 macOS 使用什么。海洋是深海蓝色调的深色模式。 | 系统 |
| **代码字体大小** | 响应正文、十六进制视图、JSON 树和代码编辑器的大小，从 10 到 22 pt。**视图** 菜单：<kbd>⌘</kbd><kbd>+</kbd> 和 <kbd>⌘</kbd><kbd>−</kbd> 也可以更改。 | 12 pt |
| **响应中的长行自动换行** | 在响应的 **正文**、**原始** 和 **传输** 视图中让长行换行，而不是横向滚动。 | 关 |

### 快速发送 [#quick-send]

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| **在菜单栏中显示快速发送** | 一个菜单栏项目和一个在任何 App 中都有效的快捷键，会打开一个面板，用来发送你已打开和最近使用的工作区中的已存储请求。见[快速发送](/docs/mac/quick-send)。 | 关 |
| **快捷键** | 点按后按下按键即可更改；**重置** 会恢复默认值。另一个 App 占用这些按键时，设置会说明。 | <kbd>⌃</kbd><kbd>⌥</kbd><kbd>Space</kbd> |

### Echo [#echo]

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| **在页面标题栏中显示 Echo 的状态屏幕** | 那块小屏幕会告诉你窗口中正在发生什么。见 [Echo](/docs/ai/echo)。 | 开 |
| **幽默** | **只讲事实**、**一点** 或 **很多**。 | 一点 |
| **让 AI 撰写 Echo 的部分评论** | 由模型写出部分内容：Mac 支持时用 Apple 的设备端模型，否则用“设置 › 助手”中选定的模型。**只讲事实** 时不可用。**作者** 显示是哪个模型，并在需要时请求它的许可。 | 关 |

### 命令行工具 [#command-line-tool]

<Edition only="direct">
  这一部分只在直接下载版本中提供。App Store 版本无法安装该工具；请从下载页面单独安装，见[命令行工具](/docs/cli)。
</Edition>

- **内置工具**：App 内部 `echolot` 工具所在的位置。
- **已在 PATH 中**：**未安装** 并带有 **安装命令行工具…**，或链接的路径并带有 **重新安装** 和 **移除**。安装会在 `/opt/homebrew/bin` 或 `/usr/local/bin` 中放入一个指向内置工具的 `echolot` 链接，
  这样 `echolot run` 和 `echolot mcp setup` 就能在“终端”中使用。两个文件夹都不可写时，macOS 会询问管理员密码。指向另一份 Echolot 的链接以橙色标出并带有 **重新安装**；不是 Echolot 放在那里的文件会显示
  **替换…**，替换前会先询问。

**Echolot › 安装命令行工具…** 的作用相同。

### 更新 [#updates]

<Edition only="appstore">
  在 App Store 版本中，这一部分显示 **App Store 会让 Echolot 保持最新。**
</Edition>

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| **自动检查更新** | 每天在 GitHub 上查找一次新版本，并在安装前询问。 | 开 |
| **自动下载并安装更新** | 不经询问直接安装更新。需要上面的设置。 | 关 |
| **上次检查** | Echolot 上次查找的时间，并带有 **立即检查**。 | |

更新带有签名，Echolot 只安装由其开发者签名的更新。**Echolot › 检查更新…** 会立即查找。你自己构建的版本不会查找更新。

## 网络 [#network]

请求所经过的代理。

| **代理** | 会发生什么 |
| --- | --- |
| **系统设置**（默认） | 来自系统设置 › 网络的 HTTP、HTTPS 和 SOCKS 代理，连同其例外。不使用自动代理配置（PAC）。 |
| **无** | 每个请求都直接连接。 |
| **手动** | 一个 HTTP、HTTPS（与代理之间使用 TLS）或 SOCKS5 代理，在下面的字段中设置。 |

选择 **手动** 时：

- **代理**：代理的地址，例如 `http://proxy:3128` 或 `socks5://host:1080`。
- **用户名**：可选。
- **密码**：保存在钥匙串中。有了用户名之后才可用。
- **直接连接到**：跳过代理的主机，用逗号分隔，例如 `localhost, *.internal`。

工作区可以在 **工作区设置 › 代理** 中设置自己的代理，它优先。HTTP/3 无法通过代理工作：这样的请求会失败并说明原因。见[请求设置](/docs/requests/settings)。

## 储存空间 [#storage]

响应及其历史记录保留多少。见[储存与加密](/docs/workspaces/storage-and-encryption)。

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| **在磁盘上加密响应正文** | 用保存在你登录钥匙串中的密钥加密正文、传输捕获和格式化副本。已存储的正文会在后台加密，关闭时再转换回来；下面一行显示进度以及有多少正文已加密。开启期间，历史记录搜索按名称、地址和标头查找请求，而不按正文的内容查找。工作区不受影响。 | 关 |
| **响应正文最多保留** | 1、2、5、10、20 或 50 GB。无论正文到达多少次，只存储一份；超过这个大小时，最久未使用的会被移除。在标签页中打开的正文始终保留。下面一行显示它们在磁盘上的大小；**移除已存储的正文…** 会在询问后，移除打开的窗口不需要的每个正文。 | 5 GB |
| **每个请求的历史记录** | 每个请求的历史记录中保留 10、25、50、100 或 200 个响应。较早的条目先被移除；每个请求最新的响应保留其正文。 | 50 个响应 |

## 助手 [#assistant]

内置于 Echolot 的智能体：模型提供商和密钥。见[助手](/docs/ai/assistant)。

<Shot id="settings-assistant" alt="设置的助手窗格：两个提供商及其模型、允许接收数据的提供商、对模型隐藏的模式，以及添加提供商的表单" />

- **提供商**：你添加的每个提供商。勾选的那个就是助手所使用的。每个提供商都有一个 **模型** 菜单（或字段）、用于重新获取列表的 **载入模型**，以及 **移除…**，后者会从钥匙串中删除它的密钥。
  Anthropic 账户还有 **推理强度**：**模型默认值**、`low`、`medium`、`high`、`xhigh` 或 `max`。CLI 智能体则有它的 **命令**。
- **允许接收你的数据**：你给予过一次性许可的提供商，以及许可涵盖的范围（**助手和 Echo 的评论**，或仅 **Echo 的评论**）。**撤销许可** 会收回许可；下一条消息会再次询问。Apple 的设备端模型和这台 Mac 上的服务器从不询问。
- **对模型隐藏**：每行一个正则表达式。工具结果中匹配的内容，会在模型看到之前被替换为 `[hidden]`。机密变量始终被隐藏；这里用于处理其余内容。
- **添加提供商**：**提供商**（**Anthropic**、**OpenAI**、**Google Gemini**、**OpenAI 兼容** 或 **CLI 智能体（ACP）**），然后是 **API 密钥**、**地址**（OpenAI 兼容；留空时为 `http://127.0.0.1:11434/v1`），
  或 **智能体** 和 **命令**（CLI 智能体），最后是 **添加**。

密钥保存在这台 Mac 的钥匙串中，并且只发送到提供商自己的地址。

<Edition only="direct">
  **CLI 智能体（ACP）** 只在直接下载版本中提供：App Store 版本无法在你的 Mac 上启动程序。
</Edition>

## 智能体 [#agents]

让 AI 智能体处理你已打开的工作区。见[外部智能体](/docs/ai/agents)。

<Shot id="settings-agents" alt="设置的智能体窗格：允许智能体使用打开的工作区的开关、带最近工作区的 Claude Desktop，以及各工具集" />

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| **允许智能体使用打开的工作区** | 工作区打开期间，智能体的调用在 Echolot 中运行：可能更改数据的发送、新主机和对工作区的更改都由你批准，你还能在窗口的 **智能体** 下看到每次调用。机密值绝不会到达智能体。 | 关 |
| **Claude Desktop** | 你最近的工作区，每个都带有 **添加到 Claude**，它会开启智能体并把工作区添加到 Claude Desktop。Claude Desktop 已有时显示 **已添加**。仅限直接下载版本。 | |
| **供智能体使用的工具** | 智能体获得的工具集：**请求**（始终开启）、**流程**、**工作区**、**环境**、**规范**、**模拟服务器**、**MCP 服务器**、**历史记录**、**流程编辑**。 | 请求和流程 |
| **其他 App** | Claude Code、Cursor、VS Code 和 Codex 从工作区窗口顶部的 **智能体** 按钮连接。 | |

<Edition only="appstore">
  App Store 版本不显示 Claude Desktop 部分，而是显示 **命令行工具**：客户端通过单独安装的 `echolot` 工具连接，**获取命令行工具** 会通向下载页面。工作区打开期间，它们的调用在 App 中运行。
</Edition>

## 隐私 [#privacy]

Echolot 可以收集什么，在你开口之前始终关闭。见[隐私与安全](/docs/privacy-and-security)。

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| **共享匿名使用数据** | 告诉 Echolot 的开发者哪些功能被使用（发送请求、运行、MCP 检查），附带请求类型和状态码之类的少量事实，并报告错误及其堆栈跟踪。绝不包含 URL、标头、正文、变量、机密或响应。 | 关 |
| **收集崩溃报告** | macOS 会在下次启动时把 Echolot 的崩溃和卡死报告交给它，Echolot 将其存储在这台 Mac 上，以便你把它们附在反馈中。仅含堆栈跟踪。它们不会被发送到任何地方。会显示已存储报告的数量，并带有 **在访达中显示**。 | 开 |
| **更新检查** | 显示 Echolot 多久向 GitHub 请求一次发布列表：**每天一次**、**仅在你要求时** 或 **通过 App Store**。GitHub 只能看到 App 的版本和你的 IP 地址，看不到关于你或你的工作区的任何信息。 | |

## 关于 [#about]

版本，以及 Echolot 把数据保存在哪里。

- **版本**：版本和构建号，并带有 **新功能** 以查看发行说明。
- **网站**：echolot.dev。**版本发布**：所有版本及其说明。
- **响应和历史记录**：**在访达中显示** 会打开 Echolot 自己的数据文件夹：响应正文、历史记录和崩溃报告。工作区位于你保存它们的地方；删除这个文件夹只会丢失历史记录，绝不会丢失请求。
- **致谢**：Echo 的字体 Departure Mono，作者 Helena Zhang，遵循 SIL Open Font License 1.1。

<Edition only="appstore">
  App Store 版本把数据保存在它自己的容器中，而不是 Application Support 文件夹；**在访达中显示** 会在那里打开。
</Edition>
