---
title: "Atajos de teclado"
description: "Todos los atajos de teclado de Echolot, desde los menús y desde las páginas, agrupados según dónde los usas."
---

Cada acción de los menús tiene su atajo al lado. Esta página los reúne, con las teclas que funcionan en una página o en
una lista. <kbd>⌘</kbd> es Comando, <kbd>⌥</kbd> Opción, <kbd>⇧</kbd> Mayúsculas, <kbd>⌃</kbd> Control.

## Espacios de trabajo y archivos [#workspaces-and-files]

| Acción | Teclas | Menú |
| --- | --- | --- |
| Nueva solicitud | <kbd>⌘</kbd><kbd>N</kbd> | Archivo |
| Nueva carpeta | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>N</kbd> | Archivo (mientras la barra lateral muestra Solicitudes) |
| Nuevo espacio de trabajo… | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>N</kbd> | Archivo |
| Abrir espacio de trabajo… | <kbd>⌘</kbd><kbd>O</kbd> | Archivo |
| Cambiar de espacio de trabajo… | <kbd>⌘</kbd><kbd>P</kbd> | Archivo |
| Cerrar pestaña | <kbd>⌘</kbd><kbd>W</kbd> | Archivo |
| Cerrar ventana | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd> | Archivo |
| Importar… | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>I</kbd> | Archivo |
| Exportar espacio de trabajo… | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>E</kbd> | Archivo |
| Duplicar | <kbd>⌘</kbd><kbd>D</kbd> | Editar |
| Deshacer, Rehacer | <kbd>⌘</kbd><kbd>Z</kbd>, <kbd>⇧</kbd><kbd>⌘</kbd><kbd>Z</kbd> | Editar |
| Ajustes | <kbd>⌘</kbd><kbd>,</kbd> | Echolot |

<kbd>⌘</kbd><kbd>W</kbd> cierra la pestaña que se ve, nunca la ventana del espacio de trabajo;
<kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd> cierra la ventana. En otras ventanas, como Ajustes, <kbd>⌘</kbd><kbd>W</kbd> cierra
la ventana.

Los elementos **Nueva solicitud GraphQL**, **Nueva solicitud WebSocket**, **Nueva solicitud Socket.IO**,
**Nueva solicitud MQTT** y **Nueva solicitud gRPC** del menú Archivo, **Exportar carpeta…** y **Renombrar** no tienen
atajo.

## Solicitudes y respuestas [#requests-and-responses]

| Acción | Teclas | Menú |
| --- | --- | --- |
| Enviar | <kbd>⌘</kbd><kbd>R</kbd> o <kbd>⌘</kbd><kbd>↩</kbd> | Solicitud |
| Cancelar | <kbd>⌘</kbd><kbd>.</kbd> | Solicitud |
| Copiar como cURL | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>C</kbd> | Solicitud |
| Generar código… | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>G</kbd> | Solicitud |
| Buscar en el cuerpo | <kbd>⌘</kbd><kbd>F</kbd> | Solicitud |
| Coincidencia siguiente, coincidencia anterior | <kbd>⌘</kbd><kbd>G</kbd>, <kbd>⇧</kbd><kbd>⌘</kbd><kbd>G</kbd> | (en la barra de búsqueda) |

Mientras hay un [entorno protegido](/docs/workspaces/protected-environments) activo, el elemento dice **Enviar a
&lt;Entorno&gt;…** y pregunta antes. **Cancelar** es el botón predeterminado, así que <kbd>↩</kbd> nunca envía por
accidente.

**Exportar intercambio como HAR…** del menú Solicitud no tiene atajo.

## La barra lateral [#the-sidebar]

| Acción | Teclas |
| --- | --- |
| Mover la selección | <kbd>↑</kbd>, <kbd>↓</kbd> |
| Abrir una carpeta | <kbd>→</kbd> |
| Cerrar una carpeta, o ir a la carpeta superior | <kbd>←</kbd> |
| Renombrar la selección | <kbd>↩</kbd> |
| Dejar de renombrar | <kbd>Esc</kbd> |
| Trasladar una solicitud a la papelera | <kbd>⌫</kbd> (pregunta antes) |

<kbd>⌫</kbd> solo funciona con una solicitud. Ninguna tecla elimina una carpeta ni varios elementos: usa
**Trasladar a la papelera…** (o **Trasladar N elementos a la papelera…**) en el menú contextual, que pregunta antes. En
la página Servidores MCP, <kbd>⌫</kbd> ofrece eliminar el servidor seleccionado.

## Hojas y diálogos [#sheets-and-dialogs]

<kbd>↩</kbd> elige el botón predeterminado y <kbd>Esc</kbd> cancela. Un diálogo que elimina algo no tiene tecla para su
botón rojo, así que siempre haces clic en él.
