Echolot은 단축어 앱에 **요청 실행**과 **폴더 실행**이라는 두 가지 동작을 추가합니다. 이 동작은 [실행](/docs/requests/runner)과
마찬가지로 저장된 요청을 검사와 함께 보내고, 결과를 다음 동작에 넘깁니다. 매일 아침 API를 점검하거나, 키보드 단축키로 실행하거나,
Siri에게 부탁할 때 사용하세요. 동작이 실행되는 동안 Echolot이 맨 앞으로 나오지는 않습니다.

## 동작 [#the-actions]

단축어 앱에서 Echolot을 검색하면 **요청** 아래에서 찾을 수 있습니다.

### 요청 실행 [#run-request]

작업 공간의 저장된 요청 하나를 검사와 함께 보내고 결과를 반환합니다. 편집기에서는 ***작업 공간*에서 *요청* 실행**으로 표시됩니다.

| 매개변수 | 선택할 항목 |
| --- | --- |
| **작업 공간** | Echolot에서 열려 있는 작업 공간 또는 최근 작업 공간 중 하나. |
| **요청** | 해당 작업 공간의 저장된 요청. 각 요청은 메서드와 경로와 함께 표시됩니다. |
| **환경** | 선택 사항. 작업 공간에 표시되는 환경 이름 또는 슬러그. 비워 두면 작업 공간이 윈도우에서 사용하는 환경, 또는 마지막으로 사용한 환경입니다. |

### 폴더 실행 [#run-folder]

폴더의 모든 요청을 검사와 함께 순서대로 실행하고 결과를 반환합니다. 편집기에서는 ***작업 공간*에서 *폴더* 실행**으로 표시됩니다.

| 매개변수 | 선택할 항목 |
| --- | --- |
| **작업 공간** | Echolot에서 열려 있는 작업 공간 또는 최근 작업 공간 중 하나. |
| **폴더** | 해당 작업 공간의 폴더, 또는 모든 요청을 실행하는 **작업 공간 전체(*이름*)**. |
| **환경** | 선택 사항. 요청 실행과 같습니다. |

요청은 스크립트와 검사와 함께 실행되고, 응답은 작업 공간의 윈도우에서 보낸 것처럼 작업 공간의 [기록](/docs/workspaces/history)에
들어갑니다. 작업 공간이 열려 있을 필요는 없습니다.

<Edition only="appstore">
  동작은 App Store 에디션에서도 같게 동작합니다. 열려 있지 않은 작업 공간은 Echolot에서 작업 공간을 열 때 허용한 접근 권한을 통해
  사용합니다.
</Edition>

## 실행 결과 [#the-outcome]

두 동작 모두 다음 동작에 넘길 **실행 결과**를 반환하며, 단축어가 끝나면 그 요약을 표시합니다.

| 속성 | 담긴 내용 |
| --- | --- |
| **통과** | 모든 요청이 오류 없이 실행되고 모든 검사를 통과했는지 여부(건너뛴 검사는 실패로 세지 않습니다). |
| **요청** | 실행된 요청 수. |
| **실패한 요청** | 실패한 요청 수. |
| **상태** | 요청이 하나일 때의 상태 코드. |
| **소요 시간(ms)** | 요청이 하나일 때의 소요 시간(밀리초). |
| **요약** | 한 줄 요약. 요청 하나는 `GET List products: 200 in 182 ms, 3 of 3 checks passed`, 폴더는 `2 of 9 requests failed`와 같은 형태입니다. |
| **실패** | 실패한 요청마다 한 줄: 요청 이름과 오류 또는 실패한 검사. |

## 보호된 환경 [#protected-environments]

환경이 [보호된 환경](/docs/workspaces/protected-environments)이면, 단축어는 무엇이든 보내기 전에 환경과 보낼 내용을 보여 주며
확인을 요청합니다. 거부하면 아무것도 보내지 않고 동작이 끝납니다.

## Siri [#siri]

Echolot의 동작은 단축어를 따로 설정하지 않아도 Siri에서 바로 사용할 수 있습니다. 요청 실행은 “Run a request in Echolot” 또는
“Send a request with Echolot”, 폴더 실행은 “Run a folder in Echolot” 또는 “Run the requests of a folder in Echolot”이라고
말하세요.

## 예시: 매일 아침 쇼핑몰 점검하기 [#example-check-the-shop-every-morning]

[데모 API](/docs/tutorials/demo-api)로 동작하는 Alpenglow 예제 작업 공간을 사용합니다.

<Steps>
<Step>
단축어 앱에서 새 단축어를 만들고 **폴더 실행**을 추가합니다. Alpenglow 작업 공간과 **Catalog** 폴더를 선택합니다.
</Step>
<Step>
**조건**을 추가하고, 입력으로 **실행 결과**의 **통과**를, 조건으로 **거짓임**을 선택합니다.
</Step>
<Step>
조건 안에 **알림 보기**를 추가하고 결과의 **요약**을 넣습니다. 실패한 모든 요청을 보려면 **실패**를 넣습니다.
</Step>
<Step>
**자동화**에서 매일 아침 단축어를 실행하는 개인용 자동화를 만듭니다.
</Step>
</Steps>
