ワークスペースは、それぞれ専用のウインドウで開きます。ウインドウは2つの部分でできています。左の**サイドバー**と、右の**コンテンツパネル**です。コンテンツパネルには、ページヘッダーの下に1度に1つのページが表示されます。

<Shot id="get-started-window" alt="Echolotのウインドウ：ホーム、検索、モジュールの切り替え、リクエストのツリーを表示したサイドバーと、右側にリクエストとそのレスポンス" />

## ようこそウインドウ [#the-welcome-window]

ワークスペースのウインドウが1つも開いていないとき、Echolotはようこそウインドウを表示します。**新規ワークスペース…**、**ワークスペースを開く…**、**サンプルを開く**、そして最近使ったワークスペースが並びます。
名前の下にはバージョンと**新機能**のリンクが表示されます。Finderから開いたワークスペース（`.echolot`フォルダをダブルクリック）は、そのままワークスペースのウインドウで開きます。

## サイドバー [#the-sidebar]

上から順に説明します。

- ウインドウのボタンの横にある**ホーム**と**検索**。**ホーム**（<kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd>）はワークスペースの概要で、リクエスト、フォルダ、環境、変数、チェックの件数、最近のリクエスト、最新のレスポンス、テストの状況、環境が表示されます。
  先頭には**Sonar**カードがあり、直近1時間・1日・1週間・1か月のすべての送信を、かかった時間に応じてプロットします。[ホームとSonar](/docs/get-started/home)を参照してください。
  **検索**は[コマンドパレット](#the-command-palette)（<kbd>⌘</kbd><kbd>K</kbd>）を開きます。
- サイドバーに何を一覧表示するかを選ぶ**モジュールの切り替え**。モジュールごとに専用のページがあります。
- **モジュールの一覧。**
- 下部にある**ワークスペースの切り替え**。

<kbd>⌘</kbd><kbd>B</kbd>（**表示 › サイドバーを非表示**）で、サイドバーの表示と非表示を切り替えます。右端をドラッグすると幅を変更できます。

### モジュール [#modules]

| モジュール | ショートカット | サイドバーの内容 | 詳細 |
| --- | --- | --- | --- |
| **リクエスト** | <kbd>⌘</kbd><kbd>1</kbd> | **テスト**と**ランナー**（状況つき）、続いてフォルダとリクエスト | [リクエスト](/docs/requests) |
| **MCPサーバ** | <kbd>⌘</kbd><kbd>2</kbd> | ワークスペースのMCPサーバ | [MCPサーバ](/docs/mcp-servers) |
| **仕様** | <kbd>⌘</kbd><kbd>3</kbd> | OpenAPIドキュメントと`.proto`ファイル | [仕様](/docs/specs) |
| **モック** | <kbd>⌘</kbd><kbd>4</kbd> | モックサーバ | [モック](/docs/mocks) |
| **フロー** | <kbd>⌘</kbd><kbd>5</kbd> | フロー | [フロー](/docs/flows) |

モジュールに切り替えると、前回表示していた内容に戻ります。一覧の行をクリックすると、そのモジュールのページで開きます。

### リクエストのツリー [#the-requests-tree]

リクエストモジュールでは、<strong>リクエスト</strong>の横の<strong>+</strong>ボタンから、あらゆる種類のリクエスト（HTTP、GraphQL、WebSocket、Socket.IO、MQTT、gRPC、MCP呼び出し）、フォルダの追加、読み込みと書き出しができます。
フォルダとリクエストの行にはそれぞれメニュー（右クリック）があり、<strong>新規リクエスト</strong>、<strong>新規フォルダ</strong>、<strong>フォルダ設定…</strong>、<strong>名前を変更</strong>、<strong>複製</strong>、<strong>上へ移動</strong>、<strong>下へ移動</strong>、<strong>Finderに表示</strong>、<strong>ゴミ箱に入れる…</strong>が並びます。

- 行をドラッグして並べ替えたり、フォルダに移動したりできます。移動先には隙間が開き、閉じたフォルダの上で止まるとそのフォルダが開きます。
- <kbd>⌘</kbd>または<kbd>⇧</kbd>で複数の行を選択して右クリックすると、<strong>N個の項目を実行</strong>、<strong>N件のリクエストを編集…</strong>、<strong>N個の項目から新規フォルダ</strong>、<strong>移動先</strong>、<strong>N個の項目をゴミ箱に入れる…</strong>が使えます。
- cURLコマンド、コレクション、仕様をサイドバーにペーストして[読み込む](/docs/get-started/importing)か、ファイルをウインドウにドロップします。
- **編集 › 複製**（<kbd>⌘</kbd><kbd>D</kbd>）と**編集 › 名前を変更**は、選択している行に対して実行されます。
- リクエストの横の点は、まだ書き込まれていない変更があることを示します。
- リクエストの横の警告マークは、直近の送信が失敗したことを示します。レスポンスがない、ステータスが400以上、またはgRPCのステータスがOK以外の場合です。ポインタを重ねると、何が問題だったかが表示されます。その後の送信が成功すると消えます。

確認なしに削除されるものはなく、削除した項目はゴミ箱に入ります。詳しくは[フォルダ](/docs/workspaces/folders)を参照してください。

### ワークスペースの切り替え [#the-workspace-switcher]

ワークスペースの名前と、その下に保存の状態が表示されます。**すべて保存済み**、**保存中…**、**保存できませんでした**のいずれかです。
クリックすると、最近使ったワークスペース、**新規ワークスペース…**、**ワークスペースを開く…**、**ワークスペース設定…**、**Finderに表示**が表示されます。
**ファイル › ワークスペースを切り替える…**（<kbd>⌘</kbd><kbd>P</kbd>）は、最近使ったワークスペースを浮動パネルに一覧表示します。入力で絞り込み、<kbd>Return</kbd>で開きます。

## ページヘッダー [#the-page-header]

コンテンツパネルの上部の帯に、ページの名前が表示されます。リクエストでは、リクエストのフォルダと名前が表示されます。右側にはウインドウのボタンがあります。

| ボタン | 動作 |
| --- | --- |
| **新機能**（きらめき） | アップデート後に、新しいリリースノートとともに表示されます。 |
| **履歴** | すべてのレスポンスと、送信者（自分、実行、エージェント）（<kbd>⌘</kbd><kbd>Y</kbd>）。[履歴](/docs/workspaces/history)を参照してください。 |
| **エージェント** | 外部のAIエージェントが、EcholotのMCPサーバを通じてこのワークスペースを使えるようにします。[エージェント](/docs/ai/agents)を参照してください。 |
| <strong>環境</strong> | 有効な環境、または<strong>環境なし</strong>を選びます。<strong>環境を管理…</strong>で環境のページが開きます。保護された環境には盾のマークが付きます。[環境](/docs/workspaces/environments)を参照してください。 |
| **レイアウト** | リクエストで、左右に並べるか上下に並べるかを選びます。[ペイン](#the-request-page)を参照してください。 |
| **エディタ** | 仕様で、ビジュアルエディタとテキストエディタを切り替えます。 |
| **アシスタント**（魔法の杖） | アシスタントを開きます（<kbd>⌘</kbd><kbd>J</kbd>）。 |

ヘッダーはタイトルバーの代わりです。ドラッグするとウインドウを移動でき、ダブルクリックすると、**システム設定 › デスクトップとDock**でタイトルバーに設定した動作（デフォルトでは拡大/縮小）になります。

## ページ [#pages]

モジュールのページのほかに、**表示**メニューから次のページを開けます。

| ページ | ショートカット |
| --- | --- |
| **ホーム** | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd> |
| **テスト**：すべてのリクエストのチェック | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>T</kbd> |
| **ランナー**：フォルダまたはワークスペースの実行 | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>R</kbd> |
| **環境** | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>E</kbd> |
| **履歴** | <kbd>⌘</kbd><kbd>Y</kbd> |

**表示 › 変数を表示**（<kbd>⌥</kbd><kbd>⌘</kbd><kbd>V</kbd>）は変数パネルを開きます。ワークスペース、フォルダ、環境にあるすべての変数が、使用中の値の印付き、シークレットはマスクされた状態で表示されます。コンテンツの横に列として固定することも、浮かせておくこともできます。

**ヘルプ › このページのヘルプ**は、表示しているページに関するこのドキュメントのページを開きます。

## タブ [#tabs]

開いたリクエストは、リクエストページの上にタブとして並びます。

| 操作 | ショートカット |
| --- | --- |
| **タブを閉じる** | <kbd>⌘</kbd><kbd>W</kbd> |
| **ウインドウを閉じる** | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd> |
| **タブ › 次のタブを表示** | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>]</kbd> |
| **タブ › 前のタブを表示** | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>[</kbd> |
| **タブ › 閉じたタブを再度開く** | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>T</kbd> |

<kbd>⌘</kbd><kbd>W</kbd>は、ブラウザと同じように、表示中のタブを閉じるだけで、ウインドウは閉じません。

## リクエストページ [#the-request-page]

リクエストページは、リクエストエディタとレスポンスの2つのペインでできています。

- 上部の<strong>リクエストヘッダー</strong>：メソッド、アドレス、<strong>送信</strong>（<kbd>⌘</kbd><kbd>R</kbd>または<kbd>⌘</kbd><kbd>↩</kbd>）。保護された環境が有効なときは、<strong>送信</strong>が<strong><em>環境</em>に送信…</strong>になり、先に確認が表示されます。
  セッション（WebSocket、Socket.IO、MQTT）には、代わりに<strong>接続</strong>と<strong>接続解除</strong>があります。
- **エディタのタブ**は、リクエストの種類によって変わります。HTTPリクエストには、**ドキュメント**、**ヘッダー**、**パラメータ**、**ボディ**、**認証**、**変数**、**テスト**、**スクリプト**、**設定**があります。[リクエスト](/docs/requests)を参照してください。
- **レスポンスのタブ**：**ボディ**、**テスト**、**ヘッダー**、**Cookie**、**生データ**、**16進数**、**通信**。さらに、スクリプトが実行されたときは**コンソール**、ストリームでは**イベント**、セッションでは**メッセージ**、GraphQLでは**スキーマ**が加わります。[レスポンス](/docs/requests/responses)を参照してください。

### ペインのレイアウト [#pane-layouts]

ペインは**左右に並べる**か**上下に並べる**（レスポンスが下）ことができます。ページヘッダーの**レイアウト**ボタン、または**表示 › ペイン**で選びます。
レイアウトと仕切りの位置は、リクエストの種類ごとに、このMacだけに保存されます。HTTPリクエストは左右に並べ、WebSocketリクエストは上下に並べることもできます。
仕切りをドラッグするとサイズを変更できます。**表示 › ペイン › ペインのサイズをリセット**で、すべての種類が元に戻ります。
左右に並べるにはウインドウが狭すぎる場合、余裕ができるまでペインは上下に並びます。

### リクエストメニュー [#the-request-menu]

| 項目 | ショートカット |
| --- | --- |
| **送信** | <kbd>⌘</kbd><kbd>R</kbd> |
| **キャンセル** | <kbd>⌘</kbd><kbd>.</kbd> |
| **cURLとしてコピー** | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>C</kbd> |
| **コードを生成…** | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>G</kbd> |
| **やり取りをHARとして書き出す…** | |
| **ボディ内を検索** | <kbd>⌘</kbd><kbd>F</kbd> |
| **コマンドパレット…** | <kbd>⌘</kbd><kbd>K</kbd> |

**表示 › コードを拡大**（<kbd>⌘</kbd><kbd>+</kbd>）、**コードを縮小**（<kbd>⌘</kbd><kbd>-</kbd>）、**実際のコードサイズ**（<kbd>⌘</kbd><kbd>0</kbd>）で、レスポンスのボディ、ツリー、コードエディタの文字サイズを変更します。
**表示 › 長い行を折り返す**で折り返します。

## コマンドパレット [#the-command-palette]

<kbd>⌘</kbd><kbd>K</kbd>、またはサイドバーの**検索**で、ワークスペース全体を検索します。数文字入力して、結果で<kbd>Return</kbd>を押します。

- **リクエスト**：フォルダとアドレスとともに表示されます。
- **アクション**：任意のページへの**移動**、**新規リクエスト**とその他の種類、**新規フォルダ**、**新規仕様**、**読み込む…**、**ワークスペースを書き出す…**、**ワークスペース設定…**、**変数を表示**、**ワークスペースを実行**。リクエストでは、**送信**、**cURLとしてコピー**、**コードを生成…**、**レイアウトを切り替える**、**ペインのサイズをリセット**も使えます。
- **環境**：**<em>環境</em>を使用**で、その環境に切り替えます。
- **レスポンス**：3文字以上入力すると、履歴のレスポンスも検索します。

## アシスタントパネル [#the-assistant-panel]

<kbd>⌘</kbd><kbd>J</kbd>（**表示 › アシスタントを表示**）、またはページヘッダーの端にある魔法の杖で、どのページでも右側にアシスタントが開きます。
アシスタントはEcholotに内蔵されたAIエージェントです。リクエストの送信、チェックの作成、フロー・仕様・モックの構築ができ、何かを変更する前に確認を求めます。
モデルは**設定 › アシスタント**で設定します。[アシスタント](/docs/ai/assistant)を参照してください。

## Echo [#echo]

Echoは、ページヘッダーの中央にある小さなステータス画面です。送信とその所要時間、エラー、実行、フロー、モック、エージェント、有効な環境など、今起きていることを伝え、ときどき冗談も言います。
クリックすると、セッションのレポートが表示されます。デフォルトではオフです。**設定 › 一般 › Echo**の**ページヘッダーにEchoのステータス画面を表示**でオンにします。[Echo](/docs/ai/echo)を参照してください。

## 設定 [#settings]

**Echolot › 設定…**（<kbd>⌘</kbd><kbd>,</kbd>）には、**一般**、**ネットワーク**、**ストレージ**、**アシスタント**、**エージェント**、**プライバシー**、**情報**のペインと、名前で設定を探せる検索フィールドがあります。[設定](/docs/settings)を参照してください。
1つのワークスペースまたはフォルダの設定は、**ワークスペース設定…**（**認証**、**変数**、**スクリプト**、**エージェント**、**プロキシ**、**証明書**）と**フォルダ設定…**（**認証**、**変数**、**スクリプト**、**ドキュメント**）にあります。

すべてのキーボードショートカットは、[キーボードショートカット](/docs/reference/keyboard-shortcuts)にまとめられています。
