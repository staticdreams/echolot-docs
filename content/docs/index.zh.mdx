Echolot 是一款原生 Mac App，用于发送、测试和构建 API。它支持 HTTP/1.1、HTTP/2 和 HTTP/3、GraphQL、gRPC、WebSocket、Server-Sent Events、Socket.IO、MQTT 和 MCP，并准确显示线路上传输的内容：原始字节、每一次重定向，以及每一步的耗时。

它能做什么：

- **把你的工作保存在纯文件中**。工作区是一个由可读的 TOML 文件组成的文件夹，每个请求一个文件，可以放进 Git。机密值保存在 macOS 钥匙串中，绝不写入文件。
- **测试和运行**。为任何请求添加检查，在运行器中运行一个文件夹或整个工作区，并用 `echolot` 命令行工具在 CI 中运行同一个工作区。
- **设计和模拟**。以可视化方式或文本方式编写 OpenAPI 规范，并运行本地模拟服务器：基于规范，或基于你手动创建、带有示例数据的路由。
- **自动化**。把请求、条件和循环在画布上串联成流程，可手动运行、按计划运行，或由 Webhook 触发。
- **与 AI 协作**。内置的助手使用你选择的模型来发送、测试和修复请求。外部 AI 智能体可以通过 Echolot 自己的 MCP 服务器使用你的工作区。任何会更改数据的操作都会先询问你。
- **读取超大响应**。正文以流的方式写入磁盘，因此 500 MB 的 JSON 响应也能立即打开。

Echolot 需要搭载 Apple 芯片、运行 macOS 15 或更高版本的 Mac。它没有账户，也无需登录。
