每个工作区都在自己的窗口中打开。窗口分为两部分：左侧的**边栏**，以及右侧的**内容面板**，后者在页面标题栏下方一次显示一个页面。

<Shot id="get-started-window" alt="Echolot 窗口：边栏中有主页、搜索、模块切换器和请求树，右侧是一个请求及其响应" />

## 欢迎窗口 [#the-welcome-window]

没有任何工作区窗口打开时，Echolot 会显示欢迎窗口：**新建工作区…**、**打开工作区…**、**打开示例**，以及你最近使用的工作区。名称下方显示版本，旁边有**新功能**链接。从访达打开的工作区（双击 `.echolot` 文件夹）会直接进入工作区窗口。

## 边栏 [#the-sidebar]

从上到下依次为：

- **主页**和**搜索**，位于窗口按钮旁边。**主页**（<kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd>）是工作区的概览：请求、文件夹、环境、变量和检查的数量，最近的请求，最新的响应，测试的情况，以及各个环境；顶部是 **Sonar** 卡片，它按耗时绘出最近一小时、一天、一周或一个月内的每一次发送。参见[主页与 Sonar](/docs/get-started/home)。**搜索**打开[命令面板](#the-command-palette)（<kbd>⌘</kbd><kbd>K</kbd>）。
- **模块切换器**，用于选择边栏列出的内容。每个模块都有自己的页面。
- **模块的列表。**
- 底部的**工作区切换器**。

<kbd>⌘</kbd><kbd>B</kbd>（**视图 › 隐藏边栏**）可隐藏和显示边栏。拖移它的右边缘可调整宽度。

### 模块 [#modules]

| 模块 | 快捷键 | 边栏列出的内容 | 详细了解 |
| --- | --- | --- | --- |
| **请求** | <kbd>⌘</kbd><kbd>1</kbd> | **测试**和**运行器**及其状态，然后是你的文件夹和请求 | [请求](/docs/requests) |
| **MCP 服务器** | <kbd>⌘</kbd><kbd>2</kbd> | 工作区的 MCP 服务器 | [MCP 服务器](/docs/mcp-servers) |
| **规范** | <kbd>⌘</kbd><kbd>3</kbd> | OpenAPI 文档和 `.proto` 文件 | [规范](/docs/specs) |
| **模拟服务器** | <kbd>⌘</kbd><kbd>4</kbd> | 模拟服务器 | [模拟服务器](/docs/mocks) |
| **流程** | <kbd>⌘</kbd><kbd>5</kbd> | 流程 | [流程](/docs/flows) |

切换到某个模块会回到它上次显示的内容。点按列表中的一行，会在该模块的页面上打开它。

### 请求树 [#the-requests-tree]

在“请求”模块中，**请求**旁边的 **+** 按钮可添加任意类型的请求（HTTP、GraphQL、WebSocket、Socket.IO、MQTT、gRPC 或 MCP 调用）、文件夹，也可以导入和导出。文件夹和请求行有各自的菜单（右键点按），包含**新建请求**、**新建文件夹**、**文件夹设置…**、**重新命名**、**复制**、**上移**、**下移**、**在访达中显示**和**移到废纸篓…**。

- 拖移行可重新排序，或把它们移入文件夹。落点处会让出空位，停留在已关闭的文件夹上会将其展开。
- 用 <kbd>⌘</kbd> 或 <kbd>⇧</kbd> 选择多行，再右键点按，可选取**运行 N 个项目**、**编辑 N 个请求…**、**用 N 个项目新建文件夹**、**移到**和**将 N 个项目移到废纸篓…**。
- 把 cURL 命令、集合或规范粘贴到边栏即可[导入](/docs/get-started/importing)，也可以把文件拖放到窗口上。
- **编辑 › 复制**（<kbd>⌘</kbd><kbd>D</kbd>）和**编辑 › 重新命名**作用于所选的行。
- 请求旁的圆点表示它有尚未写入的更改。
- 请求旁的警告标志表示它最近一次发送失败：没有响应、状态为 400 或更高，或者 gRPC 状态不是 OK。把指针停在上面可查看出了什么问题。之后一次成功的发送会清除它。

未经询问不会删除任何内容，删除的项目会移到废纸篓。详见[文件夹](/docs/workspaces/folders)。

### 工作区切换器 [#the-workspace-switcher]

显示工作区的名称，下方是它的存储状态：**已全部存储**、**正在存储…**或**无法存储**。点按它可看到最近使用的工作区、**新建工作区…**、**打开工作区…**、**工作区设置…**和**在访达中显示**。**文件 › 切换工作区…**（<kbd>⌘</kbd><kbd>P</kbd>）则在浮动面板中列出最近使用的工作区；输入文字可筛选，按 <kbd>Return</kbd> 打开。

## 页面标题栏 [#the-page-header]

内容面板顶部的横条显示页面的名称。在请求页面上，它显示请求所在的文件夹和请求名称。右侧是窗口的按钮：

| 按钮 | 作用 |
| --- | --- |
| **新功能**（闪光图标） | 更新后出现，附有新的发行说明。 |
| **历史记录** | 每个响应，以及发送者：你、某次运行或某个智能体（<kbd>⌘</kbd><kbd>Y</kbd>）。参见[历史记录](/docs/workspaces/history)。 |
| **智能体** | 允许外部 AI 智能体通过 Echolot 的 MCP 服务器使用此工作区。参见[智能体](/docs/ai/agents)。 |
| <strong>环境</strong> | 选择当前环境，或<strong>无环境</strong>；<strong>管理环境…</strong>会打开“环境”页面。受保护的环境带有盾牌图标。参见[环境](/docs/workspaces/environments)。 |
| **布局** | 在请求上：并排或堆叠。参见[窗格](#the-request-page)。 |
| **编辑器** | 在规范上：可视化编辑器或文本编辑器。 |
| **助手**（魔棒） | 打开助手（<kbd>⌘</kbd><kbd>J</kbd>）。 |

标题栏代替了窗口的标题栏：拖移它可移动窗口，双击它会执行**系统设置 › 桌面与程序坞**中为标题栏设定的操作（默认是缩放）。

## 页面 [#pages]

除了各模块的页面，**视图**菜单还可以打开以下页面：

| 页面 | 快捷键 |
| --- | --- |
| **主页** | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd> |
| **测试**：每个请求的检查 | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>T</kbd> |
| **运行器**：运行文件夹或整个工作区 | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>R</kbd> |
| **环境** | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>E</kbd> |
| **历史记录** | <kbd>⌘</kbd><kbd>Y</kbd> |

**视图 › 显示变量**（<kbd>⌥</kbd><kbd>⌘</kbd><kbd>V</kbd>）会打开变量面板：列出整个工作区、其文件夹和环境中的每个变量，标出正在使用的值，并遮蔽机密。可以把它固定为内容旁边的一栏，也可以让它浮动。

**帮助 › 此页面的帮助**会打开这些文档中与你当前所在页面对应的页面。

## 标签页 [#tabs]

你打开的请求会成为请求页面上方的标签页。

| 操作 | 快捷键 |
| --- | --- |
| **关闭标签页** | <kbd>⌘</kbd><kbd>W</kbd> |
| **关闭窗口** | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd> |
| **标签页 › 显示下一个标签页** | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>]</kbd> |
| **标签页 › 显示上一个标签页** | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>[</kbd> |
| **标签页 › 重新打开已关闭的标签页** | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>T</kbd> |

<kbd>⌘</kbd><kbd>W</kbd> 关闭的是屏幕上的标签页，而不是窗口，与浏览器相同。

## 请求页面 [#the-request-page]

请求页面有两个窗格：请求编辑器和响应。

- **顶部的请求标题栏**：方法、地址和**发送**（<kbd>⌘</kbd><kbd>R</kbd> 或 <kbd>⌘</kbd><kbd>↩</kbd>）。启用受保护的环境时，**发送**显示为**发送到 *environment*…**，并会先询问。会话（WebSocket、Socket.IO、MQTT）则改为**连接**和**断开连接**。
- **编辑器的标签页**取决于请求的类型。HTTP 请求有**文档**、**标头**、**参数**、**正文**、**认证**、**变量**、**测试**、**脚本**和**设置**。参见[请求](/docs/requests)。
- **响应的标签页**：**正文**、**测试**、**标头**、**Cookie**、**原始**、**十六进制**和**传输**，另外在脚本运行过时有**控制台**，流有**事件**，会话有**消息**，GraphQL 有 **Schema**。参见[响应](/docs/requests/responses)。

### 窗格布局 [#pane-layouts]

窗格可以**并排**或**堆叠**（响应在下方）。可用页面标题栏中的**布局**按钮选择，也可用**视图 › 窗格**。每种请求都会保留自己的布局和分隔条位置，仅限这台 Mac：HTTP 请求可以并排，而 WebSocket 请求堆叠。拖移分隔条可调整大小；**视图 › 窗格 › 重置窗格大小**会让每种请求恢复默认。当窗口太窄、放不下并排布局时，窗格会堆叠，直到空间足够。

| 项目 | 快捷键 |
| --- | --- |
| **发送** | <kbd>⌘</kbd><kbd>R</kbd> |
| **取消** | <kbd>⌘</kbd><kbd>.</kbd> |
| **拷贝为 cURL** | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>C</kbd> |
| **生成代码…** | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>G</kbd> |
| **将交换记录导出为 HAR…** | |
| **在正文中查找** | <kbd>⌘</kbd><kbd>F</kbd> |
| **命令面板…** | <kbd>⌘</kbd><kbd>K</kbd> |

**视图 › 放大代码**（<kbd>⌘</kbd><kbd>+</kbd>）、**缩小代码**（<kbd>⌘</kbd><kbd>-</kbd>）和**实际代码大小**（<kbd>⌘</kbd><kbd>0</kbd>）可更改响应正文、树和代码编辑器的大小。**视图 › 自动换行**会让它们自动换行。

## 命令面板 [#the-command-palette]

<kbd>⌘</kbd><kbd>K</kbd> 或边栏中的**搜索**会打开对整个工作区的搜索。输入几个字母，然后在某个结果上按 <kbd>Return</kbd>：

- **请求**，附有所在的文件夹和地址。
- **动作**：**前往**任意页面、**新建请求**及其他类型、**新建文件夹**、**新建规范**、**导入…**、**导出工作区…**、**工作区设置…**、**显示变量**、**运行工作区**，以及在请求上的**发送**、**拷贝为 cURL**、**生成代码…**、**切换布局**和**重置窗格大小**。
- **环境**：**使用 *environment*** 会切换到该环境。
- **响应**：输入三个字符起，也会搜索历史记录中的响应。

<Shot id="get-started-command-palette" alt="工作区上方的命令面板，其中的请求、操作和环境与输入的文字相匹配" />

## 助手面板 [#the-assistant-panel]

<kbd>⌘</kbd><kbd>J</kbd>（**视图 › 显示助手**）或页面标题栏末端的魔棒，会在任意页面的右侧打开助手。它是内置于 Echolot 的 AI 智能体：可以发送请求、编写检查、构建流程、规范和模拟服务器，并在更改任何内容之前询问你。请在**设置 › 助手**中配置模型。参见[助手](/docs/ai/assistant)。

## Echo [#echo]

Echo 是页面标题栏中间的一块小状态屏。它显示正在发生的事：发送及其耗时、错误、运行、流程、模拟服务器、智能体和当前环境，偶尔还会开个玩笑。点按它可查看本次会话的报告。它默认关闭：请在**设置 › 通用 › Echo** 中开启**在页面标题栏中显示 Echo 的状态屏幕**。参见 [Echo](/docs/ai/echo)。

## 设置 [#settings]

**Echolot › 设置…**（<kbd>⌘</kbd><kbd>,</kbd>）包含**通用**、**网络**、**储存空间**、**助手**、**智能体**、**隐私**和**关于**窗格，以及按名称查找设置的搜索栏。参见[设置](/docs/settings)。单个工作区或文件夹的设置位于**工作区设置…**（**认证**、**变量**、**脚本**、**智能体**、**代理**、**证书**）和**文件夹设置…**（**认证**、**变量**、**脚本**、**文档**）。

所有键盘快捷键都列在[键盘快捷键](/docs/reference/keyboard-shortcuts)中。
