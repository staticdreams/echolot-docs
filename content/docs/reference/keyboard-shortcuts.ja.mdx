---
title: "キーボードショートカット"
description: "Echolotのすべてのキーボードショートカット。メニューのものもページ上のものも、使う場所ごとにまとめています。"
---

メニューのすべての操作には、横にショートカットが表示されています。このページでは、それらに加えて、ページやリストで使えるキーをまとめています。<kbd>⌘</kbd>はCommand、<kbd>⌥</kbd>はOption、<kbd>⇧</kbd>はShift、<kbd>⌃</kbd>はControlです。

## ワークスペースとファイル [#workspaces-and-files]

| 操作 | キー | メニュー |
| --- | --- | --- |
| 新規リクエスト | <kbd>⌘</kbd><kbd>N</kbd> | ファイル |
| 新規フォルダ | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>N</kbd> | ファイル（サイドバーにリクエストが表示されているとき） |
| 新規ワークスペース… | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>N</kbd> | ファイル |
| ワークスペースを開く… | <kbd>⌘</kbd><kbd>O</kbd> | ファイル |
| ワークスペースを切り替える… | <kbd>⌘</kbd><kbd>P</kbd> | ファイル |
| タブを閉じる | <kbd>⌘</kbd><kbd>W</kbd> | ファイル |
| ウインドウを閉じる | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd> | ファイル |
| 読み込む… | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>I</kbd> | ファイル |
| ワークスペースを書き出す… | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>E</kbd> | ファイル |
| 複製 | <kbd>⌘</kbd><kbd>D</kbd> | 編集 |
| 取り消す、やり直す | <kbd>⌘</kbd><kbd>Z</kbd>、<kbd>⇧</kbd><kbd>⌘</kbd><kbd>Z</kbd> | 編集 |
| 設定 | <kbd>⌘</kbd><kbd>,</kbd> | Echolot |

<kbd>⌘</kbd><kbd>W</kbd>は表示中のタブを閉じ、ワークスペースのウインドウは閉じません。ウインドウを閉じるのは<kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd>です。
設定など、ほかのウインドウでは、<kbd>⌘</kbd><kbd>W</kbd>でそのウインドウが閉じます。

ファイルメニューの**新規GraphQLリクエスト**、**新規WebSocketリクエスト**、**新規Socket.IOリクエスト**、**新規MQTTリクエスト**、**新規gRPCリクエスト**、そして**フォルダを書き出す…**と**名前を変更**には、ショートカットがありません。

| 閉じたタブを再度開く | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>T</kbd> | タブ |

## ページとパネル [#pages-and-panels]

| 操作 | キー | メニュー |
| --- | --- | --- |
| リクエスト | <kbd>⌘</kbd><kbd>1</kbd> | 表示 |
| MCPサーバ | <kbd>⌘</kbd><kbd>2</kbd> | 表示 |
| 仕様 | <kbd>⌘</kbd><kbd>3</kbd> | 表示 |
| モック | <kbd>⌘</kbd><kbd>4</kbd> | 表示 |
| フロー | <kbd>⌘</kbd><kbd>5</kbd> | 表示 |
| ホーム | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd> | 表示 |
| テスト | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>T</kbd> | 表示 |
| ランナー | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>R</kbd> | 表示 |
| 環境 | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>E</kbd> | 表示 |
| 履歴 | <kbd>⌘</kbd><kbd>Y</kbd> | 表示 |
| サイドバーを表示、サイドバーを非表示 | <kbd>⌘</kbd><kbd>B</kbd> | 表示 |
| アシスタントを表示、アシスタントを非表示 | <kbd>⌘</kbd><kbd>J</kbd> | 表示 |
| 変数を表示、変数を非表示 | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>V</kbd> | 表示 |
| コマンドパレット… | <kbd>⌘</kbd><kbd>K</kbd> | リクエスト |

<kbd>⌘</kbd><kbd>1</kbd>から<kbd>⌘</kbd><kbd>5</kbd>は、サイドバーのモジュールを切り替え、そのモジュールで最後に表示していたものに戻ります。[ウインドウ](/docs/get-started/the-window)を参照してください。

## リクエストとレスポンス [#requests-and-responses]

| 操作 | キー | メニュー |
| --- | --- | --- |
| 送信 | <kbd>⌘</kbd><kbd>R</kbd>または<kbd>⌘</kbd><kbd>↩</kbd> | リクエスト |
| キャンセル | <kbd>⌘</kbd><kbd>.</kbd> | リクエスト |
| cURLとしてコピー | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>C</kbd> | リクエスト |
| コードを生成… | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>G</kbd> | リクエスト |
| ボディ内を検索 | <kbd>⌘</kbd><kbd>F</kbd> | リクエスト |
| 次の一致、前の一致 | <kbd>⌘</kbd><kbd>G</kbd>、<kbd>⇧</kbd><kbd>⌘</kbd><kbd>G</kbd> | （検索バー内） |

[保護された環境](/docs/workspaces/protected-environments)が有効な間、この項目は<strong>&lt;環境&gt;に送信…</strong>と表示され、先に確認が表示されます。そこでは<strong>キャンセル</strong>がデフォルトのボタンなので、<kbd>↩</kbd>で誤って送信されることはありません。

リクエストメニューの<strong>やり取りをHARとして書き出す…</strong>には、ショートカットがありません。

## コードのサイズ [#code-size]

| 操作 | キー | メニュー |
| --- | --- | --- |
| コードを拡大 | <kbd>⌘</kbd><kbd>+</kbd> | 表示 |
| コードを縮小 | <kbd>⌘</kbd><kbd>-</kbd> | 表示 |
| 実際のコードサイズ | <kbd>⌘</kbd><kbd>0</kbd> | 表示 |

表示メニューの**長い行を折り返す**と**ペイン › ペインのサイズをリセット**には、ショートカットがありません。

| 太字、斜体 | <kbd>⌘</kbd><kbd>B</kbd>、<kbd>⌘</kbd><kbd>I</kbd> | リクエストまたはフォルダのドキュメントエディタ |

## サイドバー [#the-sidebar]

| 操作 | キー |
| --- | --- |
| 選択を移動 | <kbd>↑</kbd>、<kbd>↓</kbd> |
| フォルダを開く | <kbd>→</kbd> |
| フォルダを閉じる、または1つ上のフォルダへ移動 | <kbd>←</kbd> |
| 選択項目の名前を変更 | <kbd>↩</kbd> |
| 名前の変更を終了 | <kbd>Esc</kbd> |
| リクエストをゴミ箱に入れる | <kbd>⌫</kbd>（先に確認が表示されます） |

<kbd>⌫</kbd>が使えるのは、リクエスト1件のときだけです。フォルダや複数の項目を削除するキーはありません。コンテキストメニューの**ゴミ箱に入れる…**（または**N個の項目をゴミ箱に入れる…**）を使うと、先に確認が表示されます。
MCPサーバページでは、<kbd>⌫</kbd>で選択したサーバを削除するかどうかを確認します。

| 閉じる | <kbd>Esc</kbd> | コマンドパレット、クイック送信 |

## フロー [#flows]

| 操作 | キー |
| --- | --- |
| 実行、または<strong>&lt;環境&gt;で実行…</strong> | <kbd>⌘</kbd><kbd>R</kbd> |
| 実行を停止 | <kbd>⌘</kbd><kbd>.</kbd> |
| ブロックを追加 | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>B</kbd> |
| 選択したブロックを複製 | <kbd>⌘</kbd><kbd>D</kbd> |
| 全体表示：フロー全体を表示 | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>0</kbd> |
| ブロックをコピー、カット、ペースト（ブロック間の接続も含む） | <kbd>⌘</kbd><kbd>C</kbd>、<kbd>⌘</kbd><kbd>X</kbd>、<kbd>⌘</kbd><kbd>V</kbd> |
| 選択項目を削除 | <kbd>⌫</kbd> |
| ある方向の最も近いブロックを選択 | <kbd>↑</kbd>、<kbd>↓</kbd>、<kbd>←</kbd>、<kbd>→</kbd> |
| 選択を解除 | <kbd>Esc</kbd> |
| 選択ボックスを描く | <kbd>⇧</kbd>または<kbd>⌘</kbd>を押しながらキャンバス上をドラッグ |

何もないキャンバス上でそのままドラッグすると、キャンバスが移動します。[フロー](/docs/flows)を参照してください。

## クイック送信 [#quick-send]

| 操作 | キー |
| --- | --- |
| どのアプリからでもクイック送信を開く | <kbd>⌃</kbd><kbd>⌥</kbd><kbd>Space</kbd> |

クイック送信は、**設定 › 一般**でオンにするまで使えません。そこで別のショートカットを記録することもできます。[クイック送信](/docs/mac/quick-send)を参照してください。

## 設定とヘルプ [#settings-and-help]

| 操作 | キー | 使える場所 |
| --- | --- | --- |
| 設定を検索 | <kbd>⌘</kbd><kbd>F</kbd> | 設定 |
| Echolotドキュメント | <kbd>⌘</kbd><kbd>?</kbd> | ヘルプメニュー |

**このページのヘルプ**は、最前面のウインドウに表示されているページについてのドキュメントのページを開きます。

## シートとダイアログ [#sheets-and-dialogs]

<kbd>↩</kbd>でデフォルトのボタンを選択し、<kbd>Esc</kbd>でキャンセルします。何かを削除するダイアログの赤いボタンにはキーがないため、必ずクリックして操作します。
