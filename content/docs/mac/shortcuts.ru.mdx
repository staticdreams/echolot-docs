Echolot добавляет в приложение «Быстрые команды» два действия: **Запустить запрос** и **Запустить папку**. Они
отправляют сохранённые запросы вместе с их проверками, как [Прогон](/docs/requests/runner), и передают итог следующему
действию. С их помощью можно проверять API каждое утро, по сочетанию клавиш или голосовой просьбой к Siri. Пока
действия выполняются, Echolot не выходит на передний план.

## Действия [#the-actions]

Найдите их в приложении «Быстрые команды», введя в поиск Echolot, в разделе **Запросы**.

### Запустить запрос [#run-request]

Отправляет один сохранённый запрос рабочего пространства вместе с его проверками и возвращает итог. В редакторе оно
выглядит так: **Запустить *запрос* в *рабочем пространстве***.

| Параметр | Что выбрать |
| --- | --- |
| **Рабочее пространство** | Рабочее пространство, открытое в Echolot, или одно из недавних. |
| **Запрос** | Сохранённый запрос этого рабочего пространства. У каждого видны метод и путь. |
| **Окружение** | Необязательно. Название окружения, как его показывает рабочее пространство, или его slug. Если поле пустое, берётся окружение, которое рабочее пространство использует в своём окне, или использовавшееся последним. |

### Запустить папку [#run-folder]

Запускает по порядку все запросы папки вместе с их проверками и возвращает итог. В редакторе оно выглядит так:
**Запустить *папку* в *рабочем пространстве***.

| Параметр | Что выбрать |
| --- | --- |
| **Рабочее пространство** | Рабочее пространство, открытое в Echolot, или одно из недавних. |
| **Папка** | Папка этого рабочего пространства или **Всё рабочее пространство (*название*)** для всех запросов. |
| **Окружение** | Необязательно, как в действии «Запустить запрос». |

Запросы выполняются со своими скриптами и проверками, а их ответы попадают в [историю](/docs/workspaces/history)
рабочего пространства, как при запуске из его окна. Рабочее пространство не обязательно открывать.

<Edition only="appstore">
  Действия работают так же и в редакции для App Store. Рабочее пространство, которое не открыто, доступно через
  разрешение, выданное Echolot, когда вы его открывали.
</Edition>

## Итог [#the-outcome]

Оба действия возвращают следующему действию **Итог прогона** и показывают его сводку, когда команда завершается.

| Свойство | Что в нём |
| --- | --- |
| **Пройдено** | Выполнен ли каждый запрос без ошибки и пройдена ли каждая проверка (пропущенные проверки не считаются). |
| **Запросы** | Сколько запросов выполнено. |
| **Запросы с ошибкой** | Сколько из них завершилось ошибкой. |
| **Статус** | Код состояния, для одного запроса. |
| **Длительность (мс)** | Время в миллисекундах, для одного запроса. |
| **Сводка** | Одна строка, например `GET List products: 200 in 182 ms, 3 of 3 checks passed` для одного запроса или `2 of 9 requests failed` для папки. |
| **Ошибки** | Одна строка на каждый запрос с ошибкой: его название и ошибка или непройденные проверки. |

## Защищённые окружения [#protected-environments]

Если окружение [защищено](/docs/workspaces/protected-environments), «Быстрые команды» спрашивают разрешения до
отправки и показывают окружение и то, что будет отправлено. Если отказаться, действие завершается, и ничего не
отправляется.

## Siri [#siri]

Действия Echolot готовы для Siri без создания команды: скажите «Запусти запрос в Echolot» или «Отправь запрос через
Echolot» для действия «Запустить запрос» и «Запусти папку в Echolot» или «Запусти запросы папки в Echolot» для
действия «Запустить папку».

## Пример: проверять магазин каждое утро [#example-check-the-shop-every-morning]

Возьмём пример рабочего пространства Alpenglow, которое работает с [демо-API](/docs/tutorials/demo-api):

<Steps>
<Step>
В приложении «Быстрые команды» создайте новую команду и добавьте **Запустить папку**. Выберите рабочее пространство
Alpenglow и папку **Catalog**.
</Step>
<Step>
Добавьте **Если**, указав на входе **Пройдено** из **Итога прогона** и условие **ложь**.
</Step>
<Step>
Внутри «Если» добавьте **Показать уведомление** со **Сводкой** итога или с **Ошибками**, чтобы увидеть каждый
запрос с ошибкой.
</Step>
<Step>
В разделе **Автоматизация** создайте личную автоматизацию, которая запускает команду каждое утро.
</Step>
</Steps>
