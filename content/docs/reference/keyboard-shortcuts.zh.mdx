---
title: "键盘快捷键"
description: "Echolot 中的所有键盘快捷键，包括菜单中的和页面上的，按使用场景分组。"
---

菜单中的每个操作旁边都有它的快捷键。本页把它们汇总在一起，并补充了在页面或列表中可用的按键。<kbd>⌘</kbd> 是 Command，<kbd>⌥</kbd> 是 Option，<kbd>⇧</kbd> 是 Shift，<kbd>⌃</kbd> 是 Control。

## 工作区和文件 [#workspaces-and-files]

| 操作 | 按键 | 菜单 |
| --- | --- | --- |
| 新建请求 | <kbd>⌘</kbd><kbd>N</kbd> | 文件 |
| 新建文件夹 | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>N</kbd> | 文件（边栏显示“请求”时） |
| 新建工作区… | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>N</kbd> | 文件 |
| 打开工作区… | <kbd>⌘</kbd><kbd>O</kbd> | 文件 |
| 切换工作区… | <kbd>⌘</kbd><kbd>P</kbd> | 文件 |
| 关闭标签页 | <kbd>⌘</kbd><kbd>W</kbd> | 文件 |
| 关闭窗口 | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd> | 文件 |
| 导入… | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>I</kbd> | 文件 |
| 导出工作区… | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>E</kbd> | 文件 |
| 复制 | <kbd>⌘</kbd><kbd>D</kbd> | 编辑 |
| 撤销、重做 | <kbd>⌘</kbd><kbd>Z</kbd>、<kbd>⇧</kbd><kbd>⌘</kbd><kbd>Z</kbd> | 编辑 |
| 设置 | <kbd>⌘</kbd><kbd>,</kbd> | Echolot |

<kbd>⌘</kbd><kbd>W</kbd> 关闭屏幕上的标签页，而不会关闭工作区窗口；<kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd> 关闭窗口。在其他窗口（例如“设置”）中，<kbd>⌘</kbd><kbd>W</kbd> 关闭该窗口。

“文件”菜单中的**新建 GraphQL 请求**、**新建 WebSocket 请求**、**新建 Socket.IO 请求**、**新建 MQTT 请求**和**新建 gRPC 请求**，以及**导出文件夹…**和**重新命名**没有快捷键。

| 操作 | 按键 | 菜单 |
| --- | --- | --- |
| 请求 | <kbd>⌘</kbd><kbd>1</kbd> | 视图 |
| MCP 服务器 | <kbd>⌘</kbd><kbd>2</kbd> | 视图 |
| 规范 | <kbd>⌘</kbd><kbd>3</kbd> | 视图 |
| 模拟服务器 | <kbd>⌘</kbd><kbd>4</kbd> | 视图 |
| 流程 | <kbd>⌘</kbd><kbd>5</kbd> | 视图 |
| 主页 | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd> | 视图 |
| 测试 | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>T</kbd> | 视图 |
| 运行器 | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>R</kbd> | 视图 |
| 环境 | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>E</kbd> | 视图 |
| 历史记录 | <kbd>⌘</kbd><kbd>Y</kbd> | 视图 |
| 显示边栏、隐藏边栏 | <kbd>⌘</kbd><kbd>B</kbd> | 视图 |
| 显示助手、隐藏助手 | <kbd>⌘</kbd><kbd>J</kbd> | 视图 |
| 显示变量、隐藏变量 | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>V</kbd> | 视图 |
| 命令面板… | <kbd>⌘</kbd><kbd>K</kbd> | 请求 |

<kbd>⌘</kbd><kbd>1</kbd> 到 <kbd>⌘</kbd><kbd>5</kbd> 会切换边栏的模块，并回到它上次显示的内容。参见[窗口](/docs/get-started/the-window)。

## 请求和响应 [#requests-and-responses]

| 操作 | 按键 | 菜单 |
| --- | --- | --- |
| 发送 | <kbd>⌘</kbd><kbd>R</kbd> 或 <kbd>⌘</kbd><kbd>↩</kbd> | 请求 |
| 取消 | <kbd>⌘</kbd><kbd>.</kbd> | 请求 |
| 拷贝为 cURL | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>C</kbd> | 请求 |
| 生成代码… | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>G</kbd> | 请求 |
| 在正文中查找 | <kbd>⌘</kbd><kbd>F</kbd> | 请求 |
| 下一个匹配项、上一个匹配项 | <kbd>⌘</kbd><kbd>G</kbd>、<kbd>⇧</kbd><kbd>⌘</kbd><kbd>G</kbd> | （在查找栏中） |

当[受保护的环境](/docs/workspaces/protected-environments)处于活动状态时，该菜单项显示为**发送到 &lt;环境&gt;…**，并会先询问。**取消**是那里的默认按钮，因此按 <kbd>↩</kbd> 绝不会误发送。

“请求”菜单中的<strong>将交换记录导出为 HAR…</strong>没有快捷键。

## 边栏 [#the-sidebar]

| 操作 | 按键 |
| --- | --- |
| 移动选择 | <kbd>↑</kbd>、<kbd>↓</kbd> |
| 展开文件夹 | <kbd>→</kbd> |
| 收起文件夹，或回到上一级文件夹 | <kbd>←</kbd> |
| 重新命名所选项 | <kbd>↩</kbd> |
| 停止重新命名 | <kbd>Esc</kbd> |
| 将请求移到废纸篓 | <kbd>⌫</kbd>（会先询问） |

<kbd>⌫</kbd> 只对单个请求有效。没有任何按键可以删除文件夹或多个项目：请使用上下文菜单中的**移到废纸篓…**（或**将 N 个项目移到废纸篓…**），它会先询问。在“MCP 服务器”页面中，<kbd>⌫</kbd> 会提示删除所选的服务器。

## 流程 [#flows]

| 操作 | 按键 |
| --- | --- |
| 运行，或**在 &lt;环境&gt; 中运行…** | <kbd>⌘</kbd><kbd>R</kbd> |
| 停止运行 | <kbd>⌘</kbd><kbd>.</kbd> |

## 快速发送 [#quick-send]

| 操作 | 按键 |
| --- | --- |
| 在任何 App 中打开快速发送 | <kbd>⌃</kbd><kbd>⌥</kbd><kbd>Space</kbd> |

快速发送默认关闭，需要在**设置 › 通用**中打开，在那里也可以录制其他快捷键。参见[快速发送](/docs/mac/quick-send)。

## 设置和帮助 [#settings-and-help]

| 操作 | 按键 | 位置 |
| --- | --- | --- |
| 搜索设置 | <kbd>⌘</kbd><kbd>F</kbd> | 设置 |

**此页面的帮助**会打开与最前面窗口中的页面相关的文档页面。

## 表单和对话框 [#sheets-and-dialogs]

<kbd>↩</kbd> 选择默认按钮，<kbd>Esc</kbd> 取消。执行删除操作的对话框，其红色按钮没有对应的按键，因此你总是要点按它。
