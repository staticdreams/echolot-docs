---
title: "Tastaturkurzbefehle"
description: "Alle Tastaturkurzbefehle in Echolot, aus den Menüs und von den Seiten, gruppiert danach, wo du sie verwendest."
---

Jede Aktion in den Menüs hat ihren Kurzbefehl daneben. Diese Seite sammelt sie, zusammen mit den Tasten, die auf einer
Seite oder in einer Liste funktionieren. <kbd>⌘</kbd> ist die Befehlstaste, <kbd>⌥</kbd> die Wahltaste, <kbd>⇧</kbd> die
Umschalttaste, <kbd>⌃</kbd> die Control-Taste.

## Arbeitsbereiche und Dateien [#workspaces-and-files]

| Aktion | Tasten | Menü |
| --- | --- | --- |
| Neue Anfrage | <kbd>⌘</kbd><kbd>N</kbd> | Datei |
| Neuer Ordner | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>N</kbd> | Datei (solange die Seitenleiste Anfragen zeigt) |
| Neuer Arbeitsbereich … | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>N</kbd> | Datei |
| Arbeitsbereich öffnen … | <kbd>⌘</kbd><kbd>O</kbd> | Datei |
| Arbeitsbereich wechseln … | <kbd>⌘</kbd><kbd>P</kbd> | Datei |
| Tab schließen | <kbd>⌘</kbd><kbd>W</kbd> | Datei |
| Fenster schließen | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd> | Datei |
| Importieren … | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>I</kbd> | Datei |
| Arbeitsbereich exportieren … | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>E</kbd> | Datei |
| Duplizieren | <kbd>⌘</kbd><kbd>D</kbd> | Bearbeiten |
| Widerrufen, Wiederholen | <kbd>⌘</kbd><kbd>Z</kbd>, <kbd>⇧</kbd><kbd>⌘</kbd><kbd>Z</kbd> | Bearbeiten |
| Einstellungen | <kbd>⌘</kbd><kbd>,</kbd> | Echolot |

<kbd>⌘</kbd><kbd>W</kbd> schließt den Tab auf dem Bildschirm, nie das Arbeitsbereichsfenster;
<kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd> schließt das Fenster. In anderen Fenstern, etwa den Einstellungen, schließt
<kbd>⌘</kbd><kbd>W</kbd> das Fenster.

Die Einträge **Neue GraphQL-Anfrage**, **Neue WebSocket-Anfrage**, **Neue Socket.IO-Anfrage**, **Neue MQTT-Anfrage** und
**Neue gRPC-Anfrage** im Menü „Datei“, **Ordner exportieren …** und **Umbenennen** haben keinen Kurzbefehl.

| MCP-Server | <kbd>⌘</kbd><kbd>2</kbd> | Ansicht |
| Specs | <kbd>⌘</kbd><kbd>3</kbd> | Ansicht |

| Tests | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>T</kbd> | Ansicht |
| Ausführung | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>R</kbd> | Ansicht |

<kbd>⌘</kbd><kbd>1</kbd> bis <kbd>⌘</kbd><kbd>5</kbd> wechseln das Modul der Seitenleiste und gehen zu dem zurück, was
sie zuletzt zeigte. Siehe [das Fenster](/docs/get-started/the-window).

## Anfragen und Antworten [#requests-and-responses]

| Aktion | Tasten | Menü |
| --- | --- | --- |
| Senden | <kbd>⌘</kbd><kbd>R</kbd> oder <kbd>⌘</kbd><kbd>↩</kbd> | Anfrage |
| Abbrechen | <kbd>⌘</kbd><kbd>.</kbd> | Anfrage |
| Als cURL kopieren | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>C</kbd> | Anfrage |
| Code erzeugen … | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>G</kbd> | Anfrage |
| Im Body suchen | <kbd>⌘</kbd><kbd>F</kbd> | Anfrage |
| Nächster Treffer, vorheriger Treffer | <kbd>⌘</kbd><kbd>G</kbd>, <kbd>⇧</kbd><kbd>⌘</kbd><kbd>G</kbd> | (in der Suchleiste) |

Solange eine [geschützte Umgebung](/docs/workspaces/protected-environments) aktiv ist, lautet der Eintrag **An
&lt;Umgebung&gt; senden …** und fragt zuerst nach. **Abbrechen** ist dort der Standardknopf, <kbd>↩</kbd> sendet also nie
versehentlich.

**Austausch als HAR exportieren …** im Menü „Anfrage“ hat keinen Kurzbefehl.

## Die Seitenleiste [#the-sidebar]

| Aktion | Tasten |
| --- | --- |
| Die Auswahl bewegen | <kbd>↑</kbd>, <kbd>↓</kbd> |
| Einen Ordner öffnen | <kbd>→</kbd> |
| Einen Ordner schließen oder zum Ordner darüber gehen | <kbd>←</kbd> |
| Die Auswahl umbenennen | <kbd>↩</kbd> |
| Das Umbenennen beenden | <kbd>Esc</kbd> |
| Eine Anfrage in den Papierkorb legen | <kbd>⌫</kbd> (fragt zuerst nach) |

<kbd>⌫</kbd> funktioniert nur bei einer einzelnen Anfrage. Keine Taste löscht einen Ordner oder mehrere Objekte: Verwende
**In den Papierkorb legen …** (oder **N Objekte in den Papierkorb legen …**) im Kontextmenü, das zuerst nachfragt. Auf der
Seite „MCP-Server“ bietet <kbd>⌫</kbd> an, den ausgewählten Server zu löschen.

## Flows [#flows]

| Aktion | Tasten |
| --- | --- |
| Ausführen oder **In &lt;Umgebung&gt; ausführen …** | <kbd>⌘</kbd><kbd>R</kbd> |
| Den Durchlauf stoppen | <kbd>⌘</kbd><kbd>.</kbd> |
| Einen Block hinzufügen | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>B</kbd> |
| Die ausgewählten Blöcke duplizieren | <kbd>⌘</kbd><kbd>D</kbd> |
| Einpassen: den ganzen Flow zeigen | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>0</kbd> |
| Blöcke kopieren, ausschneiden, einsetzen (mit den Verbindungen zwischen ihnen) | <kbd>⌘</kbd><kbd>C</kbd>, <kbd>⌘</kbd><kbd>X</kbd>, <kbd>⌘</kbd><kbd>V</kbd> |

## Schnellversand [#quick-send]

| Aktion | Tasten |
| --- | --- |
| Den Schnellversand aus jeder App öffnen | <kbd>⌃</kbd><kbd>⌥</kbd><kbd>Space</kbd> |

Der Schnellversand ist ausgeschaltet, bis du ihn unter **Einstellungen › Allgemein** einschaltest, wo du auch einen
anderen Kurzbefehl aufnehmen kannst. Siehe [Schnellversand](/docs/mac/quick-send).

## Einstellungen und Hilfe [#settings-and-help]

| Aktion | Tasten | Wo |
| --- | --- | --- |
| Die Einstellungen durchsuchen | <kbd>⌘</kbd><kbd>F</kbd> | Einstellungen |
| Echolot-Dokumentation | <kbd>⌘</kbd><kbd>?</kbd> | Menü „Hilfe“ |

**Hilfe zu dieser Seite** öffnet die Dokumentationsseite zur Seite im vordersten Fenster.

## Blätter und Dialoge [#sheets-and-dialogs]

<kbd>↩</kbd> wählt den Standardknopf, und <kbd>Esc</kbd> bricht ab. Ein Dialog, der etwas löscht, hat keine Taste für
seinen roten Knopf, du klickst ihn also immer an.
