title: "Echolot"
description: "Echolot이 무엇이고 무엇을 하는지, 그리고 이 문서를 어디서부터 읽으면 되는지 안내합니다."
---

Echolot은 API를 보내고, 테스트하고, 만들 수 있는 네이티브 Mac 앱입니다. HTTP/1.1, HTTP/2, HTTP/3, GraphQL, gRPC,
WebSocket, Server-Sent Events, Socket.IO, MQTT, MCP를 지원하며, 원본 바이트와 모든 리디렉션, 각 단계에 걸린 시간까지
네트워크로 오간 내용을 그대로 보여 줍니다.

Echolot이 하는 일은 다음과 같습니다.

- **작업 내용을 일반 파일로 보관합니다.** 작업 공간은 요청마다 하나씩 있는 읽기 쉬운 TOML 파일의 폴더이며, Git으로 관리할 수
  있습니다. 비밀 값은 파일이 아니라 macOS 키체인에 보관됩니다.
- **테스트하고 실행합니다.** 모든 요청에 검사를 추가하고, 실행 페이지에서 폴더나 작업 공간 전체를 실행하며, `echolot` 명령줄
  도구로 같은 작업 공간을 CI에서도 실행합니다.
- **설계하고 모의 서버를 만듭니다.** OpenAPI 명세를 시각적으로 또는 텍스트로 작성하고, 명세를 바탕으로 하거나 가짜 데이터로
  직접 만든 경로를 바탕으로 한 로컬 모의 서버를 실행합니다.
- **자동화합니다.** 요청, 조건, 반복을 캔버스에서 플로로 연결하고, 직접 실행하거나 일정에 따라, 또는 웹훅으로 실행합니다.
- **AI와 함께 작업합니다.** 내장된 어시스턴트가 선택한 모델로 요청을 보내고, 테스트하고, 고칩니다. 외부 AI 에이전트는 Echolot의
  자체 MCP 서버를 통해 작업 공간을 사용할 수 있습니다. 데이터를 변경하는 작업은 먼저 사용자에게 확인을 요청합니다.
- **아주 큰 응답도 읽습니다.** 본문이 디스크로 스트리밍되므로 500 MB짜리 JSON 응답도 바로 열립니다.

Echolot에는 Apple 실리콘 Mac에서 실행되는 macOS 15 이상이 필요합니다. 계정도 로그인도 없습니다.
