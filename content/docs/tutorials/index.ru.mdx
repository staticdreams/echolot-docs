Каждое руководство разбирает одну задачу от начала до конца. Во всех используется **Alpenglow** — ненастоящий магазин
outdoor-снаряжения: [демо-API](/docs/tutorials/demo-api) по адресу `https://demo.echolot.dev` и пример рабочего
пространства, в котором уже есть запрос каждого вида. Вам понадобится Echolot на Mac с macOS 15 или новее и чипом
Apple. Ничто из отправленного на демо не сохраняется.

## Рабочее пространство Alpenglow [#the-alpenglow-workspace]

В большинстве руководств либо создаётся собственное рабочее пространство, либо берётся за основу Alpenglow. Чтобы
получить его:

1. Скачайте [Alpenglow.echolot.zip](/examples/Alpenglow.echolot.zip).
2. Дважды щёлкните zip-архив в Finder, чтобы распаковать его. Получится `Alpenglow.echolot`.
3. Дважды щёлкните `Alpenglow.echolot`. Echolot откроет его в окне рабочего пространства. Можно также выбрать **Файл › Открыть рабочее пространство…** (<kbd>⌘</kbd><kbd>O</kbd>) и указать его.

Alpenglow работает при выбранном **Без окружения**: переменные его рабочего пространства указывают на демо-API. В нём
есть:

| Папка | Что внутри |
| --- | --- |
| Auth | **Sign in**, который сохраняет токен доступа в секретной переменной `{{token}}`; **Who am I**; **Orders with OAuth 2** |
| Catalog | **List products**, **Search**, **Get product**, **Categories**, запрос GraphQL **Search products**, **Export the catalog** (14 МБ) |
| Orders | **List orders**, **Create order**, **Get order**, **Cancel order** — все передают токен через авторизацию Bearer папки |
| Realtime | **Order updates** (WebSocket), **Order events** (Server-Sent Events), **Support chat** (Socket.IO), **Warehouse sensors** (MQTT) |
| Inventory | Три вызова gRPC: **List warehouses**, **Watch stock**, **Reserve stock** |
| Agent tools | Два запроса MCP, **search_catalog** и **order_status**, к серверу **Alpenglow MCP** |
| Echo | Запросы к эндпоинтам `/echo`: что вы отправили, статус, перенаправления, авторизация Basic, cookie, XML и HTML |

Там же три окружения (**Local**, **Staging** и защищённое **Production**; Staging и Production — вымышленные адреса),
три сценария (**Place a test order**, **Morning stock check**, **Order status on webhook**), MCP-сервер
**Alpenglow MCP** и спецификации `alpenglow.yaml`, `shop.graphql` и `inventory.proto`.

## Серверы на вашем Mac для gRPC, Socket.IO и MQTT [#servers-on-your-mac-for-grpc-socketio-and-mqtt]

Демо-API не умеет обслуживать gRPC, Socket.IO и MQTT. Небольшие серверы для них лежат в репозитории документации, в
`examples/servers`. Им нужен [Bun](https://bun.sh), и слушают они только на вашем Mac:

```sh
git clone https://github.com/staticdreams/echolot-docs.git
cd echolot-docs/examples/servers
bun install
bun run realtime   # Socket.IO on http://localhost:3001 (namespace /support), MQTT on mqtt://localhost:1883
bun run grpc       # the Inventory service on localhost:50051 (in a second Terminal window)
```

Запросы **Support chat**, **Warehouse sensors** и **Inventory** в Alpenglow уже указывают на эти адреса. Остановить
сервер можно клавишами <kbd>Control</kbd>-<kbd>C</kbd>.

<Callout title="У демо-API есть лимиты">
  Он принимает 120 запросов в минуту с одного адреса и 10 в минуту для экспорта, WebSocket и Server-Sent Events. При
  превышении лимита он отвечает `429 Too Many Requests`; подождите минуту и отправьте запрос снова.
</Callout>
