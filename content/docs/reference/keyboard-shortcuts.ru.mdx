У каждого действия в меню рядом указано его сочетание клавиш. На этой странице они собраны вместе с клавишами,
которые работают на странице или в списке. <kbd>⌘</kbd> — Command, <kbd>⌥</kbd> — Option, <kbd>⇧</kbd> — Shift,
<kbd>⌃</kbd> — Control.

## Рабочие пространства и файлы [#workspaces-and-files]

| Действие | Клавиши | Меню |
| --- | --- | --- |
| Новый запрос | <kbd>⌘</kbd><kbd>N</kbd> | Файл |
| Новая папка | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>N</kbd> | Файл (пока в боковой панели открыты «Запросы») |
| Новое рабочее пространство… | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>N</kbd> | Файл |
| Открыть рабочее пространство… | <kbd>⌘</kbd><kbd>O</kbd> | Файл |
| Сменить рабочее пространство… | <kbd>⌘</kbd><kbd>P</kbd> | Файл |
| Закрыть вкладку | <kbd>⌘</kbd><kbd>W</kbd> | Файл |
| Закрыть окно | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd> | Файл |
| Импортировать… | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>I</kbd> | Файл |
| Экспортировать рабочее пространство… | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>E</kbd> | Файл |
| Дублировать | <kbd>⌘</kbd><kbd>D</kbd> | Правка |
| Отменить, повторить | <kbd>⌘</kbd><kbd>Z</kbd>, <kbd>⇧</kbd><kbd>⌘</kbd><kbd>Z</kbd> | Правка |
| Настройки | <kbd>⌘</kbd><kbd>,</kbd> | Echolot |

<kbd>⌘</kbd><kbd>W</kbd> закрывает вкладку на экране, но никогда не окно рабочего пространства;
<kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd> закрывает окно. В других окнах, например в «Настройках», <kbd>⌘</kbd><kbd>W</kbd>
закрывает окно.

У пунктов **Новый запрос GraphQL**, **Новый запрос WebSocket**, **Новый запрос Socket.IO**, **Новый запрос MQTT** и
**Новый запрос gRPC** в меню «Файл», а также у **Экспортировать папку…** и **Переименовать** сочетаний клавиш нет.

<kbd>⌘</kbd><kbd>1</kbd>–<kbd>⌘</kbd><kbd>5</kbd> переключают раздел боковой панели и возвращают к тому, что в нём
было открыто в последний раз. См. [окно](/docs/get-started/the-window).

## Запросы и ответы [#requests-and-responses]

| Действие | Клавиши | Меню |
| --- | --- | --- |
| Отправить | <kbd>⌘</kbd><kbd>R</kbd> или <kbd>⌘</kbd><kbd>↩</kbd> | Запрос |
| Отменить | <kbd>⌘</kbd><kbd>.</kbd> | Запрос |
| Скопировать как cURL | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>C</kbd> | Запрос |
| Сгенерировать код… | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>G</kbd> | Запрос |
| Найти в теле | <kbd>⌘</kbd><kbd>F</kbd> | Запрос |
| Следующее совпадение, предыдущее совпадение | <kbd>⌘</kbd><kbd>G</kbd>, <kbd>⇧</kbd><kbd>⌘</kbd><kbd>G</kbd> | (в строке поиска) |

Пока активно [защищённое окружение](/docs/workspaces/protected-environments), пункт называется **Отправить в
&lt;окружение&gt;…** и сначала спрашивает разрешения. Там по умолчанию выбрана кнопка **Отменить**, поэтому
<kbd>↩</kbd> никогда не отправит запрос случайно.

У **Экспортировать обмен в HAR…** в меню «Запрос» сочетания клавиш нет.

| --- | --- | --- |

## Боковая панель [#the-sidebar]

| Действие | Клавиши |
| --- | --- |
| Переместить выбор | <kbd>↑</kbd>, <kbd>↓</kbd> |
| Открыть папку | <kbd>→</kbd> |
| Закрыть папку или перейти к папке выше | <kbd>←</kbd> |
| Переименовать выбранное | <kbd>↩</kbd> |
| Прекратить переименование | <kbd>Esc</kbd> |
| Переместить запрос в Корзину | <kbd>⌫</kbd> (сначала спрашивает) |

<kbd>⌫</kbd> работает только для одного запроса. Ни одна клавиша не удаляет папку или несколько элементов: для этого
в контекстном меню есть **Переместить в Корзину…** (или **Переместить N элементов в Корзину…**), которое сначала
спрашивает разрешения. На странице «MCP-серверы» <kbd>⌫</kbd> предлагает удалить выбранный сервер.

| Действие | Клавиши |

## Быстрая отправка [#quick-send]

| Действие | Клавиши |
| --- | --- |
| Открыть Быструю отправку из любого приложения | <kbd>⌃</kbd><kbd>⌥</kbd><kbd>Space</kbd> |

Быстрая отправка выключена, пока вы не включите её в **Настройки › Основные**, где можно записать и другое сочетание

## Листы и диалоги [#sheets-and-dialogs]

<kbd>↩</kbd> выбирает кнопку по умолчанию, а <kbd>Esc</kbd> отменяет. У красной кнопки диалога, который что-то
удаляет, клавиши нет, так что её всегда нужно нажимать мышью.
