**ホーム**は、ワークスペースのウインドウで最初に表示されるページです。ワークスペースの中身、確認が必要なもの、リクエストの応答状況がわかります。
サイドバーの**ホーム**ボタンか、<kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd>で開きます。

## ホームの内容 [#what-home-shows]

上から順に説明します。

- <strong>あいさつと、ひとこと。</strong> 失敗しているチェックの数、または未保存の変更があるリクエストの数を伝えます。どちらもなければ<strong>対応待ちの項目はありません。</strong>と表示されます。
  リクエストのない新しいワークスペースでは、コレクションの読み込みか最初のリクエストの作成を案内します。
- **ワークスペース**：名前とフォルダ、そして**リクエスト**、**フォルダ**、**環境**、**変数**、**チェック**の件数。
- **Sonar**：次のセクションで説明します。
- **最近のリクエスト**（**新規リクエスト**付き）、**最新のレスポンス**、**テスト**（チェックのあるリクエストの数、失敗しているもの、**すべて表示**）、そして**環境**（**管理**と、保護された環境の印付き）。

カードのリクエストやレスポンスをクリックすると開きます。

## Sonar [#sonar]

Sonarは、ソナーがエコーを描くように、ある期間のすべての送信をピンとして描きます。横軸は時間で、左が期間の始まり、右が**たった今**です。
深さは応答にかかった時間です。速い応答は水面近くにとどまり、遅い応答は沈みます。ひと目で、APIが速かったか、どこで遅くなったか、失敗があったかがわかります。

<Shot id="get-started-home-sonar" alt="Sonarカード：ステータスで色分けしたピン、表層・中層・深層のゾーン、最も遅い応答の下の海底、その下に5つの数値" />

### グラフの読み方 [#reading-the-chart]

- **ゾーン。** 深さの目盛りは対数なので、速い側も遅い側も読み取れます。**表層**は250 ms未満、**中層**は250 msから1 s、**深層**は1 sを超えるものです。
- **ピンの色**は、ステータスの種類です。カードのヘッダーの凡例に、**2xx**、**3xx**、**4xx**、**5xx · 失敗**が示されます。応答がまったくなかった送信も、**5xx · 失敗**に含まれます。
- **海底**は、各時間帯で最も遅い応答の下にある、影付きの床です。応答に合わせて上下します。
- **右側の線**は現在を示します。ホームを表示している間に送信が完了すると、そのピンから波紋が広がります（**視差効果を減らす**がオンのときは広がりません）。
- **グラフの下のバー**は、期間内の送信がゾーンごとにどう分かれるかを、パーセントで示します。

ピンにポインタを重ねると、そのリクエストが表示されます。送信した時刻、ステータスと時間、メソッドと名前です。クリックすると、そのレスポンスを表示した状態でリクエストが開きます。
開くものがない場合（リクエストが削除された、まだ保存されていない、または送信にレスポンスがなかった場合）、ヒントに**クリックすると履歴で表示**と出て、クリックするとリクエスト名で検索した[履歴](/docs/workspaces/history)が開きます。

### 期間を選ぶ [#choosing-the-period]

カードのヘッダーにあるコントロールで、**1時間**、**24時間**、**7日**（デフォルト）、**30日**を選びます。グラフと数値が期間に合わせて変わります。送信のない期間には、リクエストを送るとそのエコーがここに現れるというメッセージが表示されます。

### 数値 [#the-figures]

グラフの上に5つの数値が並び、それぞれの横に直前の同じ長さの期間との比較が表示されます（「前の週より+12%」）。

| 数値 | 数える内容 |
| --- | --- |
| **送信** | 期間内に送信したリクエスト。 |
| **正常応答** | ステータスが400未満で応答された送信の割合と、パーセントポイントでの変化。 |
| **時間の中央値** | 応答時間の中央値と**p95**（100回の送信のうち95回はこれより速かった時間）。 |
| **250 ms未満** | 表層に入った送信の割合。 |
| **1秒超** | 深層に入った送信の数と、そのうち失敗した数。 |

幅の狭いカードでは、最初の3つだけが表示されます。

### Sonarが数えるもの [#what-sonar-counts]

- 数値は、ワークスペースの[履歴](/docs/workspaces/history)に残っているすべての送信を数えます。消去した送信や、履歴の上限で削除された送信は数えません。グラフには最新の送信が描かれます。
- Sonarが数えるのは、HTTP、GraphQL、gRPC、MCPのリクエストです。送信したのが自分でも、ランナーでも、フローでも、エージェントでも数えます。
  WebSocket、Socket.IO、MQTTのセッションは好きなだけ開いたままにできるため、応答時間がなく、描かれません。
