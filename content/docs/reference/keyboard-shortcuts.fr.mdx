---
title: "Raccourcis clavier"
description: "Tous les raccourcis clavier d’Echolot, depuis les menus et depuis les pages, regroupés selon l’endroit où vous les utilisez."
---

Chaque action des menus a son raccourci à côté. Cette page les rassemble, avec les touches qui fonctionnent sur une page
ou dans une liste. <kbd>⌘</kbd> est Commande, <kbd>⌥</kbd> Option, <kbd>⇧</kbd> Majuscule, <kbd>⌃</kbd> Contrôle.

## Espaces de travail et fichiers [#workspaces-and-files]

| Action | Touches | Menu |
| --- | --- | --- |
| Nouvelle requête | <kbd>⌘</kbd><kbd>N</kbd> | Fichier |
| Nouveau dossier | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>N</kbd> | Fichier (quand la barre latérale affiche les requêtes) |
| Nouvel espace de travail… | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>N</kbd> | Fichier |
| Ouvrir un espace de travail… | <kbd>⌘</kbd><kbd>O</kbd> | Fichier |
| Changer d’espace de travail… | <kbd>⌘</kbd><kbd>P</kbd> | Fichier |
| Fermer l’onglet | <kbd>⌘</kbd><kbd>W</kbd> | Fichier |
| Fermer la fenêtre | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd> | Fichier |
| Importer… | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>I</kbd> | Fichier |
| Exporter l’espace de travail… | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>E</kbd> | Fichier |
| Dupliquer | <kbd>⌘</kbd><kbd>D</kbd> | Édition |
| Annuler, Rétablir | <kbd>⌘</kbd><kbd>Z</kbd>, <kbd>⇧</kbd><kbd>⌘</kbd><kbd>Z</kbd> | Édition |
| Réglages | <kbd>⌘</kbd><kbd>,</kbd> | Echolot |

<kbd>⌘</kbd><kbd>W</kbd> ferme l’onglet affiché, jamais la fenêtre de l’espace de travail ; <kbd>⇧</kbd><kbd>⌘</kbd><kbd>W</kbd>
ferme la fenêtre. Dans les autres fenêtres, comme les Réglages, <kbd>⌘</kbd><kbd>W</kbd> ferme la fenêtre.

Les éléments **Nouvelle requête GraphQL**, **Nouvelle requête WebSocket**, **Nouvelle requête Socket.IO**, **Nouvelle
requête MQTT** et **Nouvelle requête gRPC** du menu Fichier, **Exporter le dossier…** et **Renommer** n’ont pas de
raccourci.

## Requêtes et réponses [#requests-and-responses]

| Action | Touches | Menu |
| --- | --- | --- |
| Envoyer | <kbd>⌘</kbd><kbd>R</kbd> ou <kbd>⌘</kbd><kbd>↩</kbd> | Requête |
| Annuler | <kbd>⌘</kbd><kbd>.</kbd> | Requête |
| Copier en tant que cURL | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>C</kbd> | Requête |
| Générer du code… | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>G</kbd> | Requête |
| Rechercher dans le corps | <kbd>⌘</kbd><kbd>F</kbd> | Requête |
| Résultat suivant, résultat précédent | <kbd>⌘</kbd><kbd>G</kbd>, <kbd>⇧</kbd><kbd>⌘</kbd><kbd>G</kbd> | (dans la barre de recherche) |

Tant qu’un [environnement protégé](/docs/workspaces/protected-environments) est actif, l’élément se lit **Envoyer à
&lt;Environnement&gt;…** et demande d’abord confirmation. **Annuler** y est le bouton par défaut : <kbd>↩</kbd> n’envoie donc
jamais par accident.

**Exporter l’échange en HAR…** dans le menu Requête n’a pas de raccourci.

## La barre latérale [#the-sidebar]

| Action | Touches |
| --- | --- |
| Déplacer la sélection | <kbd>↑</kbd>, <kbd>↓</kbd> |
| Ouvrir un dossier | <kbd>→</kbd> |
| Fermer un dossier, ou aller au dossier au-dessus | <kbd>←</kbd> |
| Renommer la sélection | <kbd>↩</kbd> |
| Arrêter de renommer | <kbd>Esc</kbd> |
| Placer une requête dans la corbeille | <kbd>⌫</kbd> (demande d’abord confirmation) |

<kbd>⌫</kbd> ne fonctionne que pour une seule requête. Aucune touche ne supprime un dossier ou plusieurs éléments :
utilisez **Placer dans la corbeille…** (ou **Placer N éléments dans la corbeille…**) dans le menu contextuel, qui demande
d’abord confirmation. Sur la page Serveurs MCP, <kbd>⌫</kbd> propose de supprimer le serveur sélectionné.

## Feuilles et dialogues [#sheets-and-dialogs]

<kbd>↩</kbd> choisit le bouton par défaut et <kbd>Esc</kbd> annule. Un dialogue qui supprime quelque chose n’a pas de
touche pour son bouton rouge : vous devez toujours cliquer dessus.
