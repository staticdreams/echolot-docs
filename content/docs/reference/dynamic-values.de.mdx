Ein dynamischer Wert ist eine Funktion innerhalb von `{{ }}`: `{{$uuid}}`, `{{$base64('heidi:alpenglow')}}`,
`{{$responseJSONPath('auth/sign-in', '$.access_token')}}`. Echolot berechnet ihn, wenn die Anfrage gesendet wird.
Dynamische Werte funktionieren überall, wo Variablen funktionieren: in der URL, in Headern, Bodys, Auth-Feldern,
Nachrichten und Einstellungen. Wie du sie in der App auswählst und bearbeitest, steht unter
[dynamische Werte](/docs/requests/dynamic-values).

## Schreibweise [#writing-them]

- Ein dynamischer Wert beginnt mit `$`: `{{$timestamp}}`. Ohne Argumente sind die Klammern optional.
- Argumente stehen in Klammern, durch Kommas getrennt: Text in Anführungszeichen (`'…'` oder `"…"`), Zahlen,
  Variablennamen ohne Anführungszeichen oder andere dynamische Werte.
- Textargumente können eigene Tokens enthalten: `{{$base64('{{email}}:{{password}}')}}`. `}}` innerhalb von
  Anführungszeichen beendet das Token nicht.
- Was sich nicht parsen lässt, bleibt so stehen, wie du es geschrieben hast, und wird gemeldet, sodass ein verirrtes `{{`
  nie eine Anfrage zerstört.

```text
{{$sha256('{{body}}', 'base64')}}
{{$date('yyyy-MM-dd', -86400, 'Europe/Zurich')}}
{{$hmacSha256(apiSecret, $timestamp)}}
```

## Antworten [#responses]

Diese lesen die neueste Antwort einer anderen gesicherten Anfrage, angegeben über ihren Pfad (`folder/request`, wie in
`auth/sign-in`). Jeder nimmt ein optionales letztes Argument, das bestimmt, ob diese Anfrage zuerst gesendet wird:

| Letztes Argument | Bedeutung |
| --- | --- |
| `'if-missing'` (Standard) | Sendet sie zuerst, wenn sie noch keine Antwort hat. |
| `'fresh'` | Sendet sie jedes Mal zuerst; in einem Durchlauf einmal pro Durchlauf. |
| `'latest'` | Sendet sie nie; verwendet die neueste Antwort. |

| Wert | Argumente | Was er liefert |
| --- | --- | --- |
| `$responseJSONPath` | Anfrage, JSONPath | Einen Wert aus dem Body der Antwort, mit JSONPath ausgewählt. `{{$responseJSONPath('auth/sign-in', '$.access_token')}}` |
| `$responseKeyPath` | Anfrage, Schlüsselpfad | Einen Wert, mit einem Schlüsselpfad wie `data.items.0.id` ausgewählt. `{{$responseKeyPath('orders/list-orders', 'items.0.id')}}` |
| `$responseJq` | Anfrage, jq-Filter | Was ein jq-Filter aus dem Body macht; mehrere Ergebnisse kommen eines pro Zeile. `{{$responseJq('catalog/list-products', '.items[0].sku')}}` |
| `$responseXPath` | Anfrage, XPath | Einen Wert aus einer XML-Antwort. `{{$responseXPath('echo/xml', '/catalog/product[1]/@sku')}}` |
| `$responseRegex` | Anfrage, Muster | Den ersten Treffer eines regulären Ausdrucks im Body: seine erste Gruppe, wenn er eine hat. `{{$responseRegex('echo/html', '<title>(\\w+)</title>')}}` |
| `$responseHeader` | Anfrage, Header | Einen Header der Antwort. `{{$responseHeader('orders/create-order', 'Location')}}` |
| `$responseCookie` | Anfrage, Cookie | Den Wert eines Cookies, den die Antwort gesetzt hat. `{{$responseCookie('echo/set-cookie', 'flavour')}}` |
| `$responseStatus` | Anfrage | Den Statuscode. `{{$responseStatus('auth/sign-in')}}` |
| `$responseBody` | Anfrage | Den ganzen Body als Text. `{{$responseBody('auth/who-am-i')}}` |
| `$responseBodyLength` | Anfrage | Die Größe des Bodys in Bytes. `{{$responseBodyLength('catalog/export')}}` |
| `$response` | Anfrage, Abfrage | Eines der obigen, je nach Form der Abfrage: ein JSONPath (`$.token`), ein XPath (`/a/b` oder `xpath:…`), `regex:…`, `jq:…`, `keypath:…`, `header:Name` oder `cookie:Name`. `{{$response('auth/sign-in', 'header:Content-Type')}}` |

**Who am I** könnte sein Token zum Beispiel direkt aus **Sign in** nehmen und es bei Bedarf zuerst senden:

```text
Authorization: Bearer {{$responseJSONPath('auth/sign-in', '$.access_token')}}
```

Eine Anfrage, die die Antwort einer anderen im Kreis liest, wird abgelehnt, und der Kreis wird genannt.
[Erfassungen aus Antworten](/docs/requests/captures) sind der andere Weg, Werte zwischen Anfragen weiterzugeben.

## Anfragen [#requests]

Diese lesen eine Anfrage so, wie sie gesendet würde, aufgelöst. Das erste Argument ist der Pfad einer gesicherten
Anfrage oder leer (`''`) für die Anfrage, die gerade gesendet wird.

| Wert | Argumente | Was er liefert |
| --- | --- | --- |
| `$requestURL` | Anfrage | Ihre URL, aufgelöst. `{{$requestURL('')}}` |
| `$requestMethod` | Anfrage | Ihre Methode. `{{$requestMethod('')}}` |
| `$requestHeader` | Anfrage, Header | Einen Header, aufgelöst, einschließlich dessen, was ihre Auth hinzufügt. `{{$requestHeader('', 'Content-Type')}}` |
| `$requestQuery` | Anfrage, Parameter | Einen Query-Parameter ihrer URL, dekodiert. `{{$requestQuery('', 'page')}}` |
| `$requestBody` | Anfrage | Ihren Body, aufgelöst, als Text. `{{$requestBody('')}}` |
| `$requestJSONPath` | Anfrage, JSONPath | Einen Wert aus ihrem JSON-Body. `{{$requestJSONPath('orders/create-order', '$.lines[0].sku')}}` |
| `$requestJq` | Anfrage, jq-Filter | Was ein jq-Filter aus ihrem JSON-Body macht. `{{$requestJq('', '.lines[0].quantity')}}` |
| `$requestVariable` | Anfrage, Variable | Eine Variable so, wie diese Anfrage sie sieht. `{{$requestVariable('auth/sign-in', 'email')}}` |

Üblich ist, eine Anfrage mit dem zu signieren, was sie sendet:

```text
X-Signature: {{$hmacSha256(apiSecret, $requestBody(''))}}
```

| `$hex` | Text | Die UTF-8-Bytes des Texts als Hex. `{{$hex('Grüezi')}}` |
| `$hexDecode` | Hex | Hex, zu Text dekodiert. `{{$hexDecode('6869')}}` |
| `$jsonEscape` | Text | Den Text, maskiert für die Verwendung in einem JSON-String, ohne die Anführungszeichen. `{{$jsonEscape(note)}}` |
| `$newline` | keine | Einen Zeilenvorschub (`\n`). |
| `$cr` | keine | Einen Wagenrücklauf (`\r`). |
| `$crlf` | keine | Einen Wagenrücklauf und Zeilenvorschub (`\r\n`). |
| `$tab` | keine | Einen Tabulator. |
| `$unescape` | Sequenz | Text, dessen Escape-Sequenzen in Zeichen umgewandelt sind: `\n`, `\r`, `\t`, `\0`, `\\`, `\xHH`, `\uHHHH`. `{{$unescape('café')}}` |
| `$basicAuth` | Benutzer, Passwort | Einen `Authorization`-Wert für HTTP Basic: `Basic ` und Base64 von `user:password`. `{{$basicAuth(email, password)}}` |
| `$jwt` | Payload, Secret, Algorithmus (optional) | Ein JWT aus der JSON-Payload, mit dem Secret signiert: `HS256`, sofern du nicht `HS384` oder `HS512` wählst. `{{$jwt('{"sub": "heidi"}', jwtSecret)}}` |

## Hashes und Signaturen [#hashes-and-signatures]

Jeder Hash nimmt den Text und optional die Ausgabe: `'hex'` (Standard), `'base64'` oder `'base64url'`. Jedes HMAC nimmt
den Schlüssel, die Nachricht und optional die Ausgabe.

| Wert | Argumente | Was er liefert |
| --- | --- | --- |
| `$md5` | Text, Ausgabe | Den MD5 des Texts. `{{$md5('alpenglow')}}` |
| `$sha1` | Text, Ausgabe | Den SHA-1. `{{$sha1('alpenglow')}}` |
| `$sha224` | Text, Ausgabe | Den SHA-224. |
| `$sha256` | Text, Ausgabe | Den SHA-256. `{{$sha256($requestBody(''), 'base64')}}` |
| `$sha384` | Text, Ausgabe | Den SHA-384. |
| `$sha512` | Text, Ausgabe | Den SHA-512. |
| `$hmacMd5` | Schlüssel, Nachricht, Ausgabe | Das HMAC-MD5 der Nachricht mit dem Schlüssel. |
| `$hmacSha1` | Schlüssel, Nachricht, Ausgabe | Das HMAC-SHA1. |
| `$hmacSha224` | Schlüssel, Nachricht, Ausgabe | Das HMAC-SHA224. |
| `$hmacSha256` | Schlüssel, Nachricht, Ausgabe | Das HMAC-SHA256. `{{$hmacSha256(apiSecret, $timestamp)}}` |
| `$hmacSha384` | Schlüssel, Nachricht, Ausgabe | Das HMAC-SHA384. |
| `$hmacSha512` | Schlüssel, Nachricht, Ausgabe | Das HMAC-SHA512. |

## Zeit [#time]

Alle diese Werte sind der Moment, in dem die Anfrage gesendet wird.

| Wert | Argumente | Was er liefert |
| --- | --- | --- |
| `$timestamp` | keine | Unix-Zeit in Sekunden: `1793525000`. |
| `$timestampMs` | keine | Unix-Zeit in Millisekunden: `1793525000123`. |
| `$isoTimestamp` | keine | ISO 8601 in UTC, mit Millisekunden: `2026-11-01T09:30:00.123Z`. |
| `$httpDate` | keine | Ein HTTP-Datum, für `Date` oder `If-Modified-Since`: `Sun, 01 Nov 2026 09:30:00 GMT`. |
| `$date` | Format, Versatz in Sekunden (optional), Zeitzone (optional) | Die Zeit in einem Unicode-Datumsmuster, um den Versatz verschoben, in der Zeitzone (UTC, sofern nicht angegeben). `{{$date('yyyy-MM-dd')}}`, `{{$date('yyyy-MM-dd HH:mm', 3600, 'Europe/Zurich')}}` |

## Zufall [#random]

Bei jedem Senden ein neuer Wert.

| Wert | Argumente | Was er liefert |
| --- | --- | --- |
| `$uuid` | keine | Eine zufällige UUID in Kleinbuchstaben. Auch `$guid` und `$randomUUID`. `{{$uuid}}` |
| `$randomInt` | Minimum, Maximum | Eine ganze Zahl zwischen den beiden, beide eingeschlossen. Ein Argument ist das Maximum, ab 0; keines ergibt 0 bis 1000. `{{$randomInt(1, 5)}}` |
| `$randomString` | Länge, Zeichen (optional) | Zufällige Zeichen, 16, sofern nicht angegeben (bis 4096): Buchstaben und Ziffern oder die angegebenen Zeichen. `{{$randomString(8, 'ABCDEF0123456789')}}` |
| `$randomHex` | Bytes | Zufällige Bytes als Hex, 16, sofern nicht angegeben (bis 2048); doppelt so viele Ziffern. `{{$randomHex(8)}}` |

**Create order** in Alpenglow sendet `Idempotency-Key: {{$uuid}}`, sodass jede Bestellung, die es aufgibt, eine neue ist.

## Beispieldaten [#fake-data]

Erfundene Werte für Anfrage-Bodys, Testdaten und [Mock-Routen](/docs/mocks/routes#bodies-with-fake-data): Namen,
Adressen, Firmen, Preise, Datumswerte, Lorem ipsum und mehr, bei jedem Senden neu. Die Namen sind die dynamischen
Variablen von Postman, sodass Sammlungen, die sie verwenden, hier echte Werte senden. In der `{{`-Liste stehen sie unter
**Beispieldaten**, nach Gruppen.

Argumente sind optional; Zahlen reichen von -10^15 bis 10^15. Mock-Bodys können außerdem `$uuid` (als `$randomUUID`),
`$randomInt`, `$randomString`, `$randomHex`, `$timestamp`, `$timestampMs` und `$isoTimestamp` aus [Zufall](#random) und
[Zeit](#time) verwenden. Im Terminal füllt [`echolot fake`](/docs/cli/fake) eine Vorlage damit.

## Dynamische Werte und Agenten [#dynamic-values-and-agents]

Sendet ein KI-Agent eine Anfrage (über den MCP-Server von Echolot oder den Assistenten), liefert `$env` nichts, und
`$file` liest nur Dateien innerhalb des Arbeitsbereichs. Geheime Werte erreichen den Agenten nie. Siehe
[Agenten](/docs/ai/agents).
