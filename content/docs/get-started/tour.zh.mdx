导览会告诉你各项功能在哪里。它会调暗窗口，每次点亮一个控件，并在旁边放一张卡片，说明这个控件的用途。整个过程大约一分钟。

## 开始导览 [#start-the-tour]

导览只提供一次，即全新安装后打开第一个工作区窗口时：一张卡片询问**欢迎使用 Echolot**，带有**开始导览**和**以后再说**。**以后再说**会被记住，Echolot 不会再次询问。在导览推出之前就已在使用的安装不会收到这个提议。

要再次进行导览，请在任意工作区窗口中选取**帮助 › 显示导览**。

## 在导览中前进 [#move-through-it]

每张卡片都显示**第 1 步，共 8 步**，并用圆点表示你所在的位置。你可以：

| 想要 | 操作 |
| --- | --- |
| 继续 | 点按**下一步**，或按 <kbd>↩</kbd>。 |
| 返回 | 点按**返回**。 |
| 离开 | 点按关闭按钮，或按 <kbd>esc</kbd>。 |

被点亮的控件仍然可用，所以你可以试一试。在导览结束之前，点按窗口其余变暗的部分没有任何作用。导览结束后，窗口会回到之前显示的页面和模块。开启**减弱动态效果**时，光亮会淡入淡出，而不是滑动。

## 各个步骤 [#the-steps]

1. **五个模块，一个工作区**。模块切换器：请求、MCP 服务器、规范、模拟服务器和流程，对应 <kbd>⌘</kbd><kbd>1</kbd> 到 <kbd>⌘</kbd><kbd>5</kbd>。参见[窗口](/docs/get-started/the-window)。
2. **你的请求**。请求列表：每个请求都是工作区文件夹中的一个普通文件，可直接用于 Git。**+** 可添加请求和文件夹，或者从 Postman、Insomnia、OpenAPI 或 cURL 导入。
3. **测试与运行器**。列表上方的两行。参见[脚本与测试](/docs/requests/scripts-and-tests)和[运行器](/docs/requests/runner)。
4. **环境**。页面标题栏中的环境菜单。参见[环境](/docs/workspaces/environments)。
5. **查找一切**。搜索栏，<kbd>⌘</kbd><kbd>K</kbd>：请求、环境、操作以及过往响应的正文。
6. **流程**。窗口切换到“流程”并点亮它的标签页。参见[流程](/docs/flows)。
7. **问问助手**。页面标题栏中的魔棒，<kbd>⌘</kbd><kbd>J</kbd>，附有三个示例问题。点按其中一个会结束导览，并把它留在助手中，随时可以发送。参见[助手](/docs/ai/assistant)。
8. **认识 Echo**。页面标题栏中间的状态屏。如果这台 Mac 上的 Echo 已关闭，卡片会提供开启它的选项。参见 [Echo](/docs/ai/echo)。

最后一张卡片**一切就绪**列出五个值得记住的按键：<kbd>⌘</kbd><kbd>K</kbd> 搜索一切，<kbd>⌘</kbd><kbd>N</kbd> 新建请求，<kbd>⌘</kbd><kbd>R</kbd> 发送打开的请求，<kbd>⌘</kbd><kbd>J</kbd> 显示或隐藏助手，<kbd>⌘</kbd><kbd>1</kbd>–<kbd>5</kbd> 切换模块。它还会说明在哪里可以再次找到导览。所有这些都列在[键盘快捷键](/docs/reference/keyboard-shortcuts)中。
