Echo는 페이지 헤더 가운데에 있는 작은 화면입니다. 윈도우에서 일어나는 일을 그때그때 알려 줍니다. 요청 전송과 소요 시간, 오류,
실행의 진행 상황, 사용자를 기다리는 플로, 에이전트의 호출, 보호된 환경으로의 전환 등입니다. 가끔 농담을 덧붙이기도 하는데, 얼마나
할지는 사용자가 정합니다. 클릭하면 농담 없이 세션 보고서를 볼 수 있습니다. Echo는 기본적으로 켜져 있으며 끌 수 있습니다.

## Echo 켜기 또는 끄기 [#turn-echo-on-or-off]

Echo는 기본적으로 켜져 있습니다. **설정 › 일반**을 열고 **Echo** 아래의 **페이지 헤더에 Echo의 상태 화면 표시**를 사용합니다. 모든
작업 공간 윈도우가 이 설정을 따릅니다. 헤더가 너무 좁아 페이지 제목과 버튼 옆에 화면이 들어가지 않으면 Echo는 공간이 생길 때까지
물러납니다.

다시 가리려면 설정을 끄거나, 화면을 Control 키를 누른 채 클릭하고 **Echo 가리기**를 선택합니다.

## Echo가 알려 주는 것 [#what-echo-tells]

Echo는 윈도우를 지켜보다가 다음 상황에서 화면에 짧은 줄을 표시합니다.

- **전송**: 보내는 중인 요청과 지금까지 걸린 시간, 이어서 응답의 상태와 소요 시간, 실패한 검사, 또는 응답이 없는 이유(시간 초과,
  해당 주소에서 수신 대기하는 것이 없음, 호스트 이름 확인 실패, TLS 핸드셰이크 실패). 취소된 전송도 표시합니다.
- **세션**: WebSocket, Socket.IO, MQTT 세션의 연결과 종료.
- **실행**: 실행 중의 진행 상황, 이어서 통과하거나 실패한 요청 수, 또는 사용자가 중지한 지점.
- **플로**: 실행 중인 플로, 사용자를 기다리는 플로, 어떻게 끝났는지.
- **모의 서버**: 모의 서버의 시작과 중지, 모의 서버가 응답하는 요청.
- **환경**: 활성 환경의 전환, 그리고 [보호된 환경](/docs/workspaces/protected-environments)일 때의 경고.
- **에이전트**: 에이전트의 연결, 호출, 사용자를 기다리는 승인. 어시스턴트의 응답.
- **새로운 기능**: 업데이트 후 아직 읽지 않은 릴리스.

### 농담의 정도 [#how-much-it-jokes]

**설정 › 일반 › Echo**의 **유머**에서 선택하거나, 화면을 Control 키를 누른 채 클릭합니다.

| 유머 | Echo의 동작 |
| --- | --- |
| **사실만** | 상태와 세부 정보만 표시하고 농담은 하지 않습니다. |
| **조금** | 가끔 농담을 합니다. 기본값입니다. |
| **많이** | 모든 줄에 농담을 하고, 아무 일도 없을 때도 수다를 더 떱니다. |

## 보고서 [#the-report]

Echo를 클릭하거나, Control 키를 누른 채 클릭하고 **Echo의 보고서 보기**를 선택합니다. 화면에서 **세션 보고서**가 펼쳐지며, 세션이
시작된 이후의 사실이 표시됩니다.

<Shot id="ai-echo-report" alt="Echo의 세션 보고서: 전송, 실패, 평균, 가장 느린 시간과 가장 빠른 시간, 실행, 세션 이벤트 로그" />

| 항목 | 집계하는 내용 |
| --- | --- |
| **전송**, **실패** | 보낸 요청 수와 그중 실패한 수 |
| **평균**, **가장 느림**, **가장 빠름** | 응답 시간. 가장 느린 항목이나 가장 빠른 항목에 포인터를 올리면 해당 요청이 표시됩니다 |
| **실행**, **실행 실패** | 실행 횟수와, 실행한 전체 요청 중 실패한 요청 수 |
| **플로** | 플로 실행 횟수와 그중 실패한 수 |
| **세션** | WebSocket, Socket.IO, MQTT 세션 |
| **모의 서버 호출** | 모의 서버가 응답한 요청 |
| **에이전트 호출** | 에이전트의 호출 |

일어나지 않은 일에 대한 항목은 표시되지 않습니다. 그 아래에는 세션 이벤트와 그 시각의 로그가 있습니다. **지우기**를 누르면 보고서를
처음부터 다시 시작합니다. 닫기 버튼이나 <kbd>Esc</kbd>로 닫습니다.

## AI 코멘트 [#ai-comments]

Echo는 자신의 줄을 직접 씁니다. 원하면 모델이 코멘트 일부를 대신 쓰게 할 수 있습니다. **설정 › 일반 › Echo**에서 **AI가 Echo의
코멘트 일부를 작성하도록 허용**을 켭니다. 기본적으로 꺼져 있으며, **사실만**과 함께 사용할 수 없습니다.

- Apple Intelligence가 있는 Mac(macOS 26)에서는 Apple의 온디바이스 모델이 코멘트를 쓰며, Mac 밖으로 나가는 것은 없습니다.
- 그렇지 않으면 **설정 › 어시스턴트**에서 체크된 모델이 씁니다. **작성자**에 어느 쪽인지 표시됩니다. 처음에는 Echolot이 그
  제공업체에 대해 [일회성 권한](/docs/ai/assistant#the-one-time-permission)을 묻습니다. 아직 허용하지 않았다면 **작성자**에 그
  사실이 **허용…** 버튼과 함께 표시되고, 그동안 Echo는 자신의 줄을 씁니다. 어시스턴트에 이미 준 권한은 Echo에도 적용됩니다.
  CLI 에이전트는 Echo의 코멘트를 쓰지 않습니다.

모델은 30초에 최대 한 번 코멘트를 쓰며, 실패나 그 밖의 눈에 띄는 순간에 대해서만 씁니다. 실패했거나 매우 느리거나(3초 이상) 매우
빠른(30 ms 미만) 전송, 실패한 검사, 보호된 환경으로의 전송 또는 전환, 끝난 실행이나 플로, 승인을 기다리는 에이전트입니다.

### 모델에게 전달되는 내용 [#what-the-model-hears]

일어난 일만 한 문장으로 전달됩니다. 이벤트의 종류, 요청의 종류와 메서드, 상태 코드, 소요 시간, 실패한 검사 수, 전송에 응답이 없었던
이유(시간 초과, 수신 대기하는 것이 없음, 호스트 이름, TLS), 요청 몇 개의 실행에서 몇 개가 실패했다는 사실 등입니다. 예를 들면
*“HTTP POST 요청이 180 ms 만에 상태 422를 받았습니다.”* 또는 *“요청 12개의 테스트 실행이 실패 2개와 함께 끝났습니다.”*

이름, 주소, 헤더, 본문, 변수, 비밀 값은 절대 전달되지 않습니다.

## 손쉬운 사용 [#accessibility]

- **동작 줄이기**를 켜면(시스템 설정 › 손쉬운 사용 › 디스플레이) 줄이 타이핑되거나 스크롤되지 않고 바로 나타나고, 화면은 텍스트가
  바뀌거나 시계가 갱신될 때만 다시 그려지며, 보고서는 펼쳐지는 대신 짧은 페이드로 열립니다.
- **대비 높이기**를 켜면 화면이 더 높은 대비로 그려집니다.
- VoiceOver는 Echo의 현재 줄을 읽으며, 화면의 레이블은 “Echo”입니다.
