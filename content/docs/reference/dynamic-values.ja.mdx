動的な値は、`{{ }}`の中に書く関数です。`{{$uuid}}`、`{{$base64('heidi:alpenglow')}}`、`{{$responseJSONPath('auth/sign-in', '$.access_token')}}`などがあります。
Echolotはリクエストの送信時にその値を求めます。動的な値は、変数が使える場所ならどこでも使えます。URL、ヘッダー、ボディ、認証フィールド、メッセージ、設定です。
アプリでの選び方と編集の仕方は、[動的な値](/docs/requests/dynamic-values)を参照してください。

## 書き方 [#writing-them]

- 動的な値は`$`で始まります：`{{$timestamp}}`。引数がない場合、括弧は省略できます。
- 引数は括弧の中にカンマで区切って書きます。引用符で囲んだテキスト（`'…'`または`"…"`）、数値、引用符なしの変数名、ほかの動的な値を使えます。
- テキストの引数には、それ自身のトークンを含められます：`{{$base64('{{email}}:{{password}}')}}`。引用符の中の`}}`でトークンは終わりません。
- 解析できないものは書いたままになり、報告されるため、余分な`{{`でリクエストが壊れることはありません。

```text
{{$sha256('{{body}}', 'base64')}}
{{$date('yyyy-MM-dd', -86400, 'Europe/Zurich')}}
{{$hmacSha256(apiSecret, $timestamp)}}
```

## レスポンス [#responses]

これらは、別の保存済みのリクエストの最新のレスポンスを、そのパス（`folder/request`。たとえば`auth/sign-in`）で指定して読み取ります。
どれも、そのリクエストを先に送信するかどうかを指定する、省略可能な最後の引数を取ります。

| 最後の引数 | 意味 |
| --- | --- |
| `'if-missing'`（デフォルト） | まだレスポンスがない場合に、先に送信します。 |
| `'fresh'` | 毎回、先に送信します。ランでは、1回の実行につき1度です。 |
| `'latest'` | 送信せず、最新のレスポンスを使います。 |

| 値 | 引数 | 得られるもの |
| --- | --- | --- |
| `$responseJSONPath` | リクエスト、JSONPath | JSONPathで選んだ、レスポンスボディの値。`{{$responseJSONPath('auth/sign-in', '$.access_token')}}` |
| `$responseKeyPath` | リクエスト、キーのパス | `data.items.0.id`のようなキーのパスで選んだ値。`{{$responseKeyPath('orders/list-orders', 'items.0.id')}}` |
| `$responseJq` | リクエスト、jqフィルタ | jqフィルタがボディから作った結果。複数の結果は1行に1つずつ。`{{$responseJq('catalog/list-products', '.items[0].sku')}}` |
| `$responseXPath` | リクエスト、XPath | XMLレスポンスの値。`{{$responseXPath('echo/xml', '/catalog/product[1]/@sku')}}` |
| `$responseRegex` | リクエスト、パターン | ボディ内の正規表現の最初の一致。グループがあれば、その最初のグループ。`{{$responseRegex('echo/html', '<title>(\\w+)</title>')}}` |
| `$responseHeader` | リクエスト、ヘッダー | レスポンスヘッダー。`{{$responseHeader('orders/create-order', 'Location')}}` |
| `$responseCookie` | リクエスト、Cookie | レスポンスが設定したCookieの値。`{{$responseCookie('echo/set-cookie', 'flavour')}}` |
| `$responseStatus` | リクエスト | ステータスコード。`{{$responseStatus('auth/sign-in')}}` |
| `$responseBody` | リクエスト | ボディ全体をテキストで。`{{$responseBody('auth/who-am-i')}}` |
| `$responseBodyLength` | リクエスト | ボディのバイト数。`{{$responseBodyLength('catalog/export')}}` |
| `$response` | リクエスト、クエリ | クエリの形式で、上記のいずれか。JSONPath（`$.token`）、XPath（`/a/b`、または`xpath:…`）、`regex:…`、`jq:…`、`keypath:…`、`header:Name`、`cookie:Name`。`{{$response('auth/sign-in', 'header:Content-Type')}}` |

たとえば、**Who am I**は、必要なら先に送信して、**Sign in**から直接トークンを取得できます。

```text
Authorization: Bearer {{$responseJSONPath('auth/sign-in', '$.access_token')}}
```

別のリクエストのレスポンスを循環して読み取るリクエストは、循環の経路を示して拒否されます。
リクエスト間で値を受け渡すもう1つの方法は、[レスポンスのキャプチャ](/docs/requests/captures)です。

## リクエスト [#requests]

これらは、送信されるとおりに解決されたリクエストを読み取ります。最初の引数は保存済みのリクエストのパスで、送信中のリクエストを指す場合は空（`''`）にします。

| 値 | 引数 | 得られるもの |
| --- | --- | --- |
| `$requestURL` | リクエスト | 解決されたURL。`{{$requestURL('')}}` |
| `$requestMethod` | リクエスト | メソッド。`{{$requestMethod('')}}` |
| `$requestHeader` | リクエスト、ヘッダー | 解決されたヘッダー（認証が追加するものを含む）。`{{$requestHeader('', 'Content-Type')}}` |
| `$requestQuery` | リクエスト、パラメータ | URLのクエリパラメータ（デコード済み）。`{{$requestQuery('', 'page')}}` |
| `$requestBody` | リクエスト | 解決されたボディをテキストで。`{{$requestBody('')}}` |
| `$requestJSONPath` | リクエスト、JSONPath | JSONボディの値。`{{$requestJSONPath('orders/create-order', '$.lines[0].sku')}}` |
| `$requestJq` | リクエスト、jqフィルタ | jqフィルタがJSONボディから作った結果。`{{$requestJq('', '.lines[0].quantity')}}` |
| `$requestVariable` | リクエスト、変数 | そのリクエストから見た変数。`{{$requestVariable('auth/sign-in', 'email')}}` |

リクエストが送信する内容で署名するのが、典型的な使い方です。

```text
X-Signature: {{$hmacSha256(apiSecret, $requestBody(''))}}
```

| `$jsonEscape` | テキスト | JSON文字列の中に入れられるようにエスケープしたテキスト（引用符は含みません）。`{{$jsonEscape(note)}}` |
| `$newline` | なし | ラインフィード（`\n`）。 |
| `$cr` | なし | キャリッジリターン（`\r`）。 |

| `$tab` | なし | タブ。 |

| `$basicAuth` | ユーザー、パスワード | HTTP Basic用の`Authorization`の値：`Basic `と`user:password`のBase64。`{{$basicAuth(email, password)}}` |
| `$jwt` | ペイロード、シークレット、アルゴリズム（省略可） | JSONペイロードをシークレットで署名したJWT。`HS384`または`HS512`を選ばない限り`HS256`。`{{$jwt('{"sub": "heidi"}', jwtSecret)}}` |

## ハッシュと署名 [#hashes-and-signatures]

各ハッシュはテキストと、必要に応じて出力形式（`'hex'`（デフォルト）、`'base64'`、`'base64url'`）を取ります。各HMACはキー、メッセージ、そして必要に応じて出力形式を取ります。

| 値 | 引数 | 得られるもの |
| --- | --- | --- |
| `$md5` | テキスト、出力 | テキストのMD5。`{{$md5('alpenglow')}}` |
| `$sha1` | テキスト、出力 | SHA-1。`{{$sha1('alpenglow')}}` |
| `$sha224` | テキスト、出力 | SHA-224。 |
| `$sha256` | テキスト、出力 | SHA-256。`{{$sha256($requestBody(''), 'base64')}}` |
| `$sha384` | テキスト、出力 | SHA-384。 |
| `$sha512` | テキスト、出力 | SHA-512。 |
| `$hmacMd5` | キー、メッセージ、出力 | キーを使ったメッセージのHMAC-MD5。 |
| `$hmacSha1` | キー、メッセージ、出力 | HMAC-SHA1。 |
| `$hmacSha224` | キー、メッセージ、出力 | HMAC-SHA224。 |
| `$hmacSha256` | キー、メッセージ、出力 | HMAC-SHA256。`{{$hmacSha256(apiSecret, $timestamp)}}` |
| `$hmacSha384` | キー、メッセージ、出力 | HMAC-SHA384。 |
| `$hmacSha512` | キー、メッセージ、出力 | HMAC-SHA512。 |

## 時刻 [#time]

これらはすべて、リクエストを送信する時点の時刻です。オフセットを指定した場合は、その分だけずらします。

| 値 | 引数 | 得られるもの |
| --- | --- | --- |
| `$timestamp` | オフセット（省略可） | 秒単位のUnix時間：`1793525000`。`{{$timestamp(60)}}` は1分後です。 |
| `$timestampMs` | オフセット（省略可） | ミリ秒単位のUnix時間：`1793525000123`。 |
| `$isoTimestamp` | オフセット（省略可） | UTCのISO 8601形式（ミリ秒付き）：`2026-11-01T09:30:00.123Z`。`{{$isoTimestamp('-90s')}}` は90秒前です。 |
| `$httpDate` | なし | `Date`や`If-Modified-Since`用のHTTP日付：`Sun, 01 Nov 2026 09:30:00 GMT`。 |
| `$date` | フォーマット、秒単位のオフセット（省略可）、タイムゾーン（省略可） | Unixの日付パターンで表した時刻。オフセット分だけずらし、指定したタイムゾーン（指定がなければUTC）で表します。`{{$date('yyyy-MM-dd')}}`、`{{$date('yyyy-MM-dd HH:mm', 3600, 'Europe/Zurich')}}` |

`$timestamp`、`$timestampMs`、`$isoTimestamp` のオフセットは、秒数、または単位付きの数値です（単位は `ms`、`s`、`m`、`h`、`d`、`w`）。
`-` を付けると過去に、`+` を付けるか何も付けないと未来にずらします：`'-90s'`、`'2h'`、`'-1d'`、`'1w'`。
テキストとして引用符で囲んで書きます。秒数だけの数値は `{{$timestamp(-3600)}}` のようにそのまま書けます。
オフセットとして読めない値は、何を書けばよいかを示すメッセージとともに失敗します。

## ランダム [#random]

`$sameUUID` を除き、送信のたびに新しい値になります。

| 値 | 引数 | 得られるもの |
| --- | --- | --- |
| `$uuid` | なし | ランダムなUUID（小文字）。`$guid`と`$randomUUID`も同じです。`{{$uuid}}` |
| `$sameUUID` | 名前 | 一度だけ作られ、同じ名前で求められた場所すべてで同じ値になるランダムなUUID。実行ごとに1回（反復ごとに別）、実行の外ではウインドウごとに1回、コマンドラインではコマンドごとに1回作られます。`{{$sameUUID('order')}}` |
| `$randomInt` | 最小値、最大値 | 2つの値の間（両端を含む）の整数。引数が1つなら0からその値まで、なければ0から1000。`{{$randomInt(1, 5)}}` |
| `$randomString` | 長さ、文字（省略可） | ランダムな文字列。長さの指定がなければ16（最大4096）。英数字、または指定した文字から作られます。`{{$randomString(8, 'ABCDEF0123456789')}}` |
| `$randomHex` | バイト数 | ランダムなバイト列を16進数にしたもの。指定がなければ16バイト（最大2048）で、桁数はその2倍です。`{{$randomHex(8)}}` |

Alpenglowの**Create order**は`Idempotency-Key: {{$uuid}}`を送信するので、送信される注文はそのつど新しいものになります。
リクエストとその再試行、作成とそれに続く更新など、実行の中の複数のリクエストが同じキーを送る必要がある場合は、`{{$sameUUID('order')}}` を使います。
実行ごとに新しいキーが1つ作られ、`order` を指定したすべてのリクエストがそれを送信します。

## ダミーデータ [#fake-data]

リクエストボディ、テストデータ、[モックのルート](/docs/mocks/routes#bodies-with-fake-data)用の作り物の値です。名前、住所、会社、価格、日付、ロレムイプサムなどがあり、送信のたびに新しくなります。
名前はPostmanの動的変数と同じなので、それらを使っているコレクションでも、ここで実際の値が送信されます。`{{`の候補リストでは、**ダミーデータ**の下にグループ別に並んでいます。

引数は省略可能です。数値は-10^15から10^15までです。モックのボディでは、[ランダム](#random)と[時刻](#time)の`$uuid`（`$randomUUID`として）、`$randomInt`、`$randomString`、`$randomHex`、`$timestamp`、`$timestampMs`、`$isoTimestamp`も使えます（時刻の値はオフセット付きでも使えます）。
ターミナルからは、[`echolot fake`](/docs/cli/fake)がそれらでテンプレートを埋めます。

## 動的な値とエージェント [#dynamic-values-and-agents]

AIエージェントがリクエストを送信するとき（EcholotのMCPサーバまたはアシスタント経由）、`$env`は何も返さず、`$file`はワークスペース内のファイルだけを読み取ります。シークレットの値がエージェントに渡ることはありません。
[エージェント](/docs/ai/agents)を参照してください。
