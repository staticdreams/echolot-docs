Echo 是页面标题栏中间的一块小屏幕。它会实时告诉你窗口中正在发生什么：一次发送及其耗时、一个错误、运行器的进度、一个等待你的流程、一次智能体调用、
一次切换到受保护的环境。它偶尔还会开个玩笑，你想开多少都行。点按它可以查看会话报告，不带玩笑。Echo 默认开启，你可以将它关闭。

<Shot id="ai-echo-screen" alt="页面标题栏中间的 Echo，显示刚发送的请求的状态和耗时" />

## 开启或关闭 Echo [#turn-echo-on-or-off]

Echo 默认开启。打开**设置 › 通用**，在 **Echo** 下使用**在页面标题栏中显示 Echo 的状态屏幕**。每个工作区窗口都遵循该设置。
当标题栏太窄，容不下这块屏幕以及页面的标题和按钮时，Echo 会让到一旁，直到再次有空间。

要再次隐藏它，请关闭该设置，或按住 Control 键点按屏幕并选取**隐藏 Echo**。

## Echo 会说什么 [#what-echo-tells]

Echo 关注窗口，并为以下情况在屏幕上显示一行简短的话：

- **发送**：正在发送的请求以及到目前为止已用的时间，随后是响应的状态和耗时、失败的检查，或没有响应的原因（超时、该地址没有任何监听、主机名无法解析、TLS 握手失败）。取消的发送也一样。
- **会话**：WebSocket、Socket.IO 或 MQTT 会话的连接和关闭。
- **运行器**：运行时的进度，随后是通过或失败的请求数，或者你在哪里停止了它。
- **流程**：流程正在运行、正在等待你，以及它如何结束。
- **模拟服务器**：模拟服务器的启动和停止，以及它应答的请求。
- **环境**：活动环境的切换，以及当它是[受保护的环境](/docs/workspaces/protected-environments)时的警告。
- **智能体**：智能体的连接、它的调用，以及等待你批准的内容；助手的回答。
- **新功能**：更新之后，你尚未阅读的版本。

### 它开多少玩笑 [#how-much-it-jokes]

用**设置 › 通用 › Echo** 中的**幽默**来选取，或按住 Control 键点按屏幕：

| 幽默 | Echo 的做法 |
| --- | --- |
| **只讲事实** | 状态和详情，没有玩笑。 |
| **一点** | 偶尔一个玩笑。默认值。 |
| **很多** | 每一行都有玩笑，没有动静时也会多说几句。 |

## 报告 [#the-report]

点按 Echo，或按住 Control 键点按它并选取**显示 Echo 的报告**。**会话报告**会从屏幕中展开，显示会话开始以来的事实：

<Shot id="ai-echo-report" alt="Echo 的会话报告：发送次数、失败次数、平均、最慢和最快的耗时、运行次数，以及会话事件的日志" />

| 读数 | 统计的内容 |
| --- | --- |
| **发送**、**失败** | 已发送的请求，以及其中失败的数量 |
| **平均**、**最慢**、**最快** | 响应时间；将鼠标悬停在最慢或最快的上，可以看到对应的请求 |
| **运行**、**运行失败** | 运行器的运行次数，以及它们运行的所有请求中失败的请求 |
| **流程** | 流程的运行次数，以及其中失败的数量 |
| **会话** | WebSocket、Socket.IO 和 MQTT 会话 |
| **模拟调用** | 你的模拟服务器应答的请求 |
| **智能体调用** | 来自智能体的调用 |

没有发生过的事情，对应的读数不会显示。读数下方是会话事件的日志及其时间。**清除**会重新开始报告。用关闭按钮或 <kbd>Esc</kbd> 关闭它。

## AI 评论 [#ai-comments]

Echo 会自己撰写它的那些话。如果你愿意，也可以让模型来撰写其中一部分评论：在**设置 › 通用 › Echo** 中开启**让 AI 撰写 Echo 的部分评论**。
它默认关闭，在**只讲事实**下不可用。

- 在带有 Apple 智能的 Mac（macOS 26）上，由 Apple 的设备端模型撰写，没有任何内容离开这台 Mac。
- 否则由**设置 › 助手**中勾选的模型撰写。**作者**会显示是哪一个。第一次使用时，Echolot 会为该提供商询问[一次性许可](/docs/ai/assistant#the-one-time-permission)。
  如果你还没有允许，**作者**会说明这一点，并带有一个**允许…** 按钮，Echo 在此期间自己撰写。你已经给助手的许可同样涵盖 Echo。CLI 智能体从不撰写 Echo 的评论。

模型最多每 30 秒撰写一条评论，而且只针对失败和其他值得注意的时刻：失败、很慢（3 秒或更久）或很快（不到 30 毫秒）的发送、失败的检查、
发送到受保护的环境或切换到受保护的环境、完成的运行或流程、等待批准的智能体。

### 模型听到的内容 [#what-the-model-hears]

只有发生了什么，用一句话说明：事件的种类、请求的类型和方法、状态码、持续时间、失败的检查数量、发送没有得到响应的原因（超时、无人监听、主机名、TLS），
以及某次包含若干请求的运行有若干次失败。例如：*“一个 HTTP POST 请求在 180 ms 内得到状态 422。”*或*“一次包含 12 个请求的测试运行结束，有 2 次失败。”*

绝不包含名称、地址、标头、正文、变量或机密。

## 辅助功能 [#accessibility]

- 开启**减弱动态效果**（系统设置 › 辅助功能 › 显示器）时，文字行会立即出现，而不是逐字输入和滚动，屏幕只在文字变化或时钟走动时重绘，报告会以短暂的淡入打开，而不是展开。
- 开启**提高对比度**时，屏幕会以更高的对比度绘制。
- 旁白会朗读 Echo 当前的文字行；屏幕的标签是“Echo”。
