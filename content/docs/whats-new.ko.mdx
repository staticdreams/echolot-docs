Echolot이 **도움말 › Echolot의 새로운 기능**에 보여 주는 릴리스 노트이며, 최신 버전이 먼저 나옵니다. 각 버전과 다운로드는 [릴리스 페이지](https://github.com/staticdreams/echolot-public/releases)에도 있습니다.

## 0.8.0

*2026년 11월 4일 · 빌드 12*

**새로운 기능**

- 이제 Echolot을 프랑스어, 독일어, 스페인어, 일본어, 한국어, 러시아어, 중국어 간체로 사용할 수 있습니다. 시스템 언어를 따르며, 설정 › 일반 › 언어에서 직접 선택할 수도 있습니다.
- 처음 실행할 때 안내 투어가 나타나며, 도움말 › 투어 보기에서 다시 볼 수 있습니다.
- 어시스턴트 패널의 크기를 조절할 수 있습니다. 가장자리를 드래그하십시오(이중 클릭하면 기본 크기로 돌아갑니다).
- 모의 서버가 예시가 없는 명세 작업에 각 필드에 맞는 새로운 가짜 데이터로 응답합니다.

**개선 사항**

- 페이지 헤더의 상태 화면인 Echo가 기본으로 켜집니다.
- 어시스턴트의 승인 시트에서 이 세션 동안 허용을 선택하면 이제 작업 공간에 대한 모든 변경이 한 번에 허용됩니다. 삭제는 계속 묻습니다.
- 환영 윈도우의 앱 아이콘 뒤에서 소나 핑이 퍼져 나갑니다.

**수정 사항**

- 요청 편집기가 더 이상 응답 위에 겹쳐 그려지지 않습니다.
- 홈이 좁은 윈도우에 맞게 표시되므로, 넓은 어시스턴트 때문에 사이드바 위로 밀려나지 않습니다.
- Echo의 인사말이 더 이상 찌그러지지 않으며, 어시스턴트의 제목이 모든 언어에서 한 줄로 표시됩니다.
- 빼기 버튼으로 테스트를 제거할 때 Echolot이 더 이상 충돌하지 않으며, MQTT 구독이나 메시지, WebSocket 메시지, Socket.IO 전송을 제거할 때도 마찬가지입니다. 문제를 알려 주신 Amit 님께 감사드립니다.
- 플로 목록의 빼기 버튼이 선택한 플로를 삭제합니다. 이전에는 버튼의 가는 선 부분만 클릭에 반응했습니다.

## 0.7.1

*2026년 11월 3일 · 빌드 11*

**새로운 기능**

- 홈의 Sonar 카드가 지난 1시간, 24시간, 7일 또는 30일 동안의 모든 전송을 응답 시간별로 표시하며, 전송 수, 정상 응답, 중앙값, p95를 이전 기간과 비교해 보여 줍니다.
- 깊은 바다의 푸른색으로 이루어진 두 번째 다크 모양인 마린이 추가되었습니다(설정 › 일반 › 모양).
- 모든 요청에서 작업 공간 인증으로 이동: 인증 탭에서 요청이 상속하는 폴더 또는 작업 공간 인증을 열 수 있으며(자체 인증이 있는 요청은 작업 공간 인증…), 폴더 및 작업 공간 설정에서 OAuth 2.0으로 한 번 로그인하면 상속하는 모든 요청에 적용됩니다.
- 더 많은 인증 방식: OAuth 1.0, OAuth 2.0의 비밀번호 권한 부여와 고급 설정을 지원하며, Postman의 ASAP 인증은 JWT Bearer로 가져옵니다.
- 에이전트와 어시스턴트가 요청에 인증과 캡처를 지정하고(자격 증명은 `{{variables}}`로만), 폴더의 인증을 설정하며, 승인을 받은 후 플로를 한 번 시험 실행할 수 있습니다. 설정 › 어시스턴트 › 사전 확인에서 삭제, 새로운 호스트 및 보호된 환경에 대해서만 묻도록 제한할 수 있습니다.
- 마지막 호출이 실패한 요청은 요청 목록에 경고 표시와 함께 무엇이 잘못되었는지 보여 줍니다.

**개선 사항**

- 어시스턴트의 답변이 Markdown으로 렌더링되며, 스트리밍 중에도 부드럽게 표시됩니다.
- 플로 카드에 블록이 하는 일이 표시되고, 조건은 규칙으로 편집하며, 평가 블록의 마지막 표현식이 그 결과가 됩니다.
- 설정 › 저장 공간에서 응답 본문이 차지하는 용량을 확인할 수 있으며, 저장된 본문 제거…로 공간을 확보할 수 있습니다.
- 작은 화면에서 어시스턴트와 고정된 변수 때문에 윈도우가 화면 밖으로 밀려나지 않습니다. 대신 변수가 떠 있는 패널로 표시됩니다.

**수정 사항**

- 두 차례의 감사에 따른 보안 수정: OAuth 토큰은 환경과 설정별로 보관되며 다른 호스트로 전송되지 않습니다. 에이전트는 묻지 않고 파일에 자격 증명을 쓰거나 새로운 호스트로 비밀 값을 보낼 수 없습니다. 중지된 모의 서버, MCP 서버 및 웹훅 서버는 모든 연결을 닫습니다.
- 값에 매우 큰 숫자가 있을 때의 충돌, HTTPS 프록시가 HTTP/2 서버에서 실패하는 문제, `"""`로 끝나는 텍스트가 저장 시 바뀌는 문제, 이동이나 이름 변경 시 열린 탭의 실행 취소 기록이 지워지는 문제를 수정했습니다.
- 저장 데이터 암호화가 켜져 있으면 기록에 요청 본문이 더 이상 일반 텍스트로 보관되지 않습니다.
- 작업 공간 및 폴더 설정이 마린을 포함한 사용자의 모양 설정을 따르며, 탭을 전환해도 크기가 그대로 유지됩니다.
- gRPC 호출 막대가 패널에 맞게 표시됩니다. 긴 proto, 서비스, 메서드 이름은 응답 영역을 침범하지 않고 잘려서 표시됩니다.

## 0.6.0

*2026년 11월 2일 · 빌드 9*

**새로운 기능**

- 모의 서버에 더 이상 명세가 필요하지 않습니다. 경로를 직접 만들고(메서드, `{id}`가 포함된 경로, 상태, 헤더, 본문, 요청에 대한 규칙), 본문에 가짜 데이터를 넣을 수 있습니다: `{{$randomFullName}}`, `{{request.params.id}}`, `{{#repeat 10}}`…`{{/repeat}}`. 요청 생성으로 모의 서버의 경로를 요청으로 바꿀 수 있습니다.
- 같은 가짜 값을 요청에서도 사용할 수 있으며, echolot fake는 명령줄에서 템플릿으로 가짜 데이터를 만듭니다.
- 사이드바에서 여러 요청을 선택해 새 폴더에 넣거나(항목 N개를 포함한 새로운 폴더), 헤더, 쿼리 매개변수, 인증을 한 번에 변경할 수 있습니다(요청 N개 편집…).
- 페이지 헤더의 선택적 상태 화면인 Echo(설정 › 일반 › Echo)가 윈도우에서 일어나는 일을 알려 주며, 클릭하면 세션 보고서가 펼쳐집니다.
- 도움말 › Echolot 문서(⌘?)는 docs.echolot.dev의 새 문서를 열고, 도움말 › 이 페이지에 대한 도움말은 지금 보고 있는 화면에 관한 페이지를 엽니다.

**개선 사항**

- Echolot은 모델 제공업체에 무엇이든 보내기 전에 제공업체마다 한 번 묻습니다. 설정 › 어시스턴트에서 허용한 항목을 확인하고 취소할 수 있습니다. Apple의 온디바이스 모델과 이 Mac의 서버는 묻지 않습니다.
- 업데이트 후 아무것도 저절로 열리지 않습니다. 페이지 헤더의 새로운 기능 버튼에서 새로운 릴리스 노트를 볼 수 있습니다.
- 명령 팔레트가 현재 표시된 페이지에 맞는 항목만 제공합니다.
- JSON 응답에서 \u 이스케이프가 해당 문자로 표시됩니다.
- 사이드바의 하이라이트가 행에서 행으로 부드럽게 이동하며, 모듈 전환기가 선택한 모듈로 튀어 오르듯 이동합니다.

**수정 사항**

- 규칙 추가와 헤더 추가가 추가한 행을 유지하고 그 행에 커서를 놓습니다.
- 다른 윈도우가 앞으로 나올 때 윈도우의 신호등 버튼이 더 이상 잘려 보이지 않습니다.

## 0.5.0

*2026년 10월 31일 · 빌드 7*

**개선 사항**

- 보호된 환경에서 더 많은 작업 전에 확인합니다: MCP 호출, 검사 및 감시, 토큰 받기, 스키마 가져오기, gRPC 리플렉션, 환경을 전환한 후 열린 세션에서 보내는 메시지.
- 일반 텍스트로 보관된 프록시 비밀번호나 인증서 암호에 이제 경고가 표시되며, 옆에 키체인으로 이동 버튼이 있습니다. 한 요청의 기록을 지울 때는 먼저 묻습니다.
- `{{`를 입력하면 URL 막대에서 요청의 변수가 다시 제안되며, 폴더 또는 작업 공간의 설정에서는 그 인증이 사용하는 변수가 제안됩니다.
- JSON 트리가 큰 응답을 더 빨리 열고, 플로 캔버스를 더 부드럽게 이동할 수 있습니다.

**수정 사항**

- 비밀 값이 제자리에 머뭅니다: API 키 헤더와 비밀 값이 담긴 헤더는 다른 출처로의 리디렉션을 더 이상 따라가지 않고, 기록에 Hawk, EdgeGrid, NTLM, 프록시 또는 인증서의 비밀 값이 더 이상 남지 않으며, 저장 공간이 암호화되어 있으면 응답의 텍스트가 검색 색인에 포함되지 않습니다.
- 에이전트는 자격 증명이 가려진 상태로 기록을 읽으며, 비밀 값에 닿는 검색 결과는 개수에 포함되거나 표시되지 않습니다. 에이전트의 제한은 에이전트가 실행하는 플로 안에서도 유지됩니다.
- NTLM 로그인이 다른 요청에 연결을 빼앗기지 않고 HTTP/1.1로 동작하며, HTTP/1.1을 요구하는 서버에는 HTTP/1.1로 연결합니다. HTTP/3는 TCP처럼 호스트의 모든 주소를 동시에 시도합니다.
- 비정상적으로 팽창하는 응답(256 MB를 넘어 100대 1 이상)과 거대한 조각으로 이루어진 WebSocket 및 Socket.IO 메시지는 메모리를 채우지 않고 잘립니다.
- 내보내기는 원본 작업 공간을 덮어쓰거나, 그 안에 쓰거나, 그 작업 공간을 감싸는 위치에 쓰지 않으며, 대체되는 항목은 휴지통으로 보내고, 일반 텍스트로 기록된 자격 증명의 개수를 알려 줍니다.
- 편집 내용이 더 이상 사라지지 않습니다: 폴더 및 작업 공간 설정, 모의 서버 경로, 종료 직전에 닫은 탭이 모두 저장되며, 저장에 실패해도 텍스트가 유지됩니다.
- 윈도우를 닫으면 해당 윈도우의 실행과 전송이 중지됩니다. 반복을 나란히 실행해도 각자의 $response 값이 유지되며, 최대 100 MB의 데이터 파일을 윈도우가 멈추지 않고 불러옵니다.
- 요청 스크립트가 실패한 플로는 이제 실패 경로로 진행하며, 백그라운드 서비스가 환경 없음 선택을 따릅니다.

이전 버전의 릴리스 노트는 [영어판](/docs/whats-new)에 있습니다.
