这是 Echolot 在 **帮助 › Echolot 的新功能** 中显示的发行说明，最新的在最前。每个版本及其下载也可在[发布页面](https://github.com/staticdreams/echolot-public/releases)找到。

## 0.8.0

*2026年11月4日 · 构建 12*

**新增**

- Echolot 现已支持法语、德语、西班牙语、日语、韩语、俄语和简体中文。它会跟随系统语言，你也可以在“设置 › 通用 › 语言”中选择一种。
- 首次启动时会有一段引导导览，之后可从“帮助 › 显示导览”重新观看。
- “助手”面板可以调整大小：拖移它的边缘即可（连按两下恢复默认大小）。
- 对于没有示例的规范操作，模拟服务器会用每次新生成、与各字段相符的示例数据来响应。

**改进**

- Echo（页面标题栏中的状态屏幕）现已默认开启。
- 在助手的批准对话框中，“在本次会话中允许”现在一次涵盖对工作区的所有更改；删除仍会询问。
- 欢迎窗口的 App 图标后方新增了声呐脉冲效果。

**修复**

- 请求编辑器不再覆盖在响应上方。
- “主页”能适应较窄的窗口，因此较宽的助手面板不再把它推到边栏上方。
- Echo 的问候语不再被挤压，助手的标题在所有语言中都保持在一行内。
- 用减号按钮移除测试不再导致 Echolot 崩溃，移除 MQTT 订阅或消息、WebSocket 消息或 Socket.IO 发送事件时也不会。感谢 Amit 报告这个问题。
- “流程”列表中的减号按钮会删除所选流程；以前只有点按按钮上那条细线才有效。

## 0.7.1

*2026年11月3日 · 构建 11*

**新增**

- “主页”的 Sonar 卡片按响应时间绘制过去 1 小时、24 小时、7 天或 30 天内的每次发送，并显示发送次数、响应正常次数、中位数和 p95，与上一时段对比。
- 海洋：第二种深色外观，采用深海蓝色调（“设置 › 通用 › 外观”）。
- 从任意请求进入工作区认证：“认证”标签页会打开请求所继承的文件夹或工作区认证（有自己认证的请求则显示“工作区认证…”），文件夹和工作区设置可用 OAuth 2.0 登录一次，供所有继承的请求使用。
- 更多认证方式：OAuth 1.0、OAuth 2.0 的密码授权和“高级”设置，Postman 的 ASAP 认证会导入为 JWT Bearer。
- 智能体和助手可以为请求设置认证和捕获（凭据只能是 `{{variables}}`）、设置文件夹的认证，并在你批准后试运行一次流程；“设置 › 助手 › 询问时机”可将询问限定为删除、新主机和受保护的环境。
- 上次调用失败的请求会在请求列表中显示警告标志，并说明出了什么问题。

**改进**

- 助手的回复以 Markdown 渲染，流式输出时也保持流畅。
- 流程卡片会显示它的作用，条件以规则形式编辑，“求值”块的最后一个表达式即为其结果。
- “设置 › 储存空间”会显示响应正文占用了多少空间，“移除已存储的正文…”可将其释放。
- 在较小的屏幕上，助手和固定的变量面板不再把窗口撑出屏幕：变量面板会改为浮动显示。

**修复**

- 两次审计带来的安全修复：OAuth 令牌按环境和设置分别保存，且绝不会发往其他主机；智能体不能将凭据写入文件，也不能未经询问就把机密发送到新主机；已停止的模拟、MCP 和 Webhook 服务器会关闭所有连接。
- 修复了值中包含极大数字时的崩溃、HTTPS 代理连接 HTTP/2 服务器失败、以 `"""` 结尾的文本存储后发生变化，以及移动或重新命名会清除已打开标签页的撤销记录等问题。
- 开启静态加密后，历史记录不再以明文保存请求正文。
- 工作区和文件夹设置会跟随你的外观（包括海洋），切换标签页时大小保持不变。
- gRPC 调用栏能适应其窗格：较长的 proto、服务和方法名称会被截短，不再与响应重叠。

## 0.6.0

*2026年11月2日 · 构建 9*

**新增**

- 模拟服务器不再需要规范：可以手动创建路由（方法、含 `{id}` 的路径、状态、标头、正文以及针对请求的规则），并在正文中使用示例数据：`{{$randomFullName}}`、`{{request.params.id}}`、`{{#repeat 10}}`…`{{/repeat}}`。“创建请求”可将模拟服务器的路由转换为请求。
- 同样的示例值也可用于请求，echolot fake 可在命令行中根据模板生成示例数据。
- 在边栏中选择多个请求，可将它们放入新文件夹（“用 N 个项目新建文件夹”），或一次更改它们的标头、查询参数和认证（“编辑 N 个请求…”）。
- Echo 是页面标题栏中的可选状态屏幕（“设置 › 通用 › Echo”），它会告诉你窗口中发生了什么，点按一下即可展开本次会话的报告。
- “帮助 › Echolot 文档”（⌘?）会打开 docs.echolot.dev 上的新文档，“帮助 › 此页面的帮助”则打开与你正在查看的内容相关的页面。

**改进**

- Echolot 首次向每个模型提供商发送任何内容前都会询问一次；“设置 › 助手”会列出你已允许的提供商，并附有“撤销许可”。Apple 的设备端模型和你 Mac 上的服务器从不询问。
- 更新后不会自动打开任何窗口：页面标题栏中的“新功能”按钮会显示新的更新说明。
- 命令面板只提供在当前页面上有意义的操作。
- JSON 响应会将 \u 转义显示为其所代表的字符。
- 边栏的高亮会在行与行之间滑动，模块切换器会弹跳到你选择的模块。

**修复**

- “添加规则”和“添加标头”会保留新添加的行，并将光标放入其中。
- 另一个窗口移到前面时，窗口的红绿灯按钮不再显示不全。

## 0.5.0

*2026年10月31日 · 构建 7*

**改进**

- 受保护的环境会在更多操作前询问：MCP 调用、检查和监视，“获取令牌”，Schema 获取，gRPC 反射，以及切换环境后在已打开会话中发送的消息。
- 以明文保存的代理密码或证书密码短语现在会显示警告，旁边附有“移到钥匙串”；清除单个请求的历史记录前会先询问。
- 在 URL 栏中输入 `{{` 会再次列出请求的变量；在文件夹或工作区的设置中，也会列出其认证解析时所用的变量。
- JSON 树能更快打开大型响应，流程画布的平移也更流畅。

**修复**

- 机密留在原处：API 密钥标头和含有机密的标头不再随重定向发往其他源，历史记录不再保留 Hawk、EdgeGrid、NTLM、代理或证书的机密；启用加密存储后，响应的文本不会进入搜索索引。
- 智能体读取历史记录时凭据会被遮盖，涉及机密的搜索匹配既不计数也不显示；智能体的限制在它运行的流程中同样有效。
- NTLM 登录可通过 HTTP/1.1 正常进行，不会有其他请求借用它的连接；坚持使用 HTTP/1.1 的服务器也会改用 HTTP/1.1。HTTP/3 会像 TCP 一样同时尝试主机的所有地址。
- 异常膨胀的响应（超过 256 MB 后膨胀比超过 100 比 1），以及由超大分片拼成的 WebSocket 和 Socket.IO 消息，会被截断，而不会占满内存。
- 导出绝不会覆盖来源工作区，也不会写入其内部或包含它的文件夹；被替换的内容会移到废纸篓，并说明有多少凭据以明文写入。
- 编辑不再丢失：文件夹和工作区设置、模拟服务器路由以及退出前刚刚关闭的标签页都会被写入，存储失败时会保留你的文本。
- 关闭窗口会停止其中的运行和发送。并行运行的迭代各自保留自己的 $response 值，最大 100 MB 的数据文件载入时不会让窗口卡住。
- 请求脚本失败的流程现在会走失败路径，后台服务也会遵循“无环境”的选择。
