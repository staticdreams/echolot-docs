Echoは、ページヘッダーの中央にある小さな画面です。送信とその所要時間、エラー、ランナーの進行状況、あなたの操作を待っているフロー、エージェントの呼び出し、
保護された環境への切り替えなど、ウインドウで起きていることをその場で伝えます。ときどき冗談も添えますが、その量はお好みで調整できます。
クリックすると、冗談抜きでセッションのレポートが表示されます。Echoはデフォルトでオンですが、オフにもできます。

## Echoをオン／オフにする [#turn-echo-on-or-off]

Echoはデフォルトでオンです。**設定 › 一般**を開き、**Echo**の下にある**ページヘッダーにEchoのステータス画面を表示**で切り替えます。
すべてのワークスペースウインドウがこの設定に従います。ページのタイトルとボタンの横に画面を置く幅がヘッダーにないときは、余裕ができるまでEchoは場所を譲ります。

もう一度隠すには、この設定をオフにするか、画面をControlキーを押しながらクリックして**Echoを隠す**を選びます。

## Echoが伝えること [#what-echo-tells]

Echoはウインドウを見守り、次のことについて短い行を画面に表示します。

- **送信**：送信中のリクエストとここまでの所要時間、続いてレスポンスのステータスと所要時間、失敗したチェック、またはレスポンスがなかった理由
  （タイムアウト、そのアドレスで待ち受けているものがない、ホスト名を解決できなかった、TLSハンドシェイクの失敗）。キャンセルした送信も同様です。
- **セッション**：WebSocket、Socket.IO、MQTTのセッションの接続と終了。
- **ランナー**：実行中の進行状況、続いて成功したリクエストと失敗したリクエストの数、または途中で停止した場所。
- **フロー**：フローの実行中、あなたの操作待ち、終了の仕方。
- **モック**：モックサーバの開始と停止、応答したリクエスト。
- **環境**：有効な環境の切り替え、そして[保護された環境](/docs/workspaces/protected-environments)の場合は警告。
- **エージェント**：エージェントの接続、その呼び出し、あなたの承認待ち、アシスタントの回答。
- **新機能**：アップデートのあと、まだ読んでいないリリース。

### 冗談の量 [#how-much-it-jokes]

**設定 › 一般 › Echo**の**ユーモア**で選ぶか、画面をControlキーを押しながらクリックして選びます。

| ユーモア | Echoの動作 |
| --- | --- |
| **事実のみ** | ステータスと詳細だけで、冗談はありません。 |
| **ほどほど** | ときどき冗談を言います。デフォルトです。 |
| **たっぷり** | すべての行に冗談がつき、何も起きていないときもおしゃべりが増えます。 |

## レポート [#the-report]

Echoをクリックするか、Controlキーを押しながらクリックして**Echoのレポートを表示**を選びます。画面から**セッションレポート**が広がり、
セッション開始からの事実が表示されます。

<Shot id="ai-echo-report" alt="Echoのセッションレポート。送信数、失敗数、平均・最遅・最速の所要時間、実行回数、セッションのイベントのログが表示されている" />

| 項目 | 集計する内容 |
| --- | --- |
| **送信**、**失敗** | 送信したリクエストの数と、そのうち失敗した数 |
| **平均**、**最遅**、**最速** | レスポンスの所要時間。最遅や最速にポインタを重ねると、そのリクエストが表示されます |
| **実行**、**実行失敗** | ランナーの実行回数と、実行したすべてのリクエストのうち失敗したリクエストの数 |
| **フロー** | フローの実行回数と、そのうち失敗した数 |
| **セッション** | WebSocket、Socket.IO、MQTTのセッション |
| **モック呼び出し** | モックサーバが応答したリクエスト |
| **エージェント呼び出し** | エージェントからの呼び出し |

起きていないことの項目は表示されません。その下に、セッションのイベントが時刻とともにログとして表示されます。
**消去**を押すと、レポートが最初からやり直しになります。閉じるボタンまたは<kbd>Esc</kbd>で閉じます。

## AIによるコメント [#ai-comments]

Echoは自分で文を書きます。必要なら、その一部をモデルに書かせることもできます：**設定 › 一般 › Echo**で**Echoのコメントの一部をAIに書かせる**をオンにします。
デフォルトではオフで、**事実のみ**のときは使えません。

- Apple Intelligence（macOS 26）のあるMacでは、Appleのオンデバイスモデルが書き、Macの外には何も出ません。
- それ以外の場合は、**設定 › アシスタント**でチェックされているモデルが書きます。どちらが使われるかは、**作成者**に表示されます。初回は、そのプロバイダについて
  [初回の許可](/docs/ai/assistant#the-one-time-permission)を確認します。まだ許可していない場合は、<strong>作成者</strong>にその旨と<strong>許可…</strong>ボタンが表示され、
  それまでの間、Echoは自分で文を書きます。アシスタントにすでに与えた許可は、Echoにも有効です。CLIエージェントがEchoのコメントを書くことはありません。

モデルが書くコメントは30秒に1回までで、失敗やそのほかの注目すべき場面についてのみです：失敗した送信、非常に遅い（3秒以上）または非常に速い（30 ms未満）送信、
失敗したチェック、保護された環境への送信や切り替え、実行やフローの完了、エージェントの承認待ち。

### モデルに伝わる内容 [#what-the-model-hears]

起きたことだけが、1文で伝わります：イベントの種類、リクエストの種類とメソッド、ステータスコード、所要時間、失敗したチェックの数、送信にレスポンスがなかった理由
（タイムアウト、待ち受けなし、ホスト名、TLS）、何件のリクエストの実行で何件失敗したか。たとえば、*「HTTPのPOSTリクエストが、180 msでステータス422を返しました。」*や
*「12件のリクエストのテスト実行が、2件の失敗で終了しました。」*のようになります。

名前、アドレス、ヘッダー、ボディ、変数、シークレットは一切伝わりません。

## アクセシビリティ [#accessibility]

- **視差効果を減らす**がオン（システム設定 › アクセシビリティ › ディスプレイ）の場合、行は入力されるように流れず、すぐに表示されます。
  画面は、テキストが変わったときか時計が進んだときだけ再描画され、レポートは広がらずに短いフェードで開きます。
- **コントラストを上げる**がオンの場合、画面はよりコントラストを高くして描画されます。
- VoiceOverはEchoの現在の行を読み上げます。画面のラベルは「Echo」です。
